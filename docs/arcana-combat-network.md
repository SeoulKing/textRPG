## 통신과 입력 처리

- `GET /api/games/:gameId/combat-ws`로 연결합니다. 서버의 `{ready:true, protocol:1}` 뒤 `{id, action}`을 보내며 응답은 `{id, result}`입니다. 공간 전투 입력만 허용하고 HTTP와 같은 GameService·게임별 잠금을 사용합니다.
- 클라이언트는 최대 4개 요청을 동시에 보낼 수 있습니다. 위치 동기화는 하나만 진행하고 대기 중인 위치 요청을 추가하지 않습니다. 공격·회피는 앞선 동기화의 응답을 기다리지 않습니다. 광장의 비전투 시계도 같은 소켓으로 1초 간격 동기화하여 첫 발사가 HTTP 시계 응답에 막히지 않게 합니다.
- 쿨타임이 있는 미확정 동일 주문은 중복 발사하지 않습니다. 쿨타임이 0인 주문은 응답을 기다리지 않고 연속 전송할 수 있습니다. MP 예약은 표시·입력 제한에만 사용합니다. 서버 수치가 최종 판정입니다.
- 입력 대기열은 최대 8개이며 전송 전 500ms를 넘긴 입력은 만료합니다. 순간이동의 기존 즉시 로컬 조작은 유지합니다.
- 서버는 수신 즉시 공용 게임별 잠금에 등록합니다. 재연결·HTTP 종료 요청이 이전 연결에서 이미 받은 입력을 추월하지 않게 합니다. 동일·이전 공간 입력 sequence는 기존 서비스가 중복 처리하지 않습니다.
- 서버 응답의 sequence가 적용한 상태보다 작으면 버립니다. 승패 종료 처리 중 후속 응답은 상태를 덮어쓰지 않습니다.
- 연결 실패 시 지수 백오프로 재연결하고 대기 입력을 지웁니다. 처리 여부가 불명확한 공격은 재전송하지 않으며, 일시정지 공간 동기화로 서버 상태를 확인한 뒤 입력을 재개합니다.
- 서버는 메시지 16KiB, 연결당 미완료 입력 8개, 응답 버퍼 1MiB를 제한하며 30초 ping/pong으로 끊긴 연결을 정리합니다. 브라우저 연결은 같은 Origin만 허용합니다. 게임 ID를 통한 접근 경계는 기존 HTTP API와 같습니다.
- 로그인·일반 행동·전투 종료 확인·저장 불러오기는 기존 HTTP 경로를 사용합니다. 기존 1초 주기 저장과 주요 행동 저장을 유지합니다.

## 공용 광장 슬라임의 피격 결과

공용 월드 전투는 `/api/arcana/worlds/main/ws`에서 각 캐릭터의 확정 전투 이벤트를 전달합니다. 광장 슬라임의 몸 접촉과 도약은 이벤트의 `hitSource`에 각각 `slime_contact`와 `slime_leap`으로 표시됩니다. 서버가 피해 원인을 기록하므로, 보호막이 피해를 일부 줄여도 심플 모드는 어떤 공격이었는지 그대로 표시합니다. 회피가 실제로 소모되면 어떤 공격을 피했는지도 표시합니다.

몸 접촉 피해는 광장 슬라임의 교전 참가자에게 적용됩니다. 슬라임을 선택해 전투를 시작하거나 공격을 명중시키면 참가합니다.

다른 모험가가 싸우는 중 광장 지도에서 슬라임을 선택하면, 서버가 고정된 도약과 진행 중인 이동의 남은 경로를 피해서 합류 위치를 고릅니다. 이동이 끝나야 접근할 수 있는 경우에는 다시 선택할 시점을 안내합니다.

심플 모드에서 교전에 합류한 뒤 슬라임에게 가까이 붙었을 때와 도약에 맞았을 때 각각 전투 메시지의 **몸 접촉**과 **도약**을 비교합니다. 회피 버튼을 누른 뒤 실제로 앞선 공격을 피했을 때는 **회피 성공**과 원인이 표시되어야 합니다.

## 광장 슬라임의 도약과 반격 예고

광장 슬라임의 즉시 재등장과 ‘다음 슬라임 상대하기’는 전투를 반복 확인하기 위한 개발용 흐름입니다. 정식 플레이에서는 슬라임과 한 번 교전하고 나면 그 슬라임은 사라집니다.

광장 슬라임을 선택하거나 첫 공격을 맞히면, 슬라임은 도약 사거리 안에서 바로 3초 예고를 시작할 수 있습니다. 사거리 밖에서는 열린 길을 따라 한 번에 최대 1.75칸 접근하고, 장애물 앞에서는 기존의 짧은 경로로 돌아갑니다. 이후 도약 사이의 간격은 그대로입니다.

온라인 분수 광장에서 파이어볼을 발사하면 내 캐릭터에 1.8초 재사용 대기가 시작됩니다. 발사가 확인되면 서버가 알려 준 남은 시간을 막대로 표시합니다. 초원과 오프라인의 파이어볼은 기존 재사용 규칙을 따릅니다.

도약 예고에는 준비, 임박, 진행 상태를 표시합니다. 슬라임이 다른 모험가를 표적으로 삼을 때는 이를 예고에 덧붙입니다. 마지막 1초에 서버가 내 캐릭터를 표적으로 고정하면 도약 경고와 사용할 수 있는 회피를 강조합니다. 도약이 시작된 뒤에도 내게 명중할 수 있는 동안에는 ‘지금 회피’가 표시됩니다. 착지 뒤에는 **반격 기회**와 회복이 끝날 때까지 남은 시간을 막대로 표시합니다. 교전 중이면 슬라임이 다른 모험가를 표적으로 삼아도 몸 접촉 피해를 받을 수 있습니다.

표적이 내게 고정된 뒤 서버 확인 위치와 화면 속 위치가 현재 도약 경로에서 충분히 떨어지면 **경로 밖**을 표시합니다. 예고 중에는 도약까지 남은 시간이 계속 표시되고, 다시 경로에 가까워지면 위험 경고가 돌아옵니다.

고정된 표적과 충돌하지 않고 도약이 끝났다면, 그 표적의 화면에 ‘도약이 빗나갔습니다’가 표시됩니다. 도약과 충돌해 회피 효과로 피해를 막으면 기존 ‘회피 성공’이 표시됩니다. 몸 접촉 피해는 별도로 기록합니다.

광장 슬라임이 도약 뒤 약 1.2초 동안 회복하는 사이에 공격이 명중하면, 서버는 기본 피해의 50%를 정수로 내림해 더합니다. 총 피해와 추가분은 남은 HP 안에서 계산합니다. 파이어볼처럼 날아가는 주문은 도착한 순간의 슬라임 상태를 사용합니다. 심플 모드는 서버가 확인한 반격 명중과 실제 피해를 전투 기록에 표시합니다.

심플 모드의 파이어볼 버튼은 시전과 비행에 걸릴 시간을 감안해, 회복 중 도착할 여유가 예상될 때 ‘반격 노리기’를 강조합니다. 예상 도착이 늦으면 ‘반격 시간 부족’을 표시하며 일반 파이어볼은 계속 발사할 수 있습니다. 위쪽 막대는 슬라임의 남은 회복 시간을 표시합니다.

전투 화면의 ‘사거리까지 접근’으로 이동 중일 때도 회피 버튼과 단축키를 사용할 수 있습니다. 회피가 시작되면 자동 접근이 끝납니다.

온라인 분수 광장에서 사거리 안의 슬라임을 장애물이 가리면 ‘쏠 자리로 이동’이 표시됩니다. 버튼을 누르면 슬라임이 사거리 안에 들고 탄이 지나갈 수 있는 지점으로 걷습니다. 이동 중 사격 경로가 먼저 열리면 그 자리에서 멈추고 파이어볼 버튼이 다시 표시됩니다.

심플 모드에서 파이어볼을 빼고 화염파를 장착하면 광장 슬라임전의 첫 공격 버튼에 화염파가 표시됩니다. 두 기술을 함께 장착하면 전투 행동에 두 버튼이 모두 표시됩니다. 화염파의 접근 버튼은 사거리와 장애물을 확인하며, 사용할 때 같은 슬라임을 다시 조준합니다.

화염파는 비행 시간이 없으므로 연결 지연을 감안해 회복 중 입력이 닿을 여유가 예상될 때 ‘반격 노리기’를 강조합니다. 늦어도 일반 공격은 사용할 수 있습니다. 현재 슬라임을 놓치면 서버가 판정한 ‘장애물에 막힘’ 또는 ‘적에게 닿지 않음’을 시전자에게 표시합니다. 입력이 도착하기 전에 상대가 바뀌면 마나와 재사용 시간을 소모하기 전에 새 슬라임을 선택하도록 안내합니다.

발사한 파이어볼이 현재 슬라임에게 한 번도 명중하지 않았다면, 심플 모드에서 ‘장애물에 막힘’ 또는 ‘적에게 닿지 않음’이 발사자에게 표시됩니다. 두 번째 표시는 탄이 사거리를 다 쓴 경우입니다. 슬라임이 돌아가 체력을 전부 회복하면 앞서 쏜 파이어볼의 피해와 실패 기록은 다음 교전으로 넘어가지 않습니다.

도약 사거리 안에서 ‘거리 벌리기’를 누르면 전투를 이어가면서 슬라임 반대 방향으로 한 칸 걷습니다. 직선이 막혀 있으면 양쪽 대각선을 확인합니다. 보행을 시작하면 아직 발사하지 않은 주문은 취소되고, 걷는 동안에도 피해를 받을 수 있습니다. ‘이동 멈추기’ 또는 회피로 보행을 끊을 수 있습니다. 교전을 끝내려면 ‘전투에서 벗어나기’를 선택합니다.

불꽃 장막을 장착하면 회피 바로 아래에서 사용할 수 있습니다. 내게 도약이 임박하고 회피를 쓸 수 없을 때는 사용 가능한 불꽃 장막을 강조합니다. 활성화된 장막은 남은 흡수량과 지속 시간 막대를 표시하고, 효과가 끝나면 재사용 막대를 표시합니다.

824×384처럼 낮고 넓은 화면에서는 슬라임의 도약 예고와 현재 결과를 왼쪽에, 주 공격과 회피 및 장착한 장막을 오른쪽에 고정합니다. 거리 조절과 다른 행동, 전투 기록은 아래의 스크롤 영역에 있습니다.

직접 확인할 때는 마지막 예고에 회피한 뒤 ‘반격 노리기’가 표시되는 동안 파이어볼을 쏴 봅니다. 회복 중에 명중하고 슬라임의 HP가 충분하면 기본 피해 10으로 ‘반격 명중 · 피해 15 · 추가 5’가 표시됩니다.

## 그래픽 모드의 조작과 타격 표시

파이어볼과 회피는 준비가 끝나기 직전 0.18초 동안 입력 한 번을 받아 둡니다. 메뉴를 열거나 지역을 벗어나거나 연결이 끊기면 입력을 비웁니다. 회피는 현재의 시전 준비를 취소하고, 아직 서버에 보내지 않은 공격보다 먼저 전달합니다. 서버가 확정한 착지점은 해당 회피를 시작한 위치를 기준으로 보정합니다.

광장 슬라임의 도약과 초원 뿔소의 돌진은 바닥에 충돌 폭과 경로를 표시합니다. 표적과 경로가 고정되면 경고색이 바뀌고, 명중 판정이 끝나면 경로가 사라집니다. 슬라임은 착지 자세와 먼지가 화면에서 함께 나오고, 뿔소는 제동 뒤 회복 자세로 이어집니다.

온라인 몬스터의 지면 위치와 동작 단계는 같은 보간 시각에 맞춰 표시합니다. 입력과 공격 경고는 최신 서버 상태를 사용합니다. 몬스터가 다시 등장하면 이동 보간을 끊고 새 위치부터 표시합니다. 방어에 성공하거나 피해를 받을 때는 서버가 판정한 실제 접촉 좌표를 사용하며, 피격 반동은 공격이 닿은 방향을 따릅니다.

투사체는 서버 위치에 맞춰 앞으로 이어지며, 서버가 알려 준 접점에 타격 효과를 표시합니다. 피해 숫자는 적의 중심에서 올라오고, 회피·장막 흡수·회복 중 반격은 각각 다른 표시를 사용합니다. 서버는 같은 틱 안에서도 실제 접촉 시점의 회피·장막과 슬라임의 회복 상태를 확인합니다.

## 직접 확인

서버를 새 코드로 빌드·재시작하고 새 웹 산출물로 게임을 여신 뒤 확인합니다.

1. 개발자 도구 Network에서 `combat-ws`의 101 연결과 Messages 입력·응답을 확인합니다. 공간 전투의 반복 actions POST는 없어야 합니다.
2. 슬라임과 싸우며 공격 직후 회피를 사용합니다. 서버 동기화 응답 때문에 회피 연출이 멈추지 않고, MP·쿨타임·보상이 서버 상태로 정리되어야 합니다.
3. 연결을 잠시 끊었다가 복구합니다. 과거 공격이 몰아서 재발사되지 않고 서버 상태 동기화 후 새 공격이 가능해야 합니다.
4. 적 처치 후 기존 사망 연출과 보상·자동 종료가 유지되어야 합니다.
5. 그래픽 모드에서 회피 재사용 막대가 끝나기 직전에 회피를 한 번 누릅니다. 준비가 되면 한 번만 회피해야 합니다. 광장과 초원에서 예고 경로 밖으로 벗어났다 들어가며 경고·명중·회복의 순서를 확인합니다.

WebSocket은 물리적인 왕복 지연이나 DB 저장 시간을 없애지 않습니다. PvP용 과거 판정 되감기, 고정 틱 전체 롤백, UDP 전송은 이번 범위에 포함하지 않습니다. 실제 왕복 지연·체감 개선 수치는 실행 측정 전에는 확정하지 않습니다.
