# 지하철 심층 탐험의 속말과 결과 서술

탐색·NPC 대화와 같은 흐름을 지하철 조우에도 적용한다. 선택하면 기존 본문과 선택한 줄을 유지하고 짧은 속말을 표시한다. 650ms의 기존 대기 연출을 유지하며, 응답이 늦으면 결과가 올 때까지 입력을 잠근다. 같은 층의 결과는 본문에 이어 붙이고 새 문단으로 한 번 스크롤한다. 다른 층이나 다른 원정으로 이동하면 새 장면을 시작한다.

## 생성 계약

- 서버가 가능한 선택의 ID·의도·효과를 결정한다. 기존 장면 요청에 `nextChoices`를 포함하고 Gemini는 본문과 `choiceThoughts: [{optionId, thought}]`를 한 번에 반환한다.
- 속말은 상황에 따른 궁금증·가벼운 의도 한 문장이다. 공격의 “어느 쪽에 빈틈이 있을까.”, 설득의 “말이 통할 여지가 있을까.”처럼 성공이나 행동 완료를 미리 결정하지 않는다.
- 실제 판정 후 `selectedThought`와 성공·실패·피해·보상 등 확정 결과를 별도로 전달한다. 본문은 실제 행동부터 결과까지 연결하고 이미 표시한 속말은 반복하지 않는다. 속말을 실제로 말한 대사로 취급하지 않는다.
- 속말의 잘못된 ID·중복·누락·잘못된 형식은 해당 선택의 기본 속말로 보완한다. 유효한 본문은 유지하며 보완을 위한 추가 호출은 없다. 전체 생성 실패에는 실제 판정 요약과 기본 속말을 사용한다.
- 구버전 `postChoiceNarrative`는 저장을 읽을 때만 허용한다. 새 선택·화면 표시·실제 결과 기록·모델의 과거 사실에는 전파하지 않는다. 미리 표시한 행동 문장을 결과에서 빼던 처리도 제거했다.

## 검증

관련 테스트 42개가 통과했다. Gemini 어댑터의 HTTP 요청을 모의 응답으로 대체해 한 요청에 본문과 속말이 포함되는지, 성공·실패·중복 클릭·저장 이행·부분 실패·같은 층의 본문 연결을 확인했다. TypeScript 빌드와 클라이언트 구문 검사도 통과했다. 실제 Gemini의 문체와 의미적 충실도는 이번 검증 범위에 포함하지 않는다.
384×824 인앱 브라우저의 독립 메모리 세션에서 첫 조우 → 공격 선택 → 실제 결과와 다음 다섯 선택 흐름을 확인했다. 대기 중에는 이전 두 문단과 선택한 행·속말이 유지되고 입력이 잠겼다. 결과 후 본문 블록이 하나만 추가되고 속말이 사라졌다. 가로 넘침과 브라우저 오류는 없었다. 모의 응답을 사용했으므로 화면의 LLM 표시를 실제 외부 생성 검증으로 간주하지 않는다.
