# 생존 압박과 10일 경로 검증

## 규칙

- 기존 비용 규칙인 기력 → 정신력 → 체력 소모를 유지한다. 자동 시간 소모도 같은 경로를 사용한다.
- 기력 0으로 보낸 누적 게임 시간 12시간마다 탈진이 한 단계 증가한다. 기력이 남아 있으면 누적은 멈추며, 이미 쌓인 부담은 남는다.
- 음식 등의 `exhaustionRelief`는 단계와 그 아래의 누적 시간을 함께 회복한다. 1단계는 12시간 분량이며, 필요량보다 큰 회복은 0에서 멈춘다.
- 탈진 Lv4는 체력과 관계없이 생존 실패다. 휴식으로 체력만 계속 채워 무식량 생존을 지속할 수 없다.
- 취침의 기력 소모 50%, 부상·감염 진행 25%는 유지한다. 기력 0 상태의 탈진 시간은 취침 중에도 그대로 흐른다.
- 날짜가 바뀌어도 기력 소모의 남은 시간과 탈진 누적은 초기화하지 않는다. 기력이 마지막으로 1→0이 된 시점보다 앞선 시간은 탈진으로 계산하지 않는다.
- 실제 한계 시점에서 플레이어와 모든 장소의 시간이 함께 멈춘다. 중단된 제작은 이미 사용한 재료만 소비하고 결과물을 지급하지 않는다.

## 표시와 저장

상태줄의 탈진 배지에서 다음 악화 시간, 기력이 남아 진행이 멈춘 상태, 음식 회복과 Lv4 실패를 안내한다. 아이템에는 탈진 회복량을 표시하고 사용 결과에도 단계 변화를 남긴다. 취침 선택지는 현재 상태를 복사해 계산한 실제 예상 수치와 사망 위험을 표시한다. 예고를 위한 생성 요청이나 실시간 진행은 없다.

저장 버전은 21이다. 이전 규칙에서 살아 있는 채로 Lv4 이상 쌓인 저장은 Lv3으로 상한을 보정해 읽는 즉시 사망하는 일을 막는다. 장소, 인벤토리, 퀘스트, 구조 신호와 누적 시간은 보존한다. 버전 21의 Lv4는 그대로 실패로 판정한다.

## 실제 선택 목록으로 진행한 경로

`tests/survival-ten-days.test.cjs`는 새 `GameService` 게임의 표시된 선택을 사용한다. 이동과 아이템 사용은 기존 지도·인벤토리 API를 사용하며, 생존을 위해 시간·아이템·완료 플래그를 주입하지 않는다. 나레이터는 기본 서사로 대체하고 외부 fetch를 차단한다.

- 무전기를 완성한 뒤 식사 없이 휴식과 취침만 반복하는 경로는 3일차 탈진으로 끝난다.
- 편의점·병원·역·검문소·급식소의 물자를 모으고, 숲에서 목재를 채집해 화로·냄비·장작을 만든다. 현재 재료에 따라 식사와 죽을 조리한다.
- 이후 낚시·연료 가공·생선 조리로 끼니를 준비한다. 낚시에 계속 실패하면 배식소 일을 도와 부족한 식사를 산다.
- 낚시가 매번 빈손인 경로와 매번 많은 양을 얻는 경로 모두 10일차 구조에 도달한다. 첫 경로는 구입한 식사 6개와 배식소 노동 4회를 사용하고, 두 번째 경로는 추가 식사 구매 없이 생존한다.

8개 압박 규칙 테스트에서 시간 분할·날짜 변경, 음식 회복, 정확한 사망 시점, 취침 예고, 제작 중단, 기존 저장, 상태 표시를 확인했다. 관련 부상·감염과 월드 시간 테스트도 통과했다. 384×824 격리 브라우저에서 탈진 안내 → 음식 효과 확인 → 사용 → 경고 해소를 확인했다. 가로 넘침과 콘솔 오류가 없었다.

## 남은 균형과 조작 개선

이 검증은 두 자원 극단에서 경로가 가능한지 확인한 것이며 장기적인 재미를 입증하지 않는다. 저녁 대기는 이후 추가한 긴 휴식으로 줄였다. 두 성공 경로는 15분 휴식 반복 없이 진행하며, 중단·회복·클릭 횟수 비교는 `docs/long-rest.md`에 기록했다. 음식과 자원 선택의 재미는 추가 플레이 검토 대상이다. 실제 Gemini의 문체·속말·장면 연결 품질은 사용자 요청 전까지 호출 없이 남겨 둔다.
