# 역무실 탐색·응답·문체 개선

## 선택 흐름

`세계 상태 → 관찰 → 실행 가능한 의도 → 상황별 역할 → 문장 표현`의 경계를 유지한다. LLM은 선택의 조건이나 결과를 정하지 않는다.

- 잠긴 문을 확인하면 같은 실패 선택을 반복하지 않고, 현재 보이는 미확인 표면을 정보 역할에 남긴다. 숨은 보상의 위치나 종류를 읽어 정답 선택지를 만드는 방식은 아니다.
- 실제로 사용할 열쇠가 있으면 잠금 해제에 진행 역할을 배정한다. 손에 다른 물건을 들고 있거나 상자를 보고 있어도 사용할 수 있다. 열쇠의 월드 엔티티 ID와 인벤토리 아이템 ID를 직접 비교하지 않는다.
- 바로 발견한 물건의 수집은 진행 역할과 함께 남긴다. 발견과 수집은 여전히 별도 선택이며, 다른 대상을 보거나 떠날 수도 있다.
- 저장된 선택을 유지할 때에도 필수 진행 역할이 빠져 있는지 확인한다. 수집 후 빈 용기 재탐색 등으로 개수를 채우지 않고 최대 다섯 개로 유지한다.
- 같은 관찰 지점·공간 기준점에 드러난 물건은 현재 자리에서 집는다. 바닥에서 발견한 열쇠를 주우려고 일어서거나 다시 걸어가지 않는다.

실제 경로: 입장 → 철문 확인(잠김) → 바닥 관찰 → 열쇠 발견 → 별도 수집 → 잠금 해제·개방 → 아이템에서 손전등 켜기 → 복도 → 역무실 재방문.

## 대기를 읽는 흐름으로 연결

- 클릭 즉시 요청을 시작하고 짧은 속말을 기존 본문에 타이핑한다. 선택지의 1초 채움은 병렬로 진행하며 빠른 응답을 붙잡지 않는다.
- Gemini의 JSON에서 완성된 문단을 먼저 검사해 전송한다. 선택지 문장과 전체 JSON, 저장 완료를 기다리는 동안에도 첫 문단을 읽을 수 있다.
- 첫 문단에 필수 사실이 모두 포함된 경우에도 남은 관찰 사실로 기본 후속 문단을 준비한다. 후속 문단의 빈 사실 ID 때문에 정상 생성 전체가 기본 서사로 바뀌던 오류를 수정했다.
- 안전한 후속 문단을 만들 수 없는 부분 응답은 공개를 보류한다. 이후 완성된 생성문 자체가 유효하면 그대로 사용한다.
- 이미 공개한 문단은 유지하며 통신 실패 시 빠진 사실만 보완한다. 행동은 한 번 실행하고, 응답을 잃으면 저장된 처리 결과를 조회한다. 동일 행동을 재전송하거나 추가 생성하지 않는다.
- 속말에서 한 번만 스크롤하고 결과는 같은 블록에 붙인다. 결과와 저장이 완료되기 전에는 다음 선택을 막는다.

## 글로 느끼는 공간

- 주어를 주로 생략하는 1인칭 현재형과 선택한 B 문체를 유지한다. 위치·표면·접촉을 동작 안에 연결하고 이름표를 반복하지 않는다.
- 사물의 `details.responses`에 실제 조작 때 발생하는 감각을 작성할 수 있다. 철문은 잠금 해제 때 잠금장치 소리, 개방 때 경첩 소리가 주어진다. 실패한 개방에서는 성공한 문 열림 소리가 나오지 않는다.
- 현재 조작과 이어지는 감각을 우선하고 최근 장면에서 쓴 배경의 재소개를 줄인다. 이전 저장에도 수정되지 않은 원래 사물의 감각을 보완하되, 편집된 설명과 명시적 응답 데이터는 보존한다.
- 문 양쪽의 공간 이름은 현재 있는 쪽에 맞춰 전달한다. 내부 데이터의 `/`로 분리된 양방향 배치를 본문에 그대로 넣지 않는다.
- 사실 ID·행동 결과 검사와 실제 생성문 검토를 함께 한다. 실제 생성에서 관찰된 벽의 손전등을 임의로 매달렸다고 쓰는 표현은, 해당 사물에 부착 근거가 없으면 보이는 위치만 남기도록 보정한다. 자연어 전체의 충실도를 사실 ID 검사만으로 보증하지 않는다.

## 검증 기록

- `npm.cmd run build`, 컴파일된 콘텐츠 검증 성공.
- 표시된 선택으로만 문 확인 → 바닥 관찰 → 수집 → 개방 → 복도·귀환을 수행하고, 저장 복원·중복 수집 방지·다른 물건을 든 상태의 잠금 해제·관찰 지점의 도달 범위를 검사했다.
- JSONB 형태의 키 재정렬 후 표시된 선택 실행, 스트리밍 중간 실패·처리 영수증 복구, 정상 첫 문단을 잘못 버리던 사례를 회귀 테스트로 확인했다.
- 실제 Gemini 입장·발견·문 개방 결과를 검토했다. 로컬 측정값은 사용 모델·네트워크의 일부 표본이며 운영 평균이나 상한을 의미하지 않는다.
- 384×824 한 브라우저 세션에서 속말·부분 문단·최종 결과의 같은 블록 연결과 입력 잠금을 확인했다. 대기 중과 완료 뒤 스크롤은 808.5px로 동일했고 문서 너비는 384px였다.
- 이번 수정 후 실제 브라우저의 Gemini 두 장면은 입장 `첫 문단 1,351ms / 전체 2,559ms`, 문 개방 `첫 문단 1,356ms / 전체 2,583ms`였고 모두 LLM 서사로 완료됐다. 각 장면은 한 번만 호출했다.
- 관련 자동 테스트는 서로 다른 106개가 통과했다. 기존 조명 물리 테스트 두 개는 손전등이 인벤토리 아이템이 된 이후의 실제 획득 절차를 사용하도록 준비 상태를 수정했다.
- 모바일 최종 경로는 열쇠 수집 → 개방 → 아이템의 손전등 켜기 → 복도 진입 → 역무실 귀환까지 완료했다. 이전 본문 10개가 보존됐고, 재방문의 세 선택은 활성 상태였으며 브라우저 오류는 없었다.
- 로컬 서버를 최신 빌드로 재시작하고 `/api/health` 정상 응답을 확인했다.
