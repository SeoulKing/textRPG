# 상황별 행동 추천

추천 목록은 실행 가능한 행동 전체에서 현재 장면에 필요한 의도를 고르는 서버 기능입니다. 모든 실행 가능한 세부 행동은 `주변과 물건`에서 계속 사용할 수 있습니다.

## 선택 기준

1. 엔진이 시야, 거리, 잠금, 비용, 재고, 퀘스트 조건을 검사해 후보를 만듭니다. 추천이나 개인 선호가 불가능한 행동을 가능하게 만들 수는 없습니다.
2. 위험 대응, 새로 얻은 열쇠, 새로 발견한 물건 수집, 준비된 퀘스트 전달을 우선합니다. 닫히는 문에는 문을 막는 행동을 단순히 옆으로 미는 행동보다 우선합니다.
3. 일상 장면에는 대화, 주요 활동, 발견, 이동, 다른 실용적 활동의 자리를 배정합니다. 같은 계열은 한 번만 추천합니다. 구매와 배식 돕기처럼 목적이 다르면 같은 배식대의 행동도 함께 나옵니다.
4. 손에 쥐기·보관하기·넣기·내려놓기는 기본 추천에서 제외합니다. 이미 가진 물건을 다시 집는 행동도 새 수집으로 추천하지 않습니다. 실행할 수 있는 주요 행동이 있으면 같은 대상에 접근하거나 재관찰하는 단계로 추천 자리를 채우지 않습니다.
5. 3~5개를 지향하되 실제로 유용한 행동이 더 적다면 그 수만 표시합니다. 기존 지역 이동 메뉴와 중복되는 이동이나 반복 관찰로 개수를 채우지 않습니다.

## 급식소와 대화

급식소 입장 직후 노파에게 말을 건네는 선택이 나옵니다. 선택하면 엔진이 실제 접근과 시간을 처리한 뒤 기존 NPC 생성 요청 한 번으로 대화를 시작합니다. 기존 `optionId + revision`과 중복 요청 복구를 사용합니다. 접근 도중 진행이 중단되거나 상대에게 닿지 못하면 대화를 생성하거나 선호를 보상하지 않습니다.

노파를 찾기 위해 관찰·접근·대화 메뉴를 차례로 열 필요가 없습니다. 다른 지역의 보이는 주민에게도 같은 규칙이 적용되며, 다른 방·어둠·위험 상황의 NPC를 임의로 추천하지 않습니다.

급식소 배식대와 노파의 상호작용 지점에는 `directFromEntry`를 작성했습니다. 식사 구매, 배급표 교환, 배식 돕기, 통조림 전달은 조건이 충족되면 접근까지 포함한 의도가 됩니다. 실제 실행 직전 조건을 다시 확인하며 기존 금액·재고·보상에 접근 시간만 더합니다. 이전 기본 저장에는 새 작성값을 보완하고, 명시적인 `false` 설정은 보존합니다.

## 선택하면서 적응하는 선호

추가 LLM이나 별도 학습 서버 없이, 현재 게임 저장에 상황과 행동별 선호 점수를 보관합니다. 성공한 선택은 +4, 최대 +24이며 같은 상황의 다른 점수는 1씩 감소합니다. 최대 64개만 보관합니다. 습관이 달라지면 새 선택이 점차 반영됩니다.

이 점수는 각 추천 자리 안에서 우열을 조정합니다. 선호가 위험 대응·새 발견·다양성 규칙을 밀어낼 수는 없습니다. 반복할 가치가 있는 일·거래·대화에는 단순한 최근 노출 벌점을 적용하지 않으며, 확인을 끝낸 탐색에는 반복 억제를 유지합니다. 화면 조회, 생성 재시도, 중복 클릭, 실패한 행동은 추가 학습하지 않습니다. 저장을 다시 읽어도 점수와 추천 ID가 유지됩니다.

이는 클릭에 적응하는 제한된 가중치 추천입니다. 모델을 재학습하는 강화학습이나 다른 플레이어까지 아우르는 추천 모델은 아닙니다. LLM은 엔진이 확정한 의도를 기존 서술 요청 안에서 문장으로만 표현합니다.

## 검증

실제 GameService를 사용하는 추천 테스트 8개에서 입장 구성, 한 번의 접근·대화, 중복·오래된 요청, 저장 순서 변경, 조건부 퀘스트 전달, 기존 저장, 선호 유지와 상한, 위험 우선, 접근 중 탈진을 확인했습니다. 기존 선택지 계약·급식소 규칙·생존 경로·NPC·엄폐 검사와 스트리밍 검사도 확인했습니다. 세부 조작 검사는 추천 목록 대신 실제 주변과 물건 목록에서 같은 행동을 실행하도록 갱신했습니다.

384×824 인앱 브라우저 한 세션에서 입장 → 노파와 대화 → 대화 종료 → 통조림 전달을 실행했습니다. 선택은 계속 의미가 다른 행동들로 구성되었고, 속말과 결과가 연결되었으며, 가로 넘침과 콘솔 오류는 없었습니다. 입장·전달 서술 처리 2번, 대화 처리 1번, 실제 Gemini 호출 0번입니다. 화면에서 확인한 접근 문장 중복과 조사 문제는 이후 코드와 관련 테스트에서 보완했습니다.
