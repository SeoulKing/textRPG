# 생존 월드 개선 진행 기준

## 전체 목표

확장 가능한 세계 엔진, 결과를 기다리는 자연스러운 읽기 흐름, 탐험·수집·제작·요리·생존이 연결된 플레이를 개선한다. 이 문서는 완료 선언이 아니라 현재 구현과 남은 게임 설계 결정을 구분하는 기준이다.

## 이번 단계에서 반영한 것

- 탐색의 선행 행동 서사를 제거했다. 클릭 시 선택한 줄 아래에 상황에 맞는 짧은 독백을 표시하고, 결과 본문은 실제 행동과 발견을 연결한 장면으로 받는다. 독백과 다음 선택 문구는 기존 서사 요청에 포함하므로 추가 호출이 없다.
- 가상 게임 시간을 단일 경로로 전달한다. 이동·제작·요리 중에도 다른 장소의 광원과 문이 진행된다. 부재 중 사건은 목격한 것처럼 서술하지 않는다. 네트워크 대기는 시간 비용이 아니다.
- 초점을 옮기는 선택은 확인을 마친 빈 보관함보다 아직 살피지 않은 대상을 우선한다.
- 공간 관계·용기·지지면·도구·문·광원 컴포넌트가 만드는 상호작용, 실제 실행과 서술의 분리, 저장과 수량 보존은 기존 구현을 유지한다.

## 이번 채집·제작 안내 개선

채집지의 재고 공유·고갈·게임 시간에 따른 회복, 부족한 재료의 준비 방법, 새 레시피의 일반 상세 표시를 구현했다. 현재 용량과 저장·검증 계약은 `docs/resource-sites-and-crafting.md`에 정리했다. 맨손 채집에서 소지하지 않은 칼·끈을 쓰고 가공 전 목재를 판자로 묘사하던 기본 문장도 수정했다.

## 확인한 생존 경로

새 게임의 실제 선택 목록을 통해 다음 경로를 진행했다. 모의 나레이터와 메모리 저장소를 사용했으며 사용자 저장이나 실제 Gemini 할당량을 사용하지 않았다.

1. 편의점에서 식량 보관함, 진열대, 계산대, 창고 자재 더미를 탐색하고 수집한다.
2. 역무실 상자에서 추가 고철과 물병을 확보한다.
3. 숲 가장자리에서 쓰러진 나무에 접근해 살핀 뒤 목재를 모은다.
4. 임시 거처에서 화로, 찌그러진 냄비, 장작을 만든다.
5. 확보한 쌀과 물·연료를 소비해 쌀죽을 끓인다.
6. 쌀죽을 먹고 기력을 회복한다. 재조회해도 재료·결과·시간이 바뀌지 않는다.

자동 회귀 테스트는 `tests/survival-route.test.cjs`에 남겼다. 제작용 고철이 편의점 한 곳만으로 부족해 다른 지역 탐색이 필요하다는 연결도 확인했다. 이것은 첫 생존 경로의 실행 가능성에 대한 증거이며 장기적인 재미에 대한 증거는 아니다.

## 남은 개선 대상

- 일상 생존의 반복과 선택: 숲은 유한한 채집 구간, 낚시는 시간이 지나면 회복하는 기회로 바뀌었다. 새 게임에서 10일 생존 경로를 확인했다. 낚시가 계속 실패해도 요리와 배식소 노동으로 부족한 식사를 마련할 수 있고, 풍어 경로는 추가 구매 없이 구조에 도달한다. 긴 휴식으로 저녁 대기의 반복 조작을 줄였다. 두 성공 경로에서 15분 휴식 반복은 0회다. 경로 통과만으로 장기 생존의 재미를 입증하지 않는다.
- 관심과 실제 휴대: 손에 든 물건·보관한 물건·현재 조작을 분리했다. 다른 대상으로 관심을 옮기면 배치 선택은 숨기고 실제 소유는 유지한다. HOLD/STOW와 시간·서술·소비·지역 이동 계약은 `docs/held-items.md`에 정리했다. 휴대 용기의 내용물과 인벤토리·제작 비용을 연결했다. 발견 전 정보 보호, 담기·꺼내기·소비·이동의 수량 계약과 모바일 검증은 `docs/portable-containers.md`에 정리했다.
- 제작 실행: 부족한 재료의 알려진 획득처와 가공 경로 안내를 추가했다. 제작·요리·설비 조립 12개에 명시적인 작업 계약을 적용했다. 비용 합산과 선소비, 실제 시간 경과, 완료 후 지급, 중단 기록과 중복 요청 방지를 확인했다. 규칙은 `docs/activities.md`에 정리했다. 향후 장기 생존 경로에서 작업 시간과 재료 비용의 균형을 함께 검토한다.
- 확장성: 자원 상태와 새 레시피의 표시가 데이터로 확장되도록 했다. 숲·강의 채집을 공통 텍스트 월드에 연결했다. 새 지역은 방 그래프와 자원 엔티티를 작성하면 같은 접근·관찰·작업 규칙을 사용한다. 다른 지역의 고유 사건·NPC 및 레거시 탐색 경로 통합은 남아 있다.
- 읽기 품질: 실제 Gemini가 선택한 B 문체, 짧은 속말, 직전 장면과의 연결을 지키는지 별도로 검토한다. 사용자가 실제 생성 검증을 요청하기 전에는 호출하지 않는다.

이번 대기 흐름의 구체적인 계약과 검증은 `docs/world-simulation-narrator.md`에 기록했다. 전체 생존 월드 목표는 계속 진행 중이다.

## 숲·강의 공간 탐색 통합

- 숲 가장자리와 안쪽 덩굴길, 강둑의 배치를 데이터로 작성했다. 접근·자세·관찰·구역 이동은 물리 엔진을, 채집은 기존 시간·보상·숙련·도구 소모 규칙을 사용한다.
- 자원 엔티티의 `resourceSite.siteId`와 기존 행동의 `resourceUse`를 연결한다. 가까이 다가가 확인한 대상에서만 작업이 나오고, 도구와 맨손의 다른 효율을 선택할 수 있다. 소진된 작업은 목록에서 사라진다.
- 실제 작업을 WORK, 실제 획득을 TAKE 이벤트로 전달한다. 빈손·작업 중단·도구 파손을 필수 결과로 서술한다. 다음 독백과 선택 문구까지 기존 요청 한 번에 받는다. 폴링과 재로드에는 생성하지 않는다.
- 강에 한 번만 수집할 수 있는 목재 2개의 가지 더미를 두었다. 발견과 수집을 분리하고, 모두 챙기면 더미가 사라진다. 재방문·다른 지역 이동·저장 복원으로 다시 생기지 않는다.
- 지역 이동은 기존 지도에서 유지한다. 옛 채집 API 직접 호출로 현재 상황의 선택을 우회할 수 없다.
- 새 지역 테스트 10건에서 접근 조건, 실제 비용과 보상, 빈손, 중복 클릭, 사망 중단, 저장·재방문, 채집지 회복, 임의 콘텐츠 ID를 확인했다. 기존 자원·선택·Studio 방·생존 경로 테스트도 통과했다.

384×824 격리 브라우저에서 나무 관찰 → 마지막 채집 → 소진 → 안쪽 구역 이동을 확인했다. 클릭 직후 이전 본문과 독백을 유지하고 결과마다 본문 블록이 하나씩 추가됐다. 획득 칩과 소진 후 선택 전환이 정상이며 가로 넘침·콘솔 오류는 없었다. 기본 서사로 확인했고 실제 Gemini 호출은 하지 않았다.

## 탈진과 10일 생존 경로

식사 없이 휴식만 반복해 구조를 기다릴 수 있던 빈틈을 닫았다. 기존 기력·정신력·체력 비용에 누적 탈진의 실패 기준을 연결하고, 날짜 변경·취침·작업 중단과 같은 시간 규칙을 적용했다. 기존 생존 저장의 즉시 사망을 피하는 버전 21 이행과 상태·음식·취침 안내를 추가했다. 실제 선택 목록으로 무식량 실패, 빈손 낚시 시 노동·식사 구입, 풍어 시 추가 구매 없는 생존을 확인했다. 구체적인 계약과 검증 한계는 `docs/survival-balance.md`에 정리했다.

## 긴 휴식과 본문 유지

데이터로 시간을 지정하는 중단 가능한 긴 휴식을 추가했다. 기력 소진·상태 악화 시 실제 시점에서 멈추고 다음 결정을 받으며, 음식 사용 뒤 같은 방 소개를 다시 붙이지 않는다. 10일 경로의 선택 횟수와 회귀 테스트, 브라우저에서 확인한 범위 및 재확인 제한은 `docs/long-rest.md`에 기록했다. 이후 관심 대상과 휴대 상태를 분리했다. 구체적인 규칙은 `docs/held-items.md`에 기록했다. 남은 핵심 범위는 다른 지역의 고유 사건을 공통 탐색에 연결하고 제작·도구 사용과 물리 세계의 상태를 일치시키는 것이다.



## 병원의 기존 재고와 고유 행동 연결

병원 접수실·임시 처치실을 공통 탐색에 연결했다. 재고 노드 바인딩은 기존 수량과 수집 비용을 유지하고, 상호작용 지점 바인딩은 관찰·관심 대상에 따라 기존 작업과 처치를 제시한다. 실제 실행된 무작위 장면만 서술에 전달한다. 기존 저장·부분 수집 중단·고유 행동 결과·Studio 보존을 검증했으며, 계약과 모바일 검증 범위는 `docs/hospital-exploration.md`에 정리했다. 이후에는 전체 목표의 남은 읽기 경로와 생존 선택을 점검하고, 필요한 개선을 진행한다.

## NPC 대화의 대기 흐름과 호출 통합

NPC 대화에 남아 있던 선택별 선행 문단을 제거하고, NPC 반응·다음 답변·속말을 한 요청으로 묶었다. 기존 대화 기억을 유지하면서 선행 동작은 모델의 사실 문맥에서 제외한다. 대화 종료 결과의 저장과 부분 생성 실패도 처리한다. 계약과 검증은 docs/npc-dialogue-flow.md에 정리했다. 지하철 심층 탐험의 선행 서사도 같은 짧은 속말 방식으로 전환했다. 기존 요청에 다음 선택의 속말을 포함하고 같은 층의 실제 결과를 본문에 이어 붙인다. 구버전 저장·판정 보존·실패 보완 계약은 docs/subway-choice-thoughts.md에 정리했다.

## 통합 경로 재확인과 제작·요리의 본문 연결

병원 탐색 통합 후 10일 생존 테스트가 옛 수집 메뉴를 참조하던 문제를 수정했다. 현재 노출되는 보관함 탐색과 묶음 수집을 사용한 세 경로가 통과했다. 무식량 경로는 3일차 탈진, 빈손 낚시 경로는 185회 선택과 구입 식사 6개·노동 4회, 풍어 경로는 322회 선택과 추가 식사 구매 없이 10일차 구조에 도달했다. 두 생존 경로 모두 짧은 휴식 반복은 0회다.

이후 실제 작업 결과를 읽는 경로를 점검해, 제작은 완료됐지만 본문이 비어 있는 결함을 재현하고 수정했다. 실제 완료·중단 문장을 활동 기록으로 저장해 본문에 연결하고 작업 종류에 따른 짧은 속말도 제공한다. 자세한 계약은 docs/activities.md에 있다. 이 증거로 작업의 결과 전달과 두 생존 경로의 가능성은 확인했지만, 처음 플레이하는 사용자가 목표와 준비 순서를 이해하는지와 장기 선택의 재미는 아직 별도 검토가 필요하다.

## 퀘스트 안내와 이번 작업 종료 범위

퀘스트 패널에 재료 탐색과 실제 전달·조립의 다음 단계를 구분해 표시했다. 완료 행동의 실제 비용과 도구 조건에 맞춰 체크리스트를 계산하며, 확인한 재고만 획득처로 안내한다. 계약과 테스트·모바일 검증은 docs/quest-guidance.md에 정리했다. 사용자 요청에 따라 이 개선까지 마무리해 게시하고, 위에 적힌 추가 개선은 이번 범위에서 진행하지 않는다.
