# 파이어볼 성장·전문화·궁극기

사용자 최종 변경을 반영한 실행 규격입니다. 평타는 별도 스킬로 만들 예정이므로 포함하지 않습니다.

## 성장

| 레벨 | 내용 |
| --- | --- |
| 1 | 기본 파이어볼, 기본 강화 트리 개방 |
| 2~4 | 레벨마다 1포인트. 위력·사거리·쿨타임 감소 각각 1단계 |
| 5 | 폭발·관통 중 하나 무료 습득 |
| 6 | 나머지 전문화도 무료 습득 |
| 7~9 | 레벨마다 미습득 궁극기 하나를 무료 선택. 9레벨에는 세 가지 모두 습득 가능 |
| 10 | 마스터 칭호. 추가 전투 특성 없이 이후 위력 성장 개방 |
| 11 이상 | 직전 레벨 대비 기본 위력 10% 증가. 추가 트리 포인트 없음 |

레벨 1~9의 다음 레벨 숙련도는 100, 200, 300, 500, 800, 1200, 1800, 2600, 3500입니다. 레벨 10 이후 필요 숙련도는 직전 요구량의 1.25배를 올림합니다. 실제 피해를 준 파이어볼 한 발당 숙련도 10을 지급하며 폭발·관통으로 여러 적을 맞혀도 중복 지급하지 않습니다. 궁극기와 빗나간 발사에는 지급하지 않습니다.

기본 강화의 초기값은 각각 위력 +30%, 사거리 +30%, 재사용 시간 -30%입니다. 기본 공격력 10을 기준으로 파이어볼 기본 피해는 `floor(10 × (3 + 0.3 × (min(레벨,10)-1)) × 1.1^max(레벨-10,0) × 위력 강화 배율)`입니다. 기본 사거리 6칸, MP 0, 쿨타임 3초입니다.

## 전문화

폭발은 직접 맞은 적 외의 주변 1칸에 50% 피해를 줍니다. 관통은 서로 다른 적 최대 3명에게 직접 피해를 줍니다. 6레벨에 둘을 모두 습득하면 각 직접 명중마다 폭발하며, 서로 다른 폭발은 중첩될 수 있습니다. 10레벨 마스터에서 이 효과를 추가로 강화하지 않습니다.

## 궁극기

| 기술 | 효과 |
| --- | --- |
| 메테오 | 지정 위치에 1초 뒤 낙하. 반경 2칸, 현재 파이어볼 직접 피해의 10배 |
| 거대화염구 | 직진하는 큰 화염구, 일반 투사체의 2배 충돌 크기. 처음 맞은 적에게 파이어볼 피해의 15배 |
| 화염난사 | 0.2초 간격 12발. 매 발사 시 현재 HP가 가장 적은 적부터, 동률이면 가까운 적. 각 발의 피해는 파이어볼 피해와 동일 |

모두 MP 30, 사거리 8칸, 공유 쿨타임 60초입니다. 폭발·관통 전문화는 적용하지 않습니다. 각각 기존 액티브 슬롯과 퀵슬롯에 배치할 수 있습니다. 메테오는 짧게 눌러 가까운 적 위치를, 드래그로 지점을 지정합니다. 거대화염구는 기존 방향 조준을 사용합니다. 화염난사는 자동 표적 선정과 추적을 사용하며 표적이 죽으면 다음 적을 선정합니다. 유효한 적이 없으면 해당 발사는 생략하고, 사망·지역 이동·전투 종료 시 남은 난사는 취소합니다. 지형을 뚫고 피해를 주지 않습니다.

MP와 쿨타임은 확정 시 한 번 소모하며 조준 취소에는 소모하지 않습니다. 초기화·재습득으로 공유 쿨타임을 우회할 수 없습니다.

## 저장·표시

기존 XP와 일반 스킬 장착은 유지하고 이전 파이어볼 트리는 버전 3으로 1회 이관하며 투자·전문화·궁극기 선택을 초기화합니다. 새 포인트는 레벨 기준으로 반환합니다. 수동 초기화도 XP·마스터·쿨타임을 유지합니다. 초기화로 해제된 궁극기는 액티브 슬롯에서 제거하고 재습득·재장착할 수 있습니다.

기존 한 마리 공간 전투는 적 배열로 이관합니다. 새 광장 교전은 기존 슬라임 자산을 재사용해 지형에 배치 가능한 최대 3마리를 관리하고, 처치마다 30원을 한 번 지급합니다. 모든 적을 처치했을 때 전투를 종료합니다. 기존 단일 적 필드는 이전 표시 경로를 위한 파생 값으로 유지합니다.

아이콘·궁극기 연출은 기존 승인 자산을 재사용하는 임시 표시입니다. 기존 캐릭터 애니메이션과 미술 원본은 변경하지 않습니다. 트리는 기본 강화 3개 → 전문화 2개 → 궁극기 3개 → 마스터로 표시하고, 이름·효과는 선택한 하단 상세에만 표시합니다.

## 직접 확인 항목

- 2~4레벨 포인트, 5·6레벨 전문화, 7·8·9레벨 궁극기 개수, 10레벨 마스터와 이후 위력 성장
- 초기화 시 XP·공유 쿨타임 유지, 포인트 반환과 궁극기 슬롯 해제
- 폭발·관통·다수 명중의 피해와 한 발당 숙련도 1회 지급
- 메테오 낙하·취소, 거대화염구 단일 피해, 난사 표적 변경·중단, MP 부족과 공유 쿨타임
- 기존 저장 복원, 모바일 한 화면 트리와 하단 상세

자동 테스트·브라우저 실행은 별도 요청 전 수행하지 않습니다. 서버 컴파일과 Godot 웹 내보내기는 배포 산출물 생성에 포함합니다.
