# 편의점 폐허의 텍스트 탐색

편의점에 도착하면 기존 사물별 화면 대신 텍스트 월드 장면이 바로 시작됩니다. 진열대, 계산대, 보관함, 창고 자재 더미를 살핀 뒤 별도의 선택으로 발견한 물건을 챙깁니다. 본문 이어붙이기, 타이핑, 서사 출처 표시, 획득 칩은 기존 화면을 사용합니다.

## 기존 콘텐츠 연결

- `src/game/text-world/convenience.ts`는 현재 게임의 런타임 레지스트리와 `stockState`에서 관찰용 엔티티를 구성합니다. 별도의 재고를 지급하거나 초기 수량으로 되돌리지 않습니다.
- 탐색은 기존 초점 선택의 효과를 실행합니다. 물건을 모아 챙길 때에는 기존 수집 선택을 순서대로 실행하여 수량, 돈, 숙련도, 플래그, 스킬에 따른 시간 조정을 유지합니다. 탐색 이동 자체의 게임 시간은 기존 초점 선택과 같습니다.
- 수집 도중 생존이 끝나면 이후 물건은 지급하지 않습니다. 서비스의 복제 상태와 직렬 실행, `optionId + revision` 검증을 사용합니다.
- 일반 지역 이동과 귀환은 기존 이동 메뉴에서 처리하며 탐색 선택지에 중복으로 넣지 않습니다. 포탈 발견의 기존 문장과 사건 선택은 장면에 유지합니다.
- `remain` 보관함은 남기고 `disappear` 재고 노드는 소진 후 탐색 대상에서 제외합니다.

## 저장과 서술

- 지역별 상태는 `locationTextWorlds`에 저장합니다. 기존 지하철의 `textWorld`는 그대로 보존합니다. 구버전 저장은 지역 상태를 빈 레코드로 보완하고 기존 재고·발견 기록을 이어받습니다.
- 위치, 자세, 관찰 단계, 최근 세 장면을 공통 `NarrativeContext`로 전달합니다. 입장과 의도 실행마다 서술을 한 번 생성하고, 상태 폴링은 저장된 문단을 재사용합니다.
- Gemini 실패나 필수 사실 ID 오류에는 같은 행동과 발견을 기본 서사로 연결합니다. 실제 검토에서 확인한 편의점의 빈 내용물 누락 및 근거 없는 포대·자루 표현도 검사합니다.
- 엔티티와 지역별 탐색 상태는 클라이언트 스냅샷에서 숨깁니다.

## 선택 직후 행동 문장

- 현재 결과를 생성하는 한 번의 Gemini 요청에서 `nextChoices`별 행동 시작 문장도 함께 받습니다. 별도의 선행 요청이나 재시도는 없으며 출력 토큰만 소량 늘어납니다.
- 문장·선택 라벨·출처를 `choiceNarratives`에 저장하고, `postChoiceNarrative`로 보냅니다. 기존 저장이나 누락·중복·잘못된 선택 ID 및 명백한 결과 단정에는 해당 선택만 기본 행동 문장을 사용합니다. 결과 서사가 유효하면 그대로 유지합니다.
- 클릭은 기존 `optionId + revision`만 전송합니다. 서버는 같은 선택의 미리 표시된 문장을 `alreadyDisplayed`로 전달해 결과에서 반복하지 않게 하고, 최근 세 장면에도 함께 보관합니다. 실제 이동·발견·획득은 엔진 결과에서만 확정됩니다.
- 빠른 응답은 행동 문장 타이핑을 기다립니다. 타이핑 건너뛰기는 현재 문장만 완성하며, 요청 실패 시 이전 본문·획득 칩을 복구합니다.
- `tests/text-world-action-leads.test.cjs`와 `tests/scene-preparation.test.cjs`가 한 번의 호출로 문장 준비, 저장 복원, 오류 대체, 중복 클릭, 응답·타이핑·대기의 순서를 모의 응답으로 확인합니다.

## 대기 연출과 확인

탐색·수집 및 지하철 텍스트 선택에 기존 `loading` 메타데이터(500ms, activity)를 전달합니다. 이동 메뉴의 지역 이동은 1000ms의 region_travel 연출을 유지합니다. 텍스트 선택은 클릭 즉시 미리 준비한 행동 한 줄을 타이핑하고, 요청·최소 대기·행동 문장 표시가 모두 끝나면 다음 문단에 결과를 이어 붙입니다. 500ms 선택지 채움 연출도 함께 진행하며, 결과가 도착할 때 행동 문장을 화면 밖으로 밀어내지 않습니다.

`tests/convenience-text-world.test.cjs`에서 발견/수집 분리, 기존 규칙과 수집 결과 비교, 현금 단위, 기존 저장·편집된 수량·지역 왕복, 소진, 포탈, 중간 생존 종료, 중복 클릭, 호출 횟수, 대기 메타데이터와 관찰된 서술 오류를 검증합니다.
