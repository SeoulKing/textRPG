# 아르카나 가구 배치 시스템 설계

플레이어가 방의 바닥 칸에 가구를 미리 놓아 보고 설치·이동·회전·회수할 수 있게 합니다. 공간 제작과 게임 내 배치는 같은 가구 정의와 점유 규칙을 사용합니다. 첫 구현 대상으로 개인 집과 장식용 바닥 가구를 제안합니다.

## 그리드와 모델

- 방에 정수 X/Z 좌표의 그리드를 둡니다. 한 칸은 Godot 1단위이며 방마다 원점, 설치 가능한 셀, 출입구와 필수 설비 주변의 예약 셀을 지정합니다. 가장자리의 부분 셀은 기존 이동 경계에 포함할 수 있습니다. 가구 설치에는 완전한 셀을 사용합니다.
- 가구마다 설치 점유와 모델 크기를 기록합니다. 현재 식당의 의자와 2인용 식탁은 각각 1×1칸을 예약합니다. [식당 에셋 목록](../art-studies/regions/arcana-restaurant/furniture-catalog.md)에 모델 치수와 점유 칸을 함께 기록합니다. 바닥 마루판의 방향·폭·이음은 시각 재질의 규격입니다.
- 저장하는 배치 기준점은 회전한 점유 사각형의 최소 X/Z 셀입니다. 모델은 점유 중심과 바닥 피벗에 맞춥니다. 가로×깊이가 2×1인 가구를 한 번 돌리면 1×2칸을 사용합니다. 식탁의 상판 장식, 가구의 접지 높이, 돌출부는 모델과 함께 움직입니다.
- 기본 방향과 90도 단위 회전을 사용합니다. 가구에 붙은 사용 위치와 접근 칸도 점유 영역과 같은 방향으로 회전합니다. 바닥 셀의 긴 축이나 모델의 임의 배율로 점유 칸을 추정하는 대신, 카탈로그에 등록한 값으로 계산합니다.
- 이동 판정은 방의 좌표 변환을 통해 같은 점유 칸을 사용합니다. 기존 개인 집은 1단위당 16 논리 픽셀, 식당은 타일당 20 논리 픽셀로 연결됩니다. 지역별 변환을 유지하면 기존 이동·상호작용 좌표를 보존하면서 저장에는 정수 셀을 쓸 수 있습니다.

| 배치 종류 | 예약하는 위치 | 이동 판정과 사용 예 |
| --- | --- | --- |
| 바닥 가구 | 바닥 셀의 직사각형 | 바닥 충돌과 가구 겹침을 막습니다. 의자, 식탁, 장식장에 적용합니다. |
| 바닥 장식 | 같은 바닥의 별도 장식 영역 | 통행과 가구 설치를 허용합니다. 러그끼리 같은 칸을 쓰면 한쪽만 배치합니다. |
| 벽 부착물 | 벽면 방향과 길이, 높이 | 벽등과 액자가 해당 벽면을 씁니다. 창과 문 개구부에는 배치 제한을 둡니다. |
| 가구 위 장식 | 상판의 지정 위치 | 부모 가구와 함께 이동합니다. 처음에는 현재 식기처럼 모델에 포함된 장식을 사용합니다. |
| 고정 설비와 출입구 | 공간 설계자가 등록한 예약 영역 | 필수 설비와 주 동선을 보호합니다. 기존 조리대, 출입구, 상호작용 지점에 적용합니다. |

## 카탈로그와 저장 데이터

| 데이터 | 필요한 값 | 관리 위치 |
| --- | --- | --- |
| 가구 정의 | `assetId`, 종류, `footprint`, 바닥 피벗, 회전 방향, 배치 종류, 모델 경로, 충돌·사용 위치, 설치 권한 | 가구 카탈로그. Blender 원본과 Godot 리소스 경로를 함께 추적합니다. |
| 방 규격 | `layoutId`, `gridVersion`, 원점, 설치 가능·예약 셀, 등장 위치, 출구·필수 설비 접근점 | 제작자가 편집한 기본 평면. 지역·층·개인 집 구분을 포함합니다. |
| 가구 인스턴스 | `instanceId`, `assetId`, 기준 셀 `(x, z)`, `rotation`, 배치한 방 | 개인 집의 저장 배치. 같은 종류의 의자도 서로 다른 `instanceId`를 가집니다. |
| 배치 버전 | `layoutRevision`과 적용한 `gridVersion` | 확정할 때 하나씩 올리고, 재접속과 동시 편집 확인에 사용합니다. |

예를 들어 카탈로그에서 `chair = 1×1`, `table-for-two = 1×1`을 정의합니다. 방에는 창가 식탁과 양쪽 의자를 별도 인스턴스로 두고, 서로 이웃한 셀에 기록합니다. 모델의 색과 장식이 달라져도 같은 점유 규격이면 배치 ID를 유지합니다. 점유 규격을 바꾸는 경우 기존 배치를 변환할 규칙을 먼저 정합니다.

현재 [소품 라이브러리](../godot-arcana/data/prop-library.json)는 편집기에서 재사용할 에셋을 찾는 색인입니다. 게임용 카탈로그에는 설치할 수 있는 가구와 아이템만 등록하고, 에셋 ID로 미술 원본을 연결합니다. 식당의 현행 자료는 [가구와 점유 면적](../art-studies/regions/arcana-restaurant/furniture-catalog.md)에 정리했습니다.

## 플레이 흐름

1. 개인 집에서 꾸미기 모드를 열고 보관함 가구나 이미 놓인 가구를 선택합니다. 기존 [바닥 좌표 선택](../godot-arcana/scripts/native_2d_world.gd)을 사용해 마우스나 터치 위치를 셀로 변환합니다.
2. 가구 미리보기와 점유 칸을 표시합니다. 회전하거나 이동하는 동안 설치 가능 상태와 막히는 이유를 표시합니다. 그리드는 꾸미기 모드에서 표시합니다.
3. 플레이어가 확정하면 가구 ID, 셀, 회전, 현재 `layoutRevision`, 중복 방지용 `actionId`를 보냅니다. 서버가 승인한 배치를 집에 반영합니다. 취소하면 원래 위치로 돌아갑니다.
4. 집에 다시 들어오면 기본 도면과 저장한 가구를 합쳐 복원합니다. 배치를 회수하면 가구를 보관함에 돌려보냅니다.

## 검증과 저장

- 서버는 방 소유권과 꾸미기 권한, 가구 보유 수량, 인스턴스 소유권, 회전과 배치 버전을 확인합니다. 새 가구를 두는 경우에는 보관함 수량을 줄이고, 이동과 회전에는 기존 인스턴스를 사용합니다.
- 점유 칸이 설치 가능 영역에 포함되는지와 같은 층의 가구에 겹치는지 검증합니다. 이동 대상의 기존 점유만 검사에서 제외합니다. 출입구, 등장 위치, 현재 캐릭터의 발 위치, 필수 설비 접근 칸을 보호합니다. 배치 후에도 등장 위치에서 출구와 필수 접근점까지 실제 이동 여유를 포함하는 경로가 이어져야 합니다.
- 배치 확정, 보관함 변경, 중복 요청 영수증을 기존 [온라인 체크포인트 저장](../src/online/checkpoint-writer.ts)의 같은 트랜잭션에서 처리합니다. 오래된 배치 버전의 요청은 최신 배치를 돌려보내 다시 확인하게 합니다. 재접속은 확정된 배치 버전부터 복원합니다.
- 개인 집의 이동과 경로 판정은 집별 기본 도면과 저장 배치를 합친 결과를 참조합니다. 현재 [개인 집 배치 수집](../godot-arcana/scripts/player_home_3d.gd)과 [온라인 월드](../src/online/world.ts)에 이 경계를 연결할 수 있습니다. 서버는 승인 결과를 입장과 변경 시점에 동기화합니다.
- 이전 저장은 기존 집 도면으로 엽니다. 집의 도면이나 가구 크기가 바뀌어 기존 셀에 설치할 수 없으면 새 규격에 맞춰 옮길 수 있는 항목을 복원하고, 나머지는 보관함에 돌려 수량을 보존합니다. 확정된 새 배치가 플레이어의 기존 좌표를 막으면 검증된 등장 위치로 복원합니다.

## 구현 순서와 완료 조건

| 순서 | 범위 | 확인할 동작 |
| --- | --- | --- |
| 1 | 개인 집의 의자·식탁·장식용 바닥 가구 | 배치, 한 칸 이동, 90도 회전, 취소, 회수, 재접속 복원이 됩니다. 벽·다른 가구·출입구에 걸친 배치는 이유와 함께 거절됩니다. |
| 2 | 사용 기능이 있는 가구와 바닥 장식 | 앉는 위치와 접근 칸이 이동·회전에 맞춰 갱신됩니다. 러그는 사람이 걸을 수 있고 지원되는 가구와 같은 칸에 놓입니다. |
| 3 | 벽 부착물·상판 장식과 다른 공간 | 부착 가능한 면을 판정하고 부모 가구를 옮길 때 부착물이 따라옵니다. 사용할 수 있는 공간과 편집 권한은 공간별로 정합니다. |

## 공간 제작과 인계

공간을 그리기 전에 가구 종류별 가로×깊이, 예상 수량, 바닥 피벗과 접근 방향을 정합니다. Blender 원본과 GLB를 공간의 건축·가구·장식 등 용도에 맞는 폴더에 두고 반복 가구는 한 모델을 인스턴스로 재사용합니다. 바닥 가구·벽 부착물·통행 가능한 장식의 면적은 각각 기록합니다.

완료 보고에는 공간의 전체 크기, 가구별 개당 점유·수량·합계, 바닥 차단 면적과 주요 통로를 적습니다. 실제 모델 치수가 그리드 규격에 비해 작거나 장식이 셀 밖으로 돌출되면 그 점도 표시합니다. [식당 보고서](../art-studies/regions/arcana-restaurant/furniture-catalog.md)를 같은 형식으로 사용할 수 있습니다.
