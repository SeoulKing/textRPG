# 소설처럼 이어지는 지하철역 탐색

탐색과 물건 수집만 다루는 시험 구역입니다. 대합실의 **옆쪽 역무실을 둘러본다**로 시작합니다. 화면의 본문 누적, 표형 선택지와 획득 칩은 기존 구현을 사용합니다.

## 행동과 발견

역무실 입구를 기준으로 왼쪽 벽 아래에 상자, 오른쪽 벽에 손전등, 맞은편에 철문이 있습니다. 복도는 역무실과 창고를 잇고, 창고 입구 양옆의 빈 선반과 맞은편 바닥의 공구 보관함에도 같은 관찰 규칙을 적용합니다.

- 멀리서는 윤곽과 배치만 압니다. 접근하면 표면, 열고 빛이 닿으면 내부를 확인합니다.
- **나무 상자를 열어 안을 확인한다**는 서기 → 접근 → 몸 낮추기 → 관찰 → 개방을 필요한 만큼 실행합니다. 새 내부 발견에서 멈춥니다.
- **미개봉 물병과 고철 조각을 챙긴다**는 별도 선택입니다. 각 물건을 엔진에서 한 번씩 처리하며 총 물병 1개와 고철 2개가 기존 인벤토리에 들어갑니다.
- 수집한 물건은 다시 나타나지 않고 빈 상자·보관함은 남습니다. 미확인 대상처럼 반복 제시하지 않습니다.
- 선택지는 수집·미확인 대상·조명·이동·귀환에서 최대 5개를 구성합니다. 가능한 행동이 두 개뿐이면 두 개만 표시하며, 상태 재확인을 기본 선택지로 넣지 않습니다. 하위 메뉴나 선택지 페이지는 없습니다.
- 철문은 처음에 잠겨 있습니다. 바닥을 자세히 관찰하면 열쇠가 드러나며, 별도로 수집한 열쇠로 잠금을 풀고 문을 엽니다. 열쇠는 중복 지급되지 않고 기존 인벤토리에 남습니다.
- 잠금·접근 불가 조건에 닿으면 이후 행동을 실행하지 않습니다. 완료한 행동과 중단된 행동을 구분해서 기록합니다.
- 이동 5초, 자세 변경 1초, 표면 관찰 5초, 잠금 해제 3초, 개폐 2초, 물건별 수집 3초, 조명 전환 1초, 통로 관찰 5초, 대합실 귀환 5초가 소요됩니다. 불필요한 접근·자세 변경은 생략합니다.

## 렌더링 경계

    선택 ID + revision
       → 서버의 의도와 행동 계획
       → 행동별 검증·실행·시간·구조화된 결과
       → 현재 보이는 사실과 과거에 확인한 사실 구분
       → NarrativeContext
       → Gemini 최대 한 번 호출 / 실패 시 기본 서술
       → 기존 본문에 새 장면 추가

NarrativeContext에는 선택한 의도, 실제 실행 결과, 필수 변화·발견, 선택적으로 사용할 감각 정보, 현재 위치·시선·자세·휴대 도구, 최근 세 개의 실제 서술 장면이 들어갑니다. 전체 월드나 숨겨진 내용물은 전달하지 않습니다.

LLM은 현재 시제의 주어를 대체로 생략하는 1인칭 한국어로 서술합니다. 주어와 같은 사물 이름의 반복을 줄이고 움직임·시선·사물·발견을 섞습니다. 중요한 장면은 2~3문단, 조명 끄기·이미 지난 길의 귀환은 짧은 1문단입니다. 각 장면은 기존 타이핑 효과로 표시하고 `LLM 생성` 또는 `기본 서사` 출처를 붙입니다. 감각은 작성된 데이터에서만 가져오며 과거 사연·인물·전투·선택하지 않은 행동은 추가하지 않습니다.

응답의 문단 수, 필수 사실 ID 누락, 허용되지 않은 ID와 본문 ID 노출을 검사합니다. 선택 감각 정보를 모두 표현할 의무는 없습니다. 이 검사는 자연어 의미의 충실도까지 증명하지 않으므로 실제 모델 출력 검토를 함께 수행합니다. 생성이 실패해도 행동 결과와 아이템 지급을 다시 계산하지 않고 같은 결과의 기본 서술을 사용합니다.

## 저장과 책임

월드 버전 2는 위치·시선·자세·손전등, 관찰 단계, 수집 완료, 방문 구역, 구조화된 이벤트와 최근 세 장면을 저장합니다. 버전 1 저장은 기존 엔티티·내용물·문 상태·조명·시간·revision을 보존하고 필요한 필드만 이행합니다. 잘못된 기존 월드를 새 자원으로 덮어쓰지 않습니다. 아직 시험 구역에 들어가지 않은 저장은 첫 입장 때 생성합니다. 이전 역무실의 닫힌 철문에는 열쇠 규칙을 추가하되, 이미 열린 문과 수집한 자원은 보존합니다.

| 코드 | 책임 |
| --- | --- |
| schemas/text-world.ts | 저장 스키마와 장면 입력 타입 |
| text-world/definitions.ts | 기본 공간과 단계별 감각 데이터 |
| text-world/world.ts | 편집기 방 정의 연결, 시야·거리·조명, 저장 이행 |
| text-world/choices.ts | 현재 상황에서 바로 실행할 의도 계획 |
| text-world/engine.ts | 실제 행동 순서, 중간 실패, 발견 경계, 아이템·시간 |
| text-world/perception.ts | 현재 관찰과 기억 구분, 필수 정보·감각 정보 선별 |
| text-world/narrator.ts | Gemini 입력, 사실 ID 검사, 기본 서술 |
| text-world/index.ts | 기존 장면·선택지·획득 노트 연결 |
| service.ts | 요청 직렬화, 저장과 응답의 숨겨진 월드 제거 |

## 검증

    npm.cmd run build
    node --test tests/text-world.test.cjs tests/narrative-continuity.test.cjs

관련 자동 테스트는 단계별 발견, 한 번의 의도 선택, 묶음 수집과 중복 요청, 중간 실패, 어둠 속 내부, 위치·도구·최근 세 장면, 기존 저장 이행, 필수 사실 누락과 잘못된 ID, 140개 도달 가능 상태의 선택지 수, 기존 본문 연결을 다룹니다.

실제 Gemini로 입장 → 상자 확인 → 수집 → 손전등 휴대·사용 → 복도 → 역무실 재방문을 검토합니다. 로컬 실험 결과는 `.runtime/text-world-novel-live-check.json`에 저장합니다. 테스트용 게임은 사용자 저장과 분리합니다.

384×824 인앱 브라우저에서 본문 누적과 이전 문단 보존, 새 장면 첫 줄의 상단 정렬, 표형 선택지, 물병·고철 획득 칩과 가로 넘침 없음이 확인되었습니다. 실제 Gemini 검토에서 반복 배경 묘사를 줄였고, 한 문단으로 압축된 응답에는 생성 시점의 문단 수 제약을 추가했습니다. 수정 후 수집·손전등 장면 두 개가 실제 LLM의 두 문단으로 통과한 기록은 `.runtime/text-world-final-narration-review.json`에 있습니다.
