# 1인칭 탐색과 일관성 검증

적용 범위는 현재 구현된 역무실·정비 복도·정비 창고의 텍스트 월드입니다. 탐색과 수집을 유지하며 NPC·전투·과거 사연을 덧붙이지 않습니다.

| 요청 | 구현과 증거 |
| --- | --- |
| 내가 직접 겪는 소설의 시점 | NarrativeContext.voice가 first / 나 / present / omitSubject이며, 생성 지시와 응답 검사에서 플레이어를 당신·너·주인공으로 부르는 서술을 차단합니다. 실제 12장면 흐름에서 주어를 생략한 동작과 감각을 검토했습니다. |
| 행동·감각·발견이 이어지는 글 | 기본 서술도 접근과 자세 변경, 접촉과 개방, 수집과 빈 내부를 인과 단위로 엮습니다. 대합실에서 스며드는 빛, 복도의 발소리, 창고의 서늘한 공기는 방 데이터에 작성되고 해당 행동 때만 전달됩니다. |
| 글 뒤에 지속되는 세계 | 문 개폐, 정확한 연결 구역, 물건의 소속, 수집 완료, 위치·시선·자세·손전등, 관찰 단계와 최근 3장면을 저장합니다. 닫힌 내부나 어두운 곳의 물건은 노출하지 않습니다. 기존 저장의 수집 결과와 확인했던 내부의 기억도 보존합니다. |
| 의미 있는 선택과 최대 5개 | 상자 확인은 접근·자세·관찰·개방까지, 수집은 별도 결정으로 묶습니다. 손전등이 필요하면 켜고 이동하는 것을 한 의도로 처리합니다. 사물이 많은 편집기 방에서도 5개 이내로 선별하고 귀환을 남깁니다. |
| 견고한 결과 처리 | revision으로 중복 요청을 막고 실제 행동마다 조건과 시간을 검증합니다. 중간 실패와 발견에서 중단합니다. LLM의 형식 오류·사실 ID 누락·잘못된 ID·2인칭·관찰된 자세 및 출입구 모순·이동/수집 결과 생략을 검사하며 실패 시 결정된 엔진 결과로 서술합니다. |
| 상태를 분명하게 파악 | 재확인은 모델이 생략하거나 바꿀 수 없도록 저장된 배치·문 상태·휴대 도구·확인한 내부를 한 문단으로 직접 작성합니다. |

## 초기 1인칭 탐색 검증 기록

- 빌드 성공.
- 텍스트 월드 자동 테스트 19개 통과: 기존 이행·수집·중복 요청·부분 실패·조명·관찰·서술 실패·140개 도달 가능한 상태·편집기 사물 증가·시점·모순 검사.
- 연결된 콘텐츠 편집기 저장/발행/이름 변경/삭제 테스트 4개 및 본문 연속성 테스트 9개 통과.
- 실제 Gemini로 입장 → 상자 확인 → 묶음 수집 → 손전등 → 복도 → 통로 확인 → 창고 → 보관함 확인 → 수집 → 복도 → 역무실 → 상태 정리를 검토했습니다. 중요한 장면은 2~3문단, 귀환과 재확인은 1문단이며 선택지는 4~5개였습니다.
- 실험 데이터: `.runtime/text-world-first-person-live-check.json`. 물병 +1, 고철 +2, 캔 음식 +1과 빈 용기, 최근 3장면, 원본 월드 비공개를 확인했습니다.
- 실제 생성문의 재웅크리기·출입구 혼동·이동 결과 생략 사례를 회귀 테스트로 추가했습니다. 사실 ID 검사는 자연어 전체의 의미를 증명하지 않으므로 실제 생성문 검토와 구체적인 모순 검사를 함께 사용합니다.

## 유지되는 인터페이스

기존 본문 이어붙이기·이전 문단 스크롤·표형 선택지·획득 칩을 사용합니다. 서버는 선택지 ID와 revision만 받아 의도 계획을 실행하고, 자유 입력이나 LLM에 의한 상태 변경은 허용하지 않습니다.

최종 브라우저 확인: 384×824에서 ‘손전등을 켜고 정비 복도로 이동한다’ → ‘옆쪽 역무실로 돌아간다’를 실제 서버로 실행했습니다. 조명 전환과 통과한 문, 도착한 구역을 본문에서 확인했습니다. 이전 장면을 포함한 10개 본문 블록이 유지됐고 새 문단의 상단은 56px, 화면 너비와 문서 너비는 모두 384px였습니다. 선택지는 이동 후 5개·귀환 후 4개였고 브라우저 오류 로그는 없었습니다.

## 후속 변경 검증

- 모든 새 탐색 장면에 기존 타이핑 효과와 장면별 `LLM 생성` / `기본 서사` 표시를 연결했습니다.
- 철문 잠금 → 바닥 관찰 → 열쇠 발견·수집 → 잠금 해제 흐름을 실제 Gemini와 384×824 브라우저에서 확인했습니다. 열쇠 획득 칩은 `+1 철문 열쇠`로 표시됩니다.
- 상태 정리는 기본 선택지에서 제거했습니다. 완료한 탐색으로 개수를 채우지 않고 가능한 행동을 최대 5개 제공합니다.
- 최종 텍스트 월드·편집기 테스트 26개와 빌드가 통과했습니다. 타이핑·본문 연속성·출처 표시는 관련 테스트 13개로 확인했습니다.
