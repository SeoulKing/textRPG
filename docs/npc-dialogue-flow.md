# NPC 대화의 한 번 생성과 결과 연결

NPC 반응과 다음 답변을 별도로 생성하던 두 요청을 dialogue_turn 한 번으로 묶었다. 응답은 situation, dialogue, 그리고 label·thought를 가진 세 choices로 구성된다. 선택 ID와 턴 번호는 서버에서 부여하고 검증한다.

## 선택 직후와 결과

대화 시작·답변·종료 모두 이전 본문과 선택한 줄을 유지하고 짧은 속말을 표시한다. 최소 500ms 대기와 중복 입력 잠금을 지킨다. 응답이 도착하면 실제 선택한 말과 NPC 반응을 본문에 이어 붙이고 한 번 스크롤한다. 오래된 스냅샷에 postChoiceNarrative가 남아 있어도 NPC 대화에서는 출력하지 않는다. 실패 시 이전 읽기 상태와 선택을 복구하며 자동 재요청하지 않는다.

속말은 입 밖에 한 대사로 취급하지 않는다. 다음 요청에는 선택한 대화 의도와 이미 표시한 속말만 전달한다. 상황 문단에서 실제 말이 전달된 흐름을 이어 쓰고, NPC의 대사는 별도 문단으로 보여 준다.

대화 종료는 생성 요청 없이 서버가 확정한 짧은 결과를 저장한다. 재조회와 새로고침에도 이 문장을 유지하고 다음 행동에서 정리한다. 종료 후 탐색과 재대화 선택을 정상적으로 제공한다. 대화의 게임 내 시간·돈·기력 비용은 기존처럼 없다. 화면의 대기 시간은 가상 세계 시간을 소비하지 않는다.

## 호출과 부분 실패

- 정상적인 시작·답변: 요청 한 번.
- 서비스 오류, JSON 또는 본문 오류: 요청 한 번 뒤 전체 기본 응답.
- 본문은 유효하고 선택지가 잘못됨: 본문은 유지하고 선택지만 기본값으로 보완.
- 속말만 잘못됨: 해당 속말만 기본값으로 보완.
- 대화 종료, 상태 조회, 저장 복원: 대화 생성 요청 없음.

잘못된 NPC 본문에 생성된 후속 선택지를 붙이지 않는다. 본문이 무효이면 세 선택도 같은 기본 장면에 맞춘다. replySource와 각 thoughtSource를 따로 저장하므로 부분 실패가 있을 때 본문 출처를 잘못 표시하지 않는다.

## 기억과 인물 데이터

기존 대화 저장의 방문 횟수·교환 기록·현재 선택 ID를 보존한다. 과거 선택에 미리 쓴 행동 문단은 모델의 사실 문맥에서 제외한다. 최근 여덟 대화의 선택 의도와 실제 NPC 반응을 기억하며, 새 교환은 선행 서사를 저장하지 않는다.

인물 프로필도 미리 실행한 동작 문장 대신 현재 알 수 있는 배치·휴대 사물을 visibleDetails로 작성한다. NPC의 성격·말투·지식 범위는 유지한다. 모델은 대화를 통해 아이템 지급, 거래, 피해, 회복, 퀘스트 완료 등 게임 상태 변화를 선언할 수 없다.

## 확인한 범위

NPC 서비스 테스트에서 대화 시작·답변·종료·재방문, 비용 유지, 과거 턴 거부, 저장 복원을 확인했다. HTTP 호출 계약 테스트는 실제 Gemini 어댑터의 fetch를 모의 응답으로 바꾸어 한 요청에 본문과 선택지가 포함됨을 확인한다. 네트워크 오류, 무효 본문, 무효·중복 선택, 잘못된 속말, 구버전 저장도 검사했다.

클라이언트 검증은 탐색과 NPC 대화 각각에 대해 본문 유지, 최소 대기, 중복 클릭, 느린 응답, 실패 복구, 선행 서사 미표시를 확인한다. 별도의 384×824 인메모리 브라우저에서도 대화 시작과 답변에서 이전 글·선택한 줄·속말을 유지하고, 결과를 새 본문 블록으로 추가하는 흐름을 확인한다.

실제 Gemini 호출과 사용자 저장을 사용하지 않는다. 모델이 실제로 작성하는 문체와 자연어 충실도는 이 모의 검증으로 입증하지 않는다. 지하철 심층 탐험에는 별도의 선행 서사 경로가 남아 있어 후속 점검 대상이다.


모바일 검증에서는 시작 → 질문 → 종료 세 행동이 네 본문 블록으로 이어졌고, 생성기는 시작과 질문에 각 한 번씩 총 두 번 호출됐다. 384×824에서 가로 넘침과 콘솔 오류가 없었다. 브라우저의 생성 표시는 공급자 경로를 모의한 응답의 출처를 의미하며 실제 Gemini 요청을 보낸 것은 아니다.

격리 브라우저의 인증 응답에는 저장 슬롯 정보가 없어 새로고침 뒤에는 홈 화면으로 돌아온다. 이번 UI 확인은 실행 중인 대화 흐름에 한정했다. 종료 문장의 저장·재조회·재방문은 NPC 서비스 테스트에서 별도로 확인했다.
