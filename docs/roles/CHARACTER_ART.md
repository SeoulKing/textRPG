# 캐릭터 아트 담당

캐릭터의 확정 외형, 방향별 파츠, PixelPen 원본과 애니메이션 제작 기준을 이 문서에서 관리합니다. 공통 작업·검증 선택은 [AGENTS.md](../../AGENTS.md), 게임 연결은 [개발 담당](DEVELOPMENT.md), 공간 투영은 [월드 제작 담당](WORLD_BUILDING.md)을 따릅니다.

## 확정 캐릭터 · 하이브리드 버전 1

2026-11-05 사용자 지시로 현재 조립 캐릭터의 외형을 **하이브리드 버전 1**로 확정했습니다. 가느다란 3등신, 백발에 가까운 연보라 단발, 보라색 눈, 크림색 셔츠와 갈색 가죽, 붉은 골반 장식, 크림색 커프의 부츠를 유지합니다. 과거 드레스·숄·Blender 후보·전신 시트는 현행 디자인 기준이 아닙니다.

96×136은 전신 제작 캔버스이며 파츠 자체의 불투명 영역 크기가 아닙니다. 방향은 S·SE·E·NE·N·NW·W·SW 이름으로 연결하고 입력 시트의 배열 순서를 추측하지 않습니다.

- `heads/`: 8방향 머리. 목 연결점과 얼굴·턱·눈높이·머리 부피를 유지합니다.
- `upper-body/`, `rigs/upper-body/`: **팔과 몸통을 나누지 않은 한 장**을 Polygon2D와 Skeleton2D로 변형합니다. 저장된 UV·가중치와 수동 편집을 보존합니다.
- `pelvis/`: 골반 의상과 벨트. 조립용 상체 사본에서만 중복 벨트를 가립니다.
- `legs/`, `rigs/legs/`: 사용자가 보낸 전체 다리 이미지를 유지한 한 장의 Polygon2D입니다. 허벅지·정강이 두 뼈로 움직이며 그림을 두 조각으로 자르거나 다시 그리지 않습니다. 원본 RGBA를 보존합니다.
- `boots/`: 한 이미지에 한 발만 넣습니다. **동쪽 신발은 서쪽 원본의 정확한 좌우 반전**입니다. 발목·커프·실제 밑창 기준을 등록하고 양쪽 발에 따로 붙입니다.
- `hands/`: 현재 조립에 필요한 작은 손입니다. 연결부를 숨기려고 손·소매 전체를 키우지 않습니다.

현재 디자인 확정과 동작의 체감 검수는 별개입니다. 이동은 공통 3D 동작과 조립 보정값을 사용합니다. 전용 걷기·시전·앉기·낚시 완성 클립이 모두 만들어졌다고 간주하지 않습니다. 본편의 절차 포즈 호환과 사용자 플레이 확인을 구별합니다.

## 달리기 키프레임 수정과 저장

[달리기 편집 씬](../../godot-arcana/scenes/characters/hybrid-v1/run-keyframes.tscn)을 Godot에서 여세요. 외부 [run-keyframes.tres](../../godot-arcana/art/characters/hybrid-v1/run-keyframes.tres)를 편집기의 AnimationPlayer와 본편이 함께 읽습니다. JSON을 직접 고치거나 방향별 애니메이션을 따로 만들 필요가 없습니다.

1. 씬 트리의 **AnimationPlayer**를 선택하고, 아래 애니메이션 패널에서 **run**을 선택합니다. 재생 중이면 먼저 멈춥니다.
2. 시간 눈금을 눌러 고칠 자세를 선택합니다. 현재 한 바퀴는 **0.64초**이며 시작/25%/50%/75%는 **0.00 / 0.16 / 0.32 / 0.48초**입니다. 초기 41개 키를 유지해 현재 동작에서 시작합니다.
3. 씬 트리에서 **Pose → 왼다리_허벅지**, **왼다리_정강이**, **왼팔_상박**, **왼팔_전완** 등 고칠 부위를 선택합니다. 좌우는 캐릭터 기준입니다. **E 회전 도구**로 돌리거나 인스펙터 **Transform → Rotation** 값을 바꾸면 양쪽 미리보기가 갱신됩니다. 숫자는 중립 대비 회전량입니다. 회전 컨트롤의 Position/Scale과 고급 그룹은 유지합니다.
4. 위쪽 **현재 위치 키 기록**을 누릅니다. 현재 타임라인 시점의 자세를 키로 기록하며 `Ctrl+Z`로 되돌릴 수 있습니다. 특정 부위만 기록하려면 인스펙터 Rotation 옆의 **🔑**를 사용합니다. **자세를 돌린 뒤 키를 넣지 않으면 달리기 키에는 반영되지 않습니다.**
5. 0초 자세를 바꿨다면 **0초→끝 복사**로 0.64초 끝 자세도 맞춥니다. 이 작업도 `Ctrl+Z`를 지원합니다.
6. **Ctrl+S** 또는 위쪽 **달리기 저장**을 누릅니다. 이 씬에서는 저장 플러그인이 외부 달리기 파일도 함께 저장합니다. 미리보기 아래에 저장 완료 문구가 표시됩니다.

애니메이션 패널의 ▶로 연결을 확인하거나 **F6**으로 편집 씬만 재생할 수 있습니다. **본편을 중지하고 F5로 다시 실행**하면 저장된 달리기를 8방향이 함께 사용합니다. 웹 실행본은 수정 완료 후 `scripts/build-godot-arcana.ps1`로 다시 내보내야 바뀝니다.

미리보기에는 본편과 같은 관절·소매·접지 보정을 적용합니다. 트랙 이름·등록된 21개 채널·루프 설정을 유지하고 키의 회전과 시간만 다듬으세요. 전체 상하 움직임은 `전체_이동`의 Position으로 편집하며, 접지 보정 때문에 최종 발 높이는 단순 이동값과 다를 수 있습니다. 중립 자세는 편집한 0초나 RESET에서 다시 만들지 않습니다.

씬과 키 라이브러리 생성 도구는 **최초 생성 전용**입니다. 파일이 있으면 사용자 편집본을 보존합니다. Ctrl+S 저장 연결은 [편집기 플러그인의 외부 데이터 저장 API](https://docs.godotengine.org/en/4.5/classes/class_editorplugin.html#class-editorplugin-private-method-save-external-data)를 사용합니다.

## 방향별 일관성 제작 계약

**어느 방향에서도 같은 몸·얼굴·옷으로 보이게 합니다.** 같은 팔레트를 썼다는 사실만으로 같은 재질이 되는 것은 아닙니다. 같은 색들의 면적 배분과 명암 위치도 비교합니다.

| 고정할 것 | 방향·자세에 따라 달라질 수 있는 것 |
| --- | --- |
| 관절 이름·부모·길이와 목·어깨·허리·무릎·발목 연결 | 투영된 길이, 관절 각도, 자연스러운 부분 가림 |
| 목깃·어깨선·허리·옷단·커프·장식의 실제 구조 | 옆에서 좁아지는 폭, 뒤에서 가려지는 장식, 주름 |
| 얼굴형·턱·눈매·눈높이·앞머리와 뒤통수 부피 | 얼굴이 보이는 범위, 목·어깨와 함께 움직이는 자세 |
| 재질별 기본색·그림자·강조색·잉크색 | 빛을 받는 면과 그림자의 면적 |
| 원본·출력 경로, 레이어, 피벗, 등록 축척과 버전 | 동작에 따른 외접 사각형과 접촉 위치 |

모든 방향의 그림 폭·불투명 면적·색 비율을 똑같이 강제하지 않습니다. 옷의 실제 치수와 연결점을 고정하고 방향에 맞는 실루엣을 그립니다. 크기가 다르면 그림·피벗·배율 문제를 먼저 분리하고 전체 이미지를 늘여 맞추지 않습니다.

재질별 허용 RGBA와 기본/그림자/강조 역할을 기록합니다. PixelPen에서 원단·테두리·금속 등 재질 레이어를 구분하고 출력할 때 필요한 파츠로 합칩니다. 재질 ID 마스크를 사용한다면 화면 색과 구별하고 같은 캔버스로 등록합니다. RGB만으로 재질을 추정한 마스크는 시각 검수가 필요합니다.

작업 입력은 항상 같은 확정 묶음·같은 카메라·관절 투영 가이드·수정 대상입니다. 직전 생성 결과만 계속 참조하는 연쇄 생성을 피합니다. 정면·측면·후면을 먼저 맞춘 뒤 대각선을 연결하며 특히 W↔NW↔N에서 의상색·소매·옷단·머리 크기를 봅니다.

## 선명한 픽셀 마감

### 한 줄 외곽선

캐릭터마다 짙은 잉크색 하나로 최종 도트 원본의 **한 픽셀** 두께를 연속되게 읽히도록 그립니다. 회색·갈색 중간색 띠로 선을 감싸지 않습니다. 곡선의 계단 길이를 점진적으로 조절하고 돌출·겹선·두꺼운 모서리를 정리합니다. 2×2 영역이나 검은 픽셀 개수만으로 모서리·접합부를 자동 삭제하지 않습니다.

`#`는 같은 잉크색, `.`은 빈 칸입니다.

```text
정돈된 한 줄    겹쳐 두꺼워진 선
..####..      ..####..
.#....#.      .######.
#......#      ###..###
#......#      ##....##
.#....#.      .######.
..####..      ..####..
```

머리·얼굴·소매·손·골반·다리는 명도와 재질 그림자로 구분하며 모든 부위에 검은 테두리를 중복하지 않습니다. 눈·속눈썹·입·접촉 그림자는 필요한 내부 정보입니다. 짙은 색이라는 이유로 지우지 않습니다. 연결부에 띠·고리·진한 단면선 같은 접합 표시를 그리지 않고 안쪽까지 같은 재질을 채웁니다.

**하이브리드 버전 1은 원본 그림의 윤곽을 사용하므로 표시 단계에서 두 번째 외곽선을 추가하지 않습니다.** 과거 합성 실루엣 셰이더 경로를 새 원본에 중복 적용하지 않습니다. 실제 의상의 목깃·커프·장식은 보존합니다.

### 색 덩어리와 명암

재질당 기본색·그림자·밝은색 세 단계에서 시작하고 필요한 색만 추가합니다. 머리카락은 큰 묶음으로, 주름은 천이 접히는 면으로 그립니다. 비슷한 색을 합치기 전에 얼굴·머리·피부·옷이 구분되는지 봅니다. 눈빛·단추처럼 읽힘에 필요한 한 픽셀은 남기고 의미 없는 잡음만 정리합니다.

`B` 기본색, `H` 밝은색, `S` 그림자입니다.

```text
연결된 색 덩어리    흩어진 색 잡음
HHBBBB           HBHBSB
HHBBBB           BHBHBS
BBBBSS           SBBSBH
BBBSSS           BSHBSB
```

광원 방향을 머리·상체·골반·부츠에 일관되게 적용합니다. 외곽에서 안으로 기계적으로 밝아지는 베개 명암과 외곽선을 평행하게 따라가는 밴딩을 피합니다. 명도 구분을 유지하면서 필요한 만큼 빛·그림자의 색온도를 달리합니다.

자동 안티앨리어싱·블러·스머지·부드러운 브러시·Lanczos/Bilinear 축소를 최종 도트에 사용하지 않습니다. 이 화풍의 외곽선에는 수동 안티앨리어싱도 넣지 않습니다. 디더링은 기본적으로 생략하고 깨끗한 면을 우선합니다. 완성 도트의 표시는 최근접 정수 확대를 사용합니다.

`a/b/c`는 불필요한 중간색, `.`은 투명입니다.

```text
깨끗한 경계    중간색 띠가 둘러진 경계
....#BBB      ..ab#cBB
....#BBB      ..ab#cBB
....#BBB      ..ab#cBB
```

새 도트의 알파는 0/255를 기준으로 합니다. 다만 **사용자가 전체 원본 그대로 쓰도록 지정한 현재 다리**의 기존 RGBA를 이 규칙을 이유로 일괄 변환하지 않습니다. 현재 원본의 보존 계약과 신규 도트 제작 규격을 구별합니다.

## PixelPen 제작과 저장

목표 해상도·비례 → 실루엣 → 선 정리 → 재질 기본색 → 명암 덩어리 → 얼굴·주요 장식 → 픽셀 마감 순으로 작업합니다. 큰 그림의 축소·색 변환·자동 테두리만으로 완성 판정을 하지 않습니다.

수정은 확정 원본의 후보 사본에서 시작합니다. **`.pxpen` 저장 → 같은 파일 재열기 → 투명 PNG 출력**을 따릅니다. 헤드리스 작업도 같은 원본과 절차를 사용합니다. 원본 레이어·프레임·출력 매핑과 피벗을 기록하고 생성기를 다시 실행해 사용자 수동 도트·UV·가중치를 덮어쓰지 않습니다. 저장 성공과 시각 완성도를 별도로 판단합니다.

### 새 동작의 PixelPen 일관성 보정

1. 준비·주동작·회복, 지지 발, 손·가구 접촉, 진입·복귀를 먼저 정합니다. 프레임 수보다 자세의 타당성을 봅니다.
2. 같은 방향의 기준에서 핵심 자세를 만들고 머리·목·어깨·몸통을 함께 맞춥니다. 다른 방향의 몸을 가로로 잘라 합치지 않습니다.
3. 필요한 중간 자세만 추가하고 접지·회수·체중 이동·반대팔을 연결합니다. 발 미끄러짐을 숨기려고 실제 이동 속도를 바꾸지 않습니다.
4. 새 그림·프레임은 PixelPen에서 확정 캐릭터에 맞춰 팔레트·선·픽셀 밀도·관절 틈·가림·여분 손발을 반드시 보정합니다. 기존 그림을 쓰는 리그 보정만으로 새 프레임을 제작했다고 보고하지 않습니다.
5. 같은 방향·배율의 기준/후보와 대기→동작→대기를 비교하고 실제 수정 범위를 기록합니다. 필요한 PixelPen 보정이 불가능했다면 미완료로 남깁니다.

빠른 공격의 검기·잔상·불티는 별도 효과로 만듭니다. 캐릭터 자세와 효과의 시작·최대·소멸, 실제 발사·타격 시점을 맞추되 효과 제작만을 이유로 캐릭터 시트나 확정 외형을 바꾸지 않습니다. 순간 소멸은 표시 계층에서 숨겼다가 복원합니다.

## 비교와 완료 체크리스트

비교는 같은 카메라·배율·중립 또는 달리기 0/25/50/75% 위상으로 8방향을 봅니다. 전체·개별 파츠·실루엣·재질·연결점과 기준/후보를 비교합니다. 편집기 미리보기는 실제 조립기를 공유하되 자동 이동 없이 설정 변경 때 갱신합니다.

- [ ] 원본 크기와 4배/8배 최근접 확대에서 외곽선·얼굴·부위 구분이 명확합니다.
- [ ] 밝고 어두운 배경에서 흐린 띠·겹선·잔상·불필요한 접합 표시가 없습니다.
- [ ] 방향을 바꿔도 목깃·허리·옷단·커프·머리 부피·얼굴 인상이 이어집니다. 후면에 얼굴·앞 장식이 잘못 보이지 않습니다.
- [ ] 실제 포즈에서 관절 틈·손의 가림·부츠 커프와 다리의 겹침을 확인했습니다.
- [ ] 신규 도트의 부분 알파, 누락 방향, 연결점, 재질 허용색, 원본과 출력 연결을 확인했습니다. 지정 원본의 예외는 별도로 기록합니다.
- [ ] 팔레트 슬롯 수·실제 사용 불투명색 수·투명색을 따로 보고합니다.
- [ ] PixelPen 저장·재열기·PNG 출력을 확인하고 기존 수동 원본을 보존했습니다.
- [ ] 구조 확인·시각 검토·사용자 미술 승인·게임 연결·실제 플레이 확인을 구분했습니다.

검사기는 수치와 누락을 찾습니다. 불투명 영역·색 면적 변화는 검토 자료이며 같은 얼굴인지, 미술적으로 완성됐는지 자동 판정하지 않습니다. 게임·테스트 실행은 [공통 검증 원칙](../../AGENTS.md#검증-선택)에 따릅니다.

## 출처와 화풍의 선택

아래 원문은 제작 원리의 근거입니다. 한 잉크색 외곽선·외곽 안티앨리어싱 배제·디더링 생략은 이번 사용자가 선택한 스타일이며 모든 픽셀아트의 보편적 금지가 아닙니다.

- [Derek Yu · Basics](https://derekyu.com/makegames/pixelart.html): 한 픽셀 선, 곡선 계단, 큰 명암과 투명 외곽의 처리.
- [Derek Yu · Common Mistakes](https://derekyu.com/makegames/pixelart2.html): 비슷한 색의 과다 사용과 베개 명암.
- [Saint11 · Cluster Sketching and Painting](https://saint11.art/pixel_art_articles/article2/): 큰 색 덩어리에서 형태를 정리하는 과정.
- [Saint11 · Anti-Alias and Banding](https://saint11.art/pixel_art_articles/article5/): 흐림·밴딩·가독성.
- [Saint11 · Basic Color Theory](https://saint11.art/pixel_art_articles/article6/): 명도·채도와 빛·그림자의 색상 변화.
- [Radical Fish · 개발 글](https://www.radicalfishgames.com/?p=7410): 뼈 방향과 시점에 따른 파츠 표시·회전·교체. 이를 현재 그림의 미술적 정합성을 대신하는 근거로 사용하지 않습니다.

새 인물의 초상화는 대상 인물의 승인 이미지를 동일 인물 참조로, 다른 인물의 그림은 화풍 참조로 구별합니다. 뚜렷한 선화와 면 중심 셀 채색을 유지하고 사진 같은 피부 묘사를 섞지 않습니다. 폐허 서울 전용 노파·슈미의 상세 명세는 별도 [seoul-survival 프로젝트](../../../seoul-survival/README.md)에서 관리합니다.
