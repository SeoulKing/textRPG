# 휴대 상태와 관심의 분리

물건을 소유하고 지닌 상태, 실제 손에 든 상태, 지금 조작에 관심을 둔 상태를 구분한다. 특정 물건을 든 채 다른 사물을 관찰해도 MANIPULATE로 되돌아가지 않는다.

## 플레이 흐름

- TAKE는 방의 물건을 획득하고 손에 든다. 묶음 수집 도중 손을 바꿔야 하면 앞서 집은 물건을 챙겨 두는 STOW도 실행한다. 수집 후에는 마지막 물건을 놓거나 챙겨 두는 선택을 할 수 있다.
- MOVE·FOCUS·INSPECT·DEFOCUS는 관심을 바꾸며, 휴대 물건 자체를 내려놓거나 소모하지 않는다. 다른 대상에 집중하는 동안 물건 배치 선택은 숨긴다.
- HOLD는 이미 지닌 물건을 꺼내 들거나 고쳐 쥐는 행동이다. 새 획득을 지급하지 않는다. 적절한 보관함·지지면을 보고 있을 때 꺼내 드는 선택 하나를 제공하고, 그 뒤 실제 배치 선택을 제공한다.
- STOW는 손을 비우고 물건의 소유·수량을 유지한다. PUT·DROP으로 물건을 방에 남기면 인벤토리에서 해당 수량을 뺀다. 지닌 용기 안에 담는 PUT은 소유권을 유지한다. 방에 남긴 물건을 다시 수집하면 그만큼만 되돌린다.
- 자원 작업과 편의점의 기존 재고 묶음 수집은 기존 비용·보상 계약대로 소지품에 챙긴다. 물리 사본은 보관 상태이며, 별도 HOLD로 꺼내 조작할 수 있다.

선택지는 기존 표형 화면과 optionId + revision API를 사용한다. HOLD/STOW는 같은 조작 계열로 묶고, 조작을 마칠 때 ‘챙겨 둔다’를 제공한다. 주변 탐색 중에 이 계열이 조명 사용이나 실제 귀환 경로를 밀어내지 않도록 한다. 상태 재정리와 반복 관찰로 개수를 채우지 않는다.

## 엔진 계약

`components.position.zone = player`는 소유 관계다. `heldToolId`는 조명, `heldItemId`는 다른 손에 든 물건을 가리킨다. 다른 손에는 교체 중인 두 번째 조명도 있을 수 있다. `manipulating`과 현재 관심 대상이 실제 다루는 물건을 정한다.

물건 교체에는 필요한 손을 비우는 실제 STOW가 선행된다. 광원 교체는 기존 조명을 유지한 채 빈손으로 새 조명을 들어 어둠 때문에 교체 자체가 막히지 않도록 한다. 양손이 차 있으면 다른 손의 물건부터 챙겨 둔다. 손에 든 조명을 보관하면 불을 끈다.

TAKE 3초, HOLD 2초, STOW 2초이며 켜진 조명을 끄고 보관하는 데는 1초를 더 사용한다. 예를 들어 역무실의 물병과 고철 수집은 TAKE → STOW → TAKE로 8초다. 공통 게임 시간이 각 실제 단계에 흐르므로 보관 도중 문이 닫히면 이후 수집은 중단된다. 이미 보관한 물건은 유지하고 미수행 획득은 지급하지 않는다.

기존 저장의 동일한 조명을 가리키는 중복 손 참조는 하나로 보완한다. 두 개의 실제 조명은 서로 다른 물건으로 보존한다. 소비된 물건의 손 참조와 조작 상태를 정리하며, 지역 이동은 보관 물건과 손에 든 물건을 함께 옮기되 인벤토리를 재지급하지 않는다.

## 서술과 조회

결과 이벤트에 HOLD/STOW와 실제 전후 상태를 기록한다. 지각 정보는 held·carried·stowed를 구분하며, LLM이 보관을 새 획득이나 바닥에 버리기로 바꾸지 않도록 안내한다. 기본 서사와 짧은 독백도 같은 구분을 사용한다. 별도 생성 호출은 추가하지 않는다.

선택지의 상황 서명에서는 생략된 미확인 값과 false를 같은 상태로 취급한다. 저장 보완과 반복 조회로 선택이 바뀌거나 화면의 선택 ID가 거절되던 문제를 방지한다.

## 확인한 범위

신규 휴대 테스트 9건으로 묶음 수집·보관·재조작·소비·저장·지역 이동·광원 교체·시간 경과 중 실패를 확인했다. 기존 선택지 8건과 물리 시뮬레이션 17건, 지하철·편의점·숲·강의 관련 경로, 실제 선택 목록으로 진행하는 수집 → 제작 → 요리 → 식사 경로를 함께 검사했다. 발견·필수 사실·실패 서술·조회 안정성과 행동당 한 번의 서술 요청 계약도 확인했다.

TypeScript 빌드를 통과했다. 실제 Gemini 호출은 사용하지 않았다. 화면 구조나 대기·타이핑 코드를 변경하지 않아 이번 단계의 검증은 엔진·서비스·서술 계약에 한정했다.
