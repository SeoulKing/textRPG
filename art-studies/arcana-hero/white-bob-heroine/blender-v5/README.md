# V5 · 승인 시안 기반 얼굴과 머리카락 원본

승인한 백발 단발 시안의 얼굴과 머리카락부터 제작한 별도 Blender 원본입니다. `approved-concept.png`는 사용자 승인 이미지이고 `review/`는 실제 모델의 Blender 출력입니다. 둘의 품질·승인 상태를 혼동하지 않습니다. 게임에 적용하지 않았습니다.

## 편집 원본

- `heroine-v5-head.blend`: 새 얼굴 메시, 실제 눈 구멍·곡면 안구·홍채·눈꺼풀·속눈썹·귀·목, 개별 머리카락 메시와 가는 곡선, 옷깃/숄의 잘린 흉상, 패킹한 UV 텍스처와 카메라.
- `textures/`: 직접 작성한 피부·홍채·머리카락 페인트 PNG. 승인 그림을 얼굴 평면에 붙인 방식이 아닙니다.
- `hair-lock-authoring.json`: 각 큰 머리카락의 제작 경로와 폭. 최초 제작 레시피를 위한 자료이며 이후 수동 조형은 .blend가 원본입니다.
- `model-inspection.json`: 저장 원본에서 읽은 메시 목록. 메시 수는 미적 완성도 지표가 아닙니다.

V4 얼굴/머리의 크기만 조절한 결과를 재사용하지 않고 새로 조형했습니다. 보존된 V3/V4, 다른 대화의 스프라이트와 공유 Godot/Web 파일을 변경하지 않았습니다. 전신 모델·표정 리그·보행 동작은 이 흉상의 완료 범위에 포함하지 않습니다.

## 비교 자료

- `review/reference-vs-model.png`: 승인 시안과 실제 모델 사선의 나란한 비교. 시안은 고개를 기울인 일러스트이며 모델은 중립 자세이므로 동일 포즈/픽셀 일치라고 주장하지 않습니다.
- `review/model-angles.png`: 같은 메시의 정면·사선·측면과 재질을 제거한 회색 입체 렌더.
- `review/head-turntable.gif`: 같은 모델 전체를 회전시킨 24프레임 출력. 생성 이미지를 회전 영상으로 바꾼 결과가 아닙니다.

중점 수정은 턱의 뒤쪽 후퇴와 목 비례, 상부 두상의 노출, 단발의 큰 흐름, 오른쪽 귀를 드러내는 머리카락 배치, 눈꺼풀 기울기와 작은 홍채, 입술과 코 부피입니다. 모델의 형태 확인과 시안 외형의 최종 사용자 승인은 별개입니다. 시안의 섬세한 붓결과 잔머리, 머리끝의 가벼운 흐름은 여전히 비교해야 하는 미술 항목입니다. 모든 머리카락 선을 도트 해상도에서 유지한다고 가정하지 않습니다.

## 수동 편집과 재출력

Blender 4.5.15 LTS로 열 수 있습니다. 객체 이름별로 얼굴·눈·머리카락을 독립 편집하며, 승인 이미지는 편집기용 이미지 Empty로 들어 있고 렌더에는 나오지 않습니다. 머리와 얼굴이 -Y를 보고 +Z가 위쪽입니다. 턱 Z=0을 기준으로 한 독립 제작 단위이며 게임 규격/좌표를 바꾸지 않습니다.

저장한 원본에서 검토 화면만 다시 출력합니다. 이 과정은 원본을 저장하거나 재생성하지 않습니다.

```powershell
pwsh -NoProfile -File scripts/run-blender-heroine-v5.ps1 -Script scripts/blender/review_heroine_v5_head.py
python scripts/package-heroine-v5-review.py
```

`build_heroine_v5_head.py`는 최초 제작 레시피입니다. 기존 .blend가 있으면 중단합니다. 명시적 `-RebuildCandidate`는 원본을 새로 만들므로 수동 수정 이후에는 사용하지 않습니다. 오프라인 미술 렌더만 수행했으며 게임 가져오기·웹 배포·브라우저 조작·자동 플레이는 수행하지 않았습니다.
