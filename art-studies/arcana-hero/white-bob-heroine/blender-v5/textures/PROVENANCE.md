# 머릿결 UV 알베도 제작 기록

pearl-hair-atlas-v1.png는 imagegen 내장 도구로 생성한 실제 3D 머리카락용 알베도입니다. 승인 원화 approved-concept.png는 색감과 붓결 참고로 전달했습니다. 원본 생성 이미지는 편집 없이 보존하고 Blender의 UV 영역과 재질 혼합으로 대비를 조정했습니다.

요청 요약: 네 개의 세로 UV 영역, 위쪽 뿌리/아래쪽 끝, 진주백색과 연한 회보랏빛, 섬세하게 흐르는 셀 채색 머릿결, 얼굴/몸/소품/문자 없는 불투명 텍스처. 출력은 1254×1254입니다. 그 자체는 모델 렌더가 아닙니다.

최종 모델에서 각각의 입체 조형에 한 영역의 일부를 연결하고 흰색 혼합을58% 적용했습니다. 그림 한 장으로 캐릭터를 대체하지 않았습니다. 피부/눈의 원본 텍스처 출처와 수정 내용은 상위 README 및 reference-topology/source-metadata.json을 따릅니다.
