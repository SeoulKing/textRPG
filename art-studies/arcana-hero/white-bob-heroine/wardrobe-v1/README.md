# 백발 주인공 · 레이어 의상 정지 시안 v1

상태: 검토용 후보. 게임 미연결 / 보행 미제작 / 사용자 미술 승인 전.

## 기준과 규격

- 기준: 상위 폴더의 `heroine-pixel-gameplay-target-v1.png`. 원화와 같은 백발 단발, 보랏빛 눈, 하늘색 숄, 상아색 드레스, 남색 리본, 스타킹과 부츠를 사용합니다.
- 64×80 RGBA PNG, 앞·뒤·왼쪽·오른쪽 네 방향. 모든 레이어 원점은 캔버스 좌상단이며 공통 발 기준점은 (32,72)입니다. 원본을 개별적으로 trim하지 않습니다.
- `preview.html`을 이 폴더 안에서 여시면 의상을 바꿔 볼 수 있습니다. 서버와 추가 설치가 필요하지 않습니다. 이 미리보기는 게임의 착용 UI가 아닙니다.
- 이 시안의 색은 원화에서 정리한 32색 후보 팔레트입니다. 월드의 64색 후처리를 거치지 않았으며 게임 배경과의 최종 미술 검수는 후속 범위입니다.
- 원화의 작은 자수는 축약했습니다. 뒷면에는 얼굴을 그리지 않고 좌우는 별도 생성된 측면을 사용했습니다.

## 조립 계약

1. 의상 선택에서 점유 부위가 겹치면 거부합니다. `dress`는 `top`과 `bottom`을 모두 점유하며, 블라우스 또는 치마와 동시에 입지 않습니다. 숄은 `shoulders`, 신발은 `feet`, 머리는 `hair`를 점유합니다.
2. 공통 몸체를 복사하고 선택한 의상들의 `bodyOcclusion` 마스크를 합쳐 **몸체에만** 적용합니다. 흰색 불투명 픽셀은 몸체를 지웁니다. 마스크로 다른 의상이나 머리를 지우지 않습니다.
3. 가려진 몸체 → 신발 → 치마 → 드레스 → 블라우스 → 숄 → 머리 순서로 원점 (0,0)에 합성합니다. 선택하지 않은 항목은 건너뜁니다. 목·손과 치마 아래 스타킹은 남기고, 가려지는 속옷과 다리는 숨깁니다.
4. 원본 캔버스 64×80과 방향을 그대로 사용하고 최근접 정수 확대를 적용합니다. 신발 교체로 발 기준점을 바꾸거나 방향별 부품을 따로 가운데 정렬하지 않습니다.

머리와 숄은 이번 정지 자세에서 앞·뒤 조각 분리가 필요하지 않아 각각 하나의 투명 오버레이입니다. 머리 레이어에는 얼굴·몸을 포함하지 않으며 얼굴은 몸체에 남겨 둡니다. 공통 몸체는 노출 없는 회색 내의와 스타킹 상태입니다.

## 제작과 확인

- **내장 image_gen**으로 원화를 참조한 분리 부품 원본을 생성했습니다. 전체 프롬프트는 `source/prompt.txt`에 보관했습니다.
- 생성 시트는 등록 좌표가 맞지 않았으므로 원본 자체를 실사용 시트로 간주하지 않습니다. `scripts/build-heroine-wardrobe.cjs`가 부품 추출, 작은 배경 조각·색 테두리 제거, 최근접 크기 맞춤, 팔레트와 알파 정리를 수행합니다. 창작 원본을 코드로 대체해 그리지 않습니다.
- 좌우 머리의 얼굴 구멍이 몸체와 어긋난 것을 조립 화면에서 확인하고 방향별 수평 등록값을 조정했습니다. 모든 방향에 같은 기본 몸체를 사용하므로 의상 교체 시 몸의 비례는 유지됩니다.
- 준비 과정에서 32개 레이어의 64×80 규격과 알파 0/255, 24개 조합의 여백·잘림·발 기준을 확인했습니다. 정지 비교판을 열어 머리와 옷의 겹침, 숄 제거, 신발 교체 결과를 시각 확인했습니다.
- 게임 코드, 착용 UI, 진행·저장 데이터, 기존 모델 및 게임 연결은 변경하지 않았습니다. 게임 빌드·자동 테스트·브라우저 조작은 실행하지 않았습니다.

다시 준비할 때는 저장소 루트에서 `node scripts/build-heroine-wardrobe.cjs`를 실행합니다. 저장소에 이미 있는 sharp를 사용하며 이미지 생성 API를 다시 호출하지 않습니다. HTML과 이 문서는 수동 작성한 설명 자료입니다.

## 다음 제작 시 주의

- 네 방향 정지 자세 전용입니다. 걷기에서는 손·치마·숄의 앞뒤 관계가 달라지므로 프레임마다 가림 정보와 레이어 분리를 다시 작성해야 합니다.
- 몸체 가림은 현재 긴소매·미디 길이 의상에 맞춘 템플릿입니다. 짧은 치마·반소매·긴 코트에 그대로 사용하면 몸체가 잘릴 수 있으므로 해당 의상의 가림 마스크를 새로 만드셔야 합니다.
- 의상마다 자체 외곽과 내부선을 포함합니다. 조합 위에 부품별 외곽선 확장 셰이더를 중복 적용하지 않습니다. 엄격한 월드 외곽선 통일과 실제 배경 가독성은 게임 연결 시 검수합니다.
- 새 옷에도 방향별 그림이 필요합니다. 레이어 분리는 몸과 다른 의상을 재사용하게 해 주며, 모든 신규 의상의 겹침 검수를 없애 주지는 않습니다.
- 최종 외형·미술 승인은 사용자 확인으로 남아 있습니다.
