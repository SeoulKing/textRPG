# Blender V4 · 게임 반영을 보류한 개선 후보

사용자가 3D 적용을 보류하고 별도 대화에서 스프라이트를 진행하므로, 이 폴더는 독립적인 3D 제작 원본과 검토 자료만 담습니다. 현재 게임 캐릭터 선택·공유 런타임·웹 산출물은 이 후보로 교체하지 않았습니다. 미술 최종 승인본이 아닙니다.

## 이번 변경

- 목 뼈와 `CTRL_head_level`을 추가하고, 기존 약 22도 고정 머리 기울기를 제거했습니다. 골반·몸통 움직임과 머리의 중립 방향을 분리했습니다.
- 얼굴과 턱선을 새 메시로 만들고, 곡면 눈·보라색 홍채·속눈썹·볼 색·작은 입을 제작했습니다.
- 단발의 큰 실루엣과 앞머리를 다시 만들었습니다. 옆머리의 넓은 면을 옆으로 향하게 하고 두상 곡면에 맞춰 배치했습니다.
- 얇은 남색 천 리본, 꽃 브로치와 드레스 자수를 보강했습니다. 백발·보라색 눈·하늘색 숄·상아색 드레스의 정체성을 유지했습니다.
- 기존 대기·걷기·달리기·좌우 회전 동작과 분리 의상 원본을 유지했습니다. 표정 애니메이션과 새 전투 동작은 추가하지 않았습니다.

## 검토 결과와 한계

`head-posture-audit.json`은 머리 뼈의 위쪽 축과 세계 수직축 사이 각도를 검사합니다. 기존 Run 최대 기울기는 20.34도였으며, 후보의 5개 동작 총 155개 표본에서 최대 기울기는 0도였습니다. 이는 머리 자세 검사이며 전체 움직임의 미적 완성도를 입증하지는 않습니다.

`run-head-front.gif`와 `run-head-side.gif`는 Blender에서 카메라가 캐릭터를 따라가는 2주기 달리기 출력입니다. 게임 플레이 영상이 아닙니다. `dot-comparison.png`는 30도·45도 카메라의 8방향 원본 크기 비교판입니다. 검토 캔버스는 128×176, 발 기준 (64,148), 64 px/unit이며 기존 게임의 스프라이트 규격을 변경하지 않습니다.

얼굴의 입체감과 표정, 단발 끝의 겹침, 팔·소매와 의상의 변형은 추가 미술 검토 대상입니다. 이 자료를 최종 품질 또는 사용자 승인으로 취급하지 않습니다.

## 파일

- `heroine-v4.blend`: 편집 가능한 메시·리그·5개 동작·패킹된 텍스처·스튜디오 장면
- `textures/`: 얼굴·홍채·머리카락 페인트 원본 PNG
- `review/heroine-v4-review.glb`: 별도 검토용 모델. 게임에 연결하지 않았습니다.
- `beauty-v4.png`, `face-v4.png`: 전신·얼굴 렌더
- `dot-*.png`, `dot-comparison.png`: 작은 화면에서의 방향별 검토
- `motion/`, `run-head-*.gif`: 정면·측면 달리기 원본과 GIF

Blender 원본의 얼굴은 부드러운 발광 혼합 재질을 사용합니다. 검토용 GLB는 휴대성을 위해 얼굴 재질을 발광 텍스처로 단순화하므로 조명 반응이 완전히 같지 않습니다. 기존 V3 전용 셰이더에 그대로 연결해서는 안 됩니다.

## 재출력

프로젝트 루트에서 저장된 Blender 원본을 읽기만 하는 명령입니다.

```powershell
pwsh -NoProfile -File scripts/run-blender-heroine-v4.ps1 -Script scripts/blender/export_heroine_v4.py
pwsh -NoProfile -File scripts/run-blender-heroine-v4.ps1 -Script scripts/blender/review_heroine_v4.py
python scripts/package-heroine-v4-review.py
```

수동 수정은 `heroine-v4.blend`에 저장한 뒤 위 명령으로 검토 출력합니다. 최초 제작 레시피인 `scripts/blender/improve_heroine_v4.py`는 원본이 이미 있으면 중단합니다. `-RebuildCandidate`는 V3부터 다시 제작하여 V4 수동 수정을 덮어쓰므로 의도적으로 재구성할 때만 사용합니다. 기존 V3 원본은 수정하지 않습니다.

브라우저 조작·자동 플레이·Godot 가져오기·웹 내보내기는 이번 독립 후보 제작에서 수행하지 않았습니다.
