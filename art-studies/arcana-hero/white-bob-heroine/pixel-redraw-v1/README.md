# 주인공 정면 도트 재작업 초안

사용자 요청: 기존 컨셉 시안을 기준으로 도트 품질 개선.
기준: white-bob-candidates-v1.png의 2번, heroine-pixel-gameplay-target-v1.png.
유지: 백발 단발, 보라 눈, 하늘색 숄, 상아 드레스, 남색 리본, 짙은 스타킹, 회갈색 부츠.

- front-detailed-draft.png: 첫 생성 결과. 세부 묘사가 많아 작은 게임 스프라이트로 부적합.
- front-coarse-draft.png: 색 덩어리와 장식을 단순화한 두 번째 생성 초안.

두 파일은 이미지 생성 도구 출력이며 PixelPen에서 직접 편집한 원본이 아닙니다.
정확한 96×136 캔버스, 균일 픽셀 격자, 제한 팔레트, 이진 알파는 보장하지 않습니다.
배경의 보라색 후광도 실제 자산 제작 시 제거해야 합니다.
현재 Blender v3 주인공과 런타임·게임 배포는 변경하지 않았습니다.
후속 제작은 원본 크기의 정면 마스터 정리와 실제 표시 배율 비교가 필요합니다.
