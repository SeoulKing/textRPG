# 얼굴 집중 후속 원본

사용자는 V7 결과가 조금씩 가까워지고 있다고 평가하고, **머리카락보다 예쁜 얼굴을 우선**하도록 지정했습니다. 승인된 백발/보랏빛 눈/작은 미소의 인물을 유지하면서 실제 얼굴 메시와 눈 재질만 다듬습니다. 이전 `../heroine-v7-head.blend`는 보존합니다.

현재 편집 원본은 `heroine-face.blend`입니다. 기존 머리카락의 실제 정점/곡선은 그대로이며, 얼굴 수정을 위해 머리카락을 재생성하지 않았습니다. 게임에는 연결하지 않습니다.

## 얼굴 변경

- 측면의 입술을 전진시키고 턱의 돌출을 줄여 코–입–턱의 흐름을 정리했습니다. 실제 얼굴과 윤곽에 같은 2단계 곡면 세분화를 연결하고 눈 구멍의 열린 경계는 크리즈로 고정했습니다.
- 턱 끝의 날카로운 지점을 조금 올리고 아래쪽 윤곽을 둥글게 정리했습니다. 볼은 작은 곡면으로 보강하고 코의 돌출을 줄였으며, 입꼬리와 입의 폭을 미세하게 조정했습니다.
- 피부/눈 주변을 연속된 변형으로 수정했습니다. 얼굴과 외곽선에 같은 변형을 적용하고, `V7 MASTER`의 `face_refinement_weight`가 연결된 쉐이프 키를 함께 조절합니다. 0~1로 조형의 강도를 조정할 수 있습니다. 이 제어는 조형용이며 재질까지 이전 상태로 되돌리는 기능은 아닙니다.
- 홍채 원본과 투명도는 보존하고, 위쪽의 눈꺼풀 그늘과 동공을 실제 UV 좌표에 연결했습니다. 흰자는 약하게 따뜻한 음영으로 조정했습니다.
- 속눈썹/눈썹의 원래 농담과 투명도를 유지했습니다. 눈꺼풀은 연속 곡선으로 두께를 줄이고 부드러운 실제 곡면으로 다듬었습니다. 코의 과도한 흰 반사도 국소 재질에서 줄였습니다.

## 확인 자료

`review/final/`은 저장된 원본을 읽어 출력하는 실제 Blender 렌더입니다. 같은 카메라의 이전 얼굴과 수정 얼굴, 정면/사선/측면과 시안 비교 자세, 재질/머리카락을 숨긴 조형 검토를 제공합니다. 조형 검토에서는 투명도 그림으로 쓰는 눈썹/속눈썹/홍채 판을 회색 사각판으로 채우지 않고 숨겨 실제 얼굴 면과 흰자/귀/뒤통수를 확인합니다. 생성된 초상화를 실제 모델 렌더로 대신하지 않습니다.

`authoring.json`에는 수정 전 원본과 머리카락 정점/곡선의 해시가 있습니다. 이는 원본 보존 기록이며 아름다움이나 미술 승인의 점수가 아닙니다. `review/final/render-evidence.json`은 검토 렌더가 원본을 변경하지 않았는지 기록합니다.

## 편집과 재출력

Blender 4.5.15 LTS용입니다. `heroine-face.blend`에서 직접 수정해 저장한 뒤 아래 명령으로 화면만 출력합니다.

```powershell
pwsh -NoProfile -File scripts/run-blender-heroine-v7.ps1 -Script scripts/blender/review_heroine_face.py
python scripts/package-heroine-face-review.py
```

`refine_heroine_face.py`, `finish_heroine_face_lines.py`, `smooth_heroine_face_lines.py`, `balance_heroine_face_profile.py`, `preserve_heroine_eye_rims.py`는 이번 제작 단계입니다. 일상 재출력에 사용하지 않습니다. `refine`는 기존 파일이 있으면 명시적인 재구성 옵션 없이 덮어쓰지 않고, 후속 단계도 이미 적용된 상태에 재적용하지 않습니다. 직접 편집한 원본이 기준입니다.

`review/*-face-a.png`, `*-face-b.png`, `*-face-c.png`, `*-face-d.png`는 중간 평가입니다. 특히 첫 색상 변경과 점별 눈꺼풀 수축은 과한 선/꺾임 때문에 후속 단계에서 수정했습니다.

기초 얼굴/UV와 머리의 CC0 출처, 보존된 이미지 생성 원본은 상위 README를 따릅니다. 새 래스터 초상화/텍스처 생성이나 게임 런타임/웹 변경, 브라우저/자동 플레이는 이번 작업에 포함하지 않습니다.
