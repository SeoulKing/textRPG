# V7 · 얼굴과 단발의 추가 조형 후보

사용자가 V6 결과와 승인 시안의 큰 차이를 다시 지적했습니다. 승인 시안을 유지하고 독립 Blender 머리 원본을 추가 수정했습니다. **현재도 미승인 후보이며, 원화 수준에 도달한 완성본으로 취급하지 않습니다.** 게임에는 연결하지 않았습니다.

## 얼굴 우선 후속 작업

사용자는 V7이 시안에 조금씩 가까워지고 있다고 평가했으며, 머리카락보다 얼굴의 아름다움을 우선하도록 지정했습니다. 이 기준의 후속 편집 원본은 `face-refinement/heroine-face.blend`와 해당 README입니다. V7 원본은 보존하고 머리카락을 다시 제작하지 않은 상태에서 얼굴/눈 재질을 수정합니다. 게임에는 연결하지 않습니다.

## 실제 변경

- 얼굴의 눈 안쪽/바깥쪽, 눈썹, 입꼬리, 턱선에 대응하는 기준을 잡고 좌우 대칭의 연속 변형으로 실제 메시를 수정했습니다. 비교 카메라는 얼굴보다 약간 높은 위치로 고정해, 아래에서 올려다보는 각도로 비례 차이를 숨기지 않게 했습니다. 좌표 피팅 수치는 미술 승인이나 아름다움의 증거가 아닙니다.
- 기존 V6의 반복된 큰 잎 모양 머리 조형을 교체했습니다. 수정 가능한 CC0 단발의 뒤통수/정수리 토폴로지를 기초로 사용하고, 비대칭 앞머리·옆머리·턱 주변 컬·작은 갈라진 끝을 실제 곡면 메시로 새로 조형했습니다.
- 안쪽 이마 연결 면은 큰 앞머리 아래에 두고, 가까운 귀의 가닥은 귀 뒤로 넣었습니다. 큰 면 위에 머릿결 UV와 회보라색 명암을 연결했습니다. 피부/홍채는 이전의 UV 원본을 유지하며 원화의 눈과 머리 색이 피부 위에 중복되지 않습니다.
- 눈 주변을 공통 연속 변형으로 조금 열고, 바깥 눈꼬리와 눈썹의 기울기를 완화했습니다. 피부/눈꺼풀/흰자/홍채를 같은 변형으로 이동하고 윤곽 껍질을 갱신했습니다. 코의 과한 흰색은 실제 표면의 국소 재질에서 줄였습니다.
- 뒷면에서 얼굴의 입이 비치던 오류를 수정했습니다. 얼굴 표면은 실제 단면 재질로 바꾸고, 뒤통수/목덜미를 곡면 메시로 보강했으며 뒷머리를 그 면 위로 늘렸습니다.
- 머리 원본은 중립 회전입니다. 기울인 고개와 시안 비교 카메라는 검토 렌더에만 적용합니다. 원화 투영을 얼굴/머리에 붙인 초기 실험은 얼룩과 중복 때문에 폐기했으며 현재 모델에 사용하지 않습니다.

## 현재 남은 차이

시안보다 머리의 큰 가닥이 넓고 균일합니다. 붓으로 그린 듯한 불규칙한 하이라이트, 더 가벼운 머리 끝, 눈 아래 윤곽과 표정의 세밀함이 부족합니다. 이 문제는 프레임 수나 장식 개수를 늘려 해결됐다고 보지 않습니다. 목과 의상 흉상은 인상 확인용이며 전신 제작 완료본이 아닙니다.

## 원본과 확인 자료

- `heroine-v7-head.blend`: 현재 편집할 독립 원본. 실제 얼굴/머리 메시, UV, 패킹 이미지와 중립 제어가 있습니다.
- `heroine-v7-seed.blend`: 수정 전의 이번 제작 기초. 일상 작업 중 다시 생성하지 않습니다.
- `native-hair-authoring.json`: 새 앞머리와 컬의 제작 경로. 이후 직접 편집한 `.blend`가 원본입니다.
- `reference-fit.json`: 얼굴 기준점과 실제 조형 변형값. 미술 유사도 점수가 아닙니다.
- `review/portrait-native-v7.png`: 현재 저장 모델의 실제 사선 렌더.
- `review/reference-comparison-v7.png`: 승인 시안 / 거절된 V6 / 이번 V7 비교.
- `review/model-angles-v7.png`, `review/head-turntable-v7.gif`: 같은 저장 모델의 정면·측면·뒤·재질 제거와 회전.
- `review/render-evidence.json`, `delivery.json`: 렌더 원본 해시, 수정 여부, 미승인 상태와 남은 차이.

`review/neutral-fit-*`, `reference-fit-*`, `native-sculpt-*`는 제작 중간 평가이며 최종 결과로 전달하지 않습니다. 특히 초기 원화 투영 실험은 사용하지 않습니다. 위 `native-v7` 자료가 현재 후보입니다.

## 편집과 재출력

Blender 4.5.15 LTS용입니다. 정면 -Y, 위 +Z이며 게임 픽셀 규격의 변경이 아닙니다. `V7 MASTER` / `V7 HEAD POSE` 아래에서 실제 메시를 수정해 저장합니다. 얼굴은 CC0 기초 UV를 유지하고, 새 머리 가닥의 길이 방향은 `FlowUV`로 관리합니다.

저장된 모델을 그대로 읽는 검토 명령은 다음과 같습니다. 원본을 재생성하거나 저장하지 않으며 해시가 유지되는지 확인합니다.

```powershell
pwsh -NoProfile -File scripts/run-blender-heroine-v7.ps1
python scripts/package-heroine-v7-review.py
```

`build_heroine_v7.py`, `fit_heroine_v7.py`, `refine_heroine_v7.py`, `finish_heroine_v7.py`, `close_heroine_v7_skull.py`, `taper_heroine_v7.py`, `soften_heroine_v7_face.py`는 제작 단계의 스크립트입니다. 일상 출력에 재실행하지 않습니다. `fit_heroine_v7.py`는 폐기된 투영 실험을 별도 study 파일로만 출력하며 현재 편집 원본에 저장하지 않습니다. 초기 파일이 존재하면 명시적 재구성 옵션 없이 덮어쓰지 않습니다. 수정한 원본을 재구성 전에 따로 보존합니다.

## 출처와 범위

얼굴 기초는 V5에서 출처를 확인한 pixiv Sendagaya Shino(CC0)를 이어 사용합니다. 공식 출처: https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino

이번 뒤통수 기초는 pixiv Sendagaya Shibu의 **beta AvatarSample 1(CC0)** 입니다. 모든 VRoid 모델에 일반화한 라이선스가 아닙니다. 원본 VRM과 다운로드 URL/메타데이터/해시는 `reference-topology/provenance.json`에 있습니다. 공식 설명: https://vroid.pixiv.help/hc/en-us/articles/360012381793-%CE%B2-Ver-AvatarSample-1

새 얼굴 조형과 앞머리/컬 메시, UV 연결, 재질 조정은 이 후보를 위한 작업입니다. 피부·홍채·머릿결 PNG는 V6의 보존된 생성 원본을 재사용했습니다. 생성 초상화를 실제 모델 렌더로 대신하지 않았습니다.

게임 런타임·활성 스프라이트·광장·분수·충돌·저장·웹은 변경하지 않았으며, 브라우저 조작·자동 플레이·Godot 가져오기·웹 내보내기는 하지 않았습니다.
