# V6 · 승인 시안과 실제 모델의 차이 추가 수정

사용자는 V5 실제 모델이 승인 시안과 여전히 다르다고 지적했습니다. 시안은 변경하지 않고 얼굴과 머리카락의 실제 메시·UV·재질을 수정했습니다. 현재 독립 원본은 `heroine-v6-head.blend`이며, V5는 그대로 보존합니다. 게임에는 적용하지 않았습니다.

## 수정한 부분

- 머리의 세로 비례를 줄이고 가로로 퍼지는 단발을 새로 조형했습니다. 기존28개 V5 머리 조형은 이 원본에서 사용하지 않습니다.
- 23개 큰 흐름과46개 독립된 갈라진 끝, 별도 잔머리 곡선으로 앞/옆/뒷머리를 구성했습니다. 앞머리를 길게 내려 먼 쪽 눈 위로 겹치게 했습니다.
- 피니시 단계에서 가닥 가장자리의 회보라색 명암과 진주색 중심 하이라이트를 보강하고, 균일한 안테나 모양 잔머리를 서로 다른 곡선으로 교체했습니다.
- V5에서 넓혔던 턱 아래 폭을 되돌리고 귀와 속눈썹의 두께를 줄였습니다. 피부·홍채를 승인 시안의 셀 채색에 맞춘 실제 UV 텍스처로 바꿨습니다.
- 깃털처럼 엇갈렸던 V5 헤어 텍스처 대신 가는 세로 결을 메시의 길이 방향에 연결했습니다. 작은 UV 구간과 기존 가닥 색을 혼합해 반복 무늬와 과한 빗살 표현을 줄였습니다.
- 얼굴과 머리카락 윤곽은 실제 반전된 메시 껍질의 얇은 선입니다. 특정 카메라에만 맞춘 윤곽 그림을 붙인 방식이 아닙니다.

이번 범위는 머리 흉상입니다. 옷깃/숄은 인상 확인용 보조 조형이며 전신·표정 리그·보행 제작 완료본이 아닙니다. 활성 게임 캐릭터·스프라이트·공유 월드·웹 산출물은 교체하지 않았습니다.

## 실제 렌더와 시안 비교

`review/reference-comparison-v6.png`는 같은 참조 이미지 영역과 실제 모델의 비교용 자세를 나란히 놓은 것입니다. 눈 두 곳·코·입·턱의 참조 위치를 기록하여 카메라/고개 각도의 차이와 조형 차이를 구별했습니다. 위치 피팅의 수치는 외형이 같다는 증거나 미술 승인이 아닙니다. 기준 좌표와 카메라값은 `reference-registration.json`에 있습니다.

모델 원본의 고개는 중립이며, 기울인 자세는 검토 렌더에만 적용합니다. 정면/사선/측면/뒤/재질 제거 및 회전 렌더는 저장된 같은 모델을 읽어 출력합니다. 생성 이미지를 모델 렌더나 회전 영상으로 대신하지 않습니다. 승인 시안의 붓결과 실제 모델의 표면·실루엣에는 표현 차이가 있으므로 비교판으로 판단해야 합니다.

## 파일과 수정 보존

- `heroine-v6-head.blend`: 현재 수동 편집 원본. 메시·UV·패킹 텍스처·중립 머리 제어·편집기용 승인 이미지가 있습니다.
- `review/portrait-v6.png`: 실제 사선 모델 렌더.
- `review/reference-comparison-v6.png`: 승인 시안과 실제 비교용 자세.
- `review/model-angles-v6.png`: 정면·사선·측면·뒤·회색 조형.
- `review/head-turntable-v6.gif`: 중립 모델의24방향 실제 회전 출력.
- `textures/`: 원본 피부/눈 UV를 수정한 셀 채색과 세로 머릿결 PNG.
- `hair-authoring-v6.json`: 큰 머리카락 경로. 수동 편집 후에는 .blend가 원본이며 이 레시피로 덮어쓰지 않습니다.

Blender 4.5.15 LTS용입니다. 정면 -Y, 위 +Z, 턱 근처 Z=0인 독립 조형 단위입니다. 게임 픽셀/발 기준 규격의 변경이 아닙니다. 검토용 제어 `V6 HEAD POSE - art comparison only`는 원본에서 회전0이며 조형 비례를 위한 Z축 크기0.82를 포함합니다. 게임에서 머리를 기울이는 애니메이션 계약으로 사용하지 않습니다.

수동 수정은 이 .blend에 저장한 뒤 아래 명령으로 화면만 다시 출력합니다. 검토 스크립트는 원본을 재생성하거나 저장하지 않습니다.

```powershell
pwsh -NoProfile -File scripts/run-blender-heroine-v6.ps1
python scripts/package-heroine-v6-review.py
```

최초 제작 단계는 `revise_heroine_v6.py` → `paint_heroine_v6.py` → `refine_heroine_v6.py` → `finish_heroine_v6.py`입니다. 기존 파일/단계가 있으면 중단하며, 수동 수정 후 일상 출력에 이 제작 레시피를 재실행하지 않습니다. 명시적인 재구성 옵션은 제작 원본을 덮어쓸 수 있으므로 별도로 보존한 경우에만 사용합니다.

## 출처

얼굴 기초 토폴로지와 수정 전 피부/눈 UV는 V5에서 확인한 pixiv/Sendagaya Shino(CC0) 자료를 이어 사용합니다. 공식 출처는 https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino 이며 파일 메타데이터/원본 해시는 ../blender-v5/reference-topology/source-metadata.json에 보존되어 있습니다. 얼굴 비례/턱/귀/눈꺼풀 수정, 새 단발 조형과 UV/재질 편집은 이번 캐릭터를 위한 작업입니다.

세 텍스처는 내장 imagegen 도구로 제작했습니다. 피부/홍채는 기존 CC0 UV를 편집 대상으로, 승인 시안을 색·화풍 참고로 사용했습니다. 머릿결은 새 세로 알베도입니다. 프롬프트와 역할은 textures/GENERATION.md를 따릅니다. 캐릭터 초상화를 생성해 실제 모델로 보고하지 않았습니다.

브라우저 조작·자동 플레이·Godot 가져오기·웹 내보내기는 실행하지 않았습니다.
