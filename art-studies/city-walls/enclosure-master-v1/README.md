# 성벽 전체 완성본 우선 제작

사용자 요청: 작은 공간을 둘러싼 성벽을 먼저 완성하고, 실제로 이어지는 부분을 추출해 재사용합니다.

현재 `enclosure-concept.png`는 사용자가 승인한 전체 외형입니다. [실제 조각과 TileSet](../../../godot-arcana/art/source/walls/assembled-v1/README.md)으로 제작해 광장에 연결했습니다.
`enclosure-geometry.png`는 투영·입구·벽 폭을 설명하는 기하 참조이며 완성 미술이 아닙니다.

승인 후 우선 전체 원본의 실제 도트·접지·벽 두께를 맞춥니다. 앞/뒤 가로벽, 왼쪽/오른쪽 세로벽, 네 모서리, 입구 좌우 끝을 구별해 추출합니다. 경계에 테두리나 기둥을 추가하지 않으며 조각을 다시 이어 원래 성곽을 복원한 뒤 긴 직선으로 확장합니다.

잘라낼 위치는 캔버스 사각형이 아니라 바닥 점유와 접합 위치를 기준으로 정합니다. 처음에는 여러 칸짜리 직선·모서리를 허용합니다. 현재 활성 네이티브 월드의 화면 격자는64×64이며 투영 기준 깊이1단위는45.25px이므로, 세로로 늘려 맞추지 않고 등록 격자를 최종 제작 시 명시해야 합니다. 생성 그림이 이미 정확한 제작 좌표를 충족했다고 간주하지 않습니다.

입력 참조: 보관된 Stardew 실내/여름야외 시트, 대상 기하 가이드, 활성 타운하우스 PNG, 확정 주인공·메이 비율 이미지. `prompt.txt`와 `brief.json`에 입력 목적과 시작 치수를 남겼습니다.
