# 마법학교 내부 · 승인 시안과 2개 층

사용자는 concept 이미지의 분위기를 승인하고 실제 2층 왕복을 요청했습니다.
기준은 approved-concept.png이며 원본 그림 전체를 게임 배경으로 축소하지 않습니다.

- 생성: 내장 image_gen. source/architecture.png와 source/furniture.png는 디자인을 따른 분리 자산 시트이며 source/stairs-down.png는 내려가는 계단실의 보완 원본입니다.
- 규격: 정면형 3/4(yaw 0°, pitch 45°), 64px/월드 단위, 최근접, 이진 알파, 기존 LUT.
- 재제작: node scripts/build-academy-interior.cjs. 각 개체의 실측 원본 영역·최종 크기·발 기준점은 asset-manifest.json에 있습니다.
- 게임: godot-arcana/scenes/academy_first_floor.tscn, academy_second_floor.tscn 및 scripts/academy_interior.gd.
- 1층: 중앙 천체 장식, 도서관, 강의실, 수정 실습실, 위층 계단, 광장 출구.
- 2층: 교장실, 별빛 정원, 천문 관측 공간, 아래층 계단. 각 공간의 기존 서버 행동과 잠금 조건을 유지합니다.
- 계단: 가까이 걸어가 E/Space 또는 원형 상호작용 버튼. 화면의 층 이름이 바뀌고 다른 층의 개체·충돌·미술을 로드합니다. 계단 도착만으로 자동 왕복하지 않습니다.
- 저장: 기존 위치 저장에 academyFloor를 추가합니다. 이전 저장은 서버의 현재 방으로 층을 추론합니다. 같은 방의 서버 갱신은 자유 탐색 중 선택한 층을 되돌리지 않습니다.
- 등록: 게임 이동은 16px/월드 단위이며 미술 발 기준은 64px/월드 단위입니다. 가구 충돌과 상호작용 접근 지점을 분리합니다. 두 층의 좌표 공간은 독립적이며 2층에서 바로 광장으로 나가는 출구를 만들지 않습니다.
- 조명: 공통 실내 조명 수신과 개체 가림을 사용합니다. 원화 명암을 보존하며 새 가구별 정밀 높이 맵은 없습니다.

제작 프롬프트: 승인 시안의 크림 석재·파란 별 장식·금색·꽃덩굴을 공유하는 정면형 3/4 2D 도트 RPG용 독립 개체. 건축 시트는 창문 벽·올라가는 계단·책장·낮은 앞벽·교장실 문·내려가는 계단, 가구 시트는 천체 장식·책상·칠판/수정 장·벤치·화분·망원경으로 구성하며 사람·글자·UI는 제외합니다. 원본 시트는 투명 배경으로 생성하고 등록 과정에서 이진 알파를 적용합니다.

검수 범위는 godot-arcana/art/PRODUCTION.md의 마법학교 2개 층 항목을 참조합니다. 최종 인게임 미술 승인은 별도입니다.

### 책장 식생 제거
사용자 수정 지시에 따라 책장 위 덩굴·꽃·화분을 모두 제거했습니다. 내장 image_gen으로 bookcase-before.png의 목재·책·금색 천체 장식·수정을 유지하고 가려진 선반을 복원한 source/bookcase-clean.png를 제작했습니다. 책장 제작 입력은 clean 원본을 사용하며 200×212 캔버스·발(100,208)을 유지합니다. 1층/2층 공통 책장에 적용합니다. 제작 지시: 책장에 붙은 모든 식생과 화분을 제거하고 가려진 목재/책을 복원하며, 세 칸 책장·별 문양·투명 배경·기존 도트풍을 유지합니다.

## 실내 전체를 그린 바닥과 독서 장면 (2026-10-28)

사용자가 반복 타일에 얽매이지 않고 영화 속 한 장면처럼 내부를 꾸미도록 요청했습니다. 기존 승인된 크림 석재·파랑·금색을 이어 받아 층마다 독립된 전체 바닥 그림을 제작했습니다. source/floor-first-painted.png와 floor-second-painted.png가 원본이며 둘 다1374×1145입니다. 게임에서는1152×960,64px/월드 단위의18×15평면에 딱 한 번 표시합니다. 별도 반복 판석·절차적 별 메달·사각 러그 레이어는 현재 내부에서 사용하지 않습니다.

1층은 출입구-중앙 천체 모자이크-계단을 잇는 파란 카펫과 금속 상감, 학습 공간별 러그, 창빛으로 구성합니다. 천체 장식은 바닥 모자이크 중심(12,11.5)에 맞추고 충돌과 푸른 조명도 함께 옮겼습니다. 2층은 목재 테두리·달의 위상 모자이크·천문 바닥 문양·독서 러그로 구별합니다. 그림에 포함된 창빛과 마모는 정적인 원화 표현이며 동적인 창 그림자라고 보고하지 않습니다.

source/reading-details.png는 책 수레·작은 독서/찻상과 의자·독서용 플로어 램프의 투명 원본입니다. 개별PNG로 추출해 같은64px/단위로 등록하고 가장자리 학습/휴식 구역에 배치했습니다. 새 가구의 발 범위에만 충돌을 추가하고 기존 방 접근점과 계단/출구는 유지합니다. 램프는 공통 실내 조명 수신 경로에 따뜻한 국소 광원을 추가합니다. 책장의 식생 제거 원본은 그대로 사용합니다.

생성 도구: 내장 image_gen. 제작 지시:
- 1층 바닥: 승인 실내의 색과 도트풍을 따른 정탑뷰 전체 바닥. 중앙 천체 모자이크, 입구에서 계단까지의 청금색 카펫, 좌우 학습 러그, 따뜻한 석재와 곡선 금색 상감, 창의 색빛. 반복용 타일·가구·사람·글자 없이 한 장으로 구성합니다.
- 2층 바닥: 같은18×15면적의 정탑뷰 전체 바닥. 목재 가장자리·달의 위상 원형 장식·천문 관측 문양·교장실 러그·독서 구역을 하나의 구도로 구성하고 가구/계단을 그림에 포함하지 않습니다.
- 독서 소품: 정면형3/4의 분리된 둥근 찻상/스툴·책 수레·금색 플로어 램프. 목재·파랑·금색·기존 도트풍과 투명 배경을 유지하고 꽃·덩굴·화분을 붙이지 않습니다.

## 1층 안의 작은 방 3개 (2026-10-28)

사용자가 큰1층 홀 안에 작은 방들도 요청했습니다. 기존 도서관·강의실·실습실 구역을 실제로 걸어 들어가는 부속실로 나눕니다. 별도 로딩이나 메뉴로 이동을 대신하지 않습니다. 2층/계단·원화 바닥·기존 수업과 퀘스트는 유지합니다.

- 도서실: 지도 X48~152,Y64~240. 남쪽 Y240의 X80~120을 비운 아치 출입구로 들어갑니다.
- 강의실: X240~336,Y64~184. 중앙 홀에 닿는 서쪽 벽 X240,Y120~168에 통행구를 둡니다.
- 실습실: X240~336,Y184~264. 서쪽 벽 X240,Y200~248에 별도 통행구를 둡니다.

academy_interior.gd의 partition_rects()가 미술 배치와 실제 이동 충돌의 공통 원본입니다. 낮은 컷어웨이 석벽으로 내부를 보이게 하며 플레이어 가림에는 기존 반투명을 적용합니다. source/room-partitions.png의 가로벽·깊이벽·열린 아치·작은 기둥을 사용합니다. 가로벽은 같은 밀도의64px 구간을 추출해 이어 붙이고 비균등 늘리기를 하지 않습니다. 방의 문틈은 길찾기 격자16px와 충돌 여유3px를 감안해40/48px로 남깁니다. 벽에 걸치던 책 수레·독서등·화분은 방 안쪽으로 재배치하고 해당 발 충돌도 맞춥니다.

생성: 내장 image_gen. 제작 지시: 승인된 학교의 크림 석재·금색을 잇는 정면형3/4 2D 도트 파티션 키트. 수평 낮은 벽·앞뒤 방향의 좁은 측벽·속이 투명하게 열린 아치·별 문양 기둥을 분리하고, 꽃·덩굴·화분·글자는 넣지 않습니다. 원본은 투명 배경이며 등록은 기존64px/단위와 LUT/최근접/이진 알파를 따릅니다.
