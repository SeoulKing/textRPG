# 단일 스킬 트리 템플릿

[승인 이미지](approved-template.png)는 아이콘 중심 배치와 상아색·남색 UI의 기준입니다. 원래 이미지의 노드 수·효과는 현행 규칙과 구별합니다.

- 공통 화면: `godot-arcana/scripts/skill_tree_view.gd`.
- 스킬 선택 탭·성장 설명·노드 이름은 트리에 넣지 않고, 선택한 이름·효과·조건만 하단에 표시합니다.
- 상단 레벨·숙련도·포인트, 중앙 가변 행 트리, 하단 고정 상세·행동 버튼을 유지합니다. 낮은 가로 화면은 상세를 오른쪽에 둡니다.
- 노드 데이터의 행·열·연결·유료/무료·자동 획득 여부로 배치합니다. 다른 스킬을 추가할 때 UI를 복제하지 않습니다.
- 아이콘은 기존 주문 텍스처를 임시 재사용합니다.
- 현재 파이어볼: 기본 강화 3개 → 전문화 2개 → 궁극기 3개 → 마스터. [확정 규칙](../../docs/arcana-fireball-progression.md)을 따릅니다.
- 다른 스킬은 기존 트리·숙련도 규칙을 유지합니다.

개인 이미지 템플릿은 `artifact-template-arcana`이며, 게임의 실제 재사용 원본은 위 Control과 서버 노드 정의입니다.
