# 야외 자산 통일 · 가로등과 분수 기준

2026-10-29 사용자 요청: 현재 야외 자산을 통일하고, 마음에 드는 가로등과 분수를 기준으로 삼습니다. 수정에는 PixelPen을 사용합니다. 캐릭터·실내·UI는 이번 교체 대상이 아닙니다.

## 원본과 연결

- `manifest.json`: 야외 자산 23종의 실제 연결, 기존 캔버스·발 기준점·배치 배율·기존 유효 밀도와 출력 해시입니다. 저장 장면의 해당 자산 배치는 161개입니다. 자동 생성되는 길가 풀·소품도 같은 표시기를 사용합니다.
- 편집 원본: `godot-arcana/art/source/outdoor-unified-v1/*.pxpen`.
- 게임 출력: `godot-arcana/art/export/outdoor-unified-v1/*.png`.
- 실제 연결: `outdoor_art.gd` → `illustrated_prop.gd`; 야외 factory에서만 활성화합니다. 원래 캔버스·피벗·저장 Transform과 충돌은 유지합니다.
- 분수·포탈은 기존 애니메이션 원본을 유지합니다. 분수는 이번에 수정하지 않았습니다. 가로등은 기존 생성 원화에서 현재 크기에 맞게 옮겼으며 디자인 수정과 잡점 보정을 적용하지 않았습니다.
- 기존 공통 바닥·벽은 이미 같은 투영·64px/월드 단위로 제작된 원본을 유지합니다. 지역 원화와 분수 바닥 문양을 새 반복 타일로 대체하지 않습니다.

## 실제 제작 범위

나무 3종은 기존 수종·전체 비례를 보존한 내장 image_gen 보정 원화를 만들고, 목표 도트 격자에 옮긴 뒤 PixelPen에서 정리했습니다. 나머지는 보존된 제작 원화와 등록을 사용했습니다. 원화와 기존 자산은 삭제하거나 덮어쓰지 않았습니다.

`pixelpen-plan.json`은 준비 이미지와 좌표별 보정 지시(이전 색/새 색)입니다. 가장자리·틈·고대비 하이라이트는 일반 잡점 정리에서 제외하고, 불투명한 내부에서 주변과 끊기는 낮거나 중간 대비의 고립 도트만 정리했습니다. `pixelpen-audit.json`에는 네이티브 저장·재열기·PNG 출력과 자산별 실제 보정 수가 있습니다. 이는 구조·제작 증거이며 사용자 미술 승인을 뜻하지 않습니다.

원화 축소와 색 변환은 준비 공정입니다. 실제 보정은 PixelPen의 IndexedColorImage 도트에 적용해 저장했습니다. 일부 자산은 보정량이 적으며 전체를 새로 손으로 그렸다고 보고하지 않습니다.

## 재출력

프로젝트 루트에서 실행합니다. 기존 PixelPen이 있으면 준비 이미지를 다시 덮지 않고 해당 편집 원본을 내보냅니다.

```powershell
node scripts/build-outdoor-unified-art.cjs --prepare
pwsh -NoProfile -File scripts/run-outdoor-art.ps1 -Action Native
node scripts/build-outdoor-unified-art.cjs --package
```

`--prepare`는 보존 원화·생성 원화를 등록 캔버스에 옮긴 준비 이미지와 보정 명세를 만듭니다. `-Action Native`는 기존 `.pxpen`을 우선 재열고 PNG를 내보냅니다. 최초 원본에만 보정 지시를 적용하며, 사용자 수동 보정을 덮어쓰지 않습니다. 재수정은 `.pxpen`에서 수행합니다. 팔레트는 기존 월드 LUT를 사용하고 PNG 가져오기는 손실 없음·무밉맵·3D 자동 압축 전환 금지입니다.

일부 건물의 확대는 원래부터 배치에 있었습니다. 이를 취소하거나 충돌·문 위치를 바꾸지 않고 고해상도 원화의 세부를 사용하며, 표시 셰이더가 배치 배율을 포함한 1/64 월드 단위 격자에서 읽습니다. 정사영 0°/45° 제작 그림을 다시 세로 압축하지 않습니다.
