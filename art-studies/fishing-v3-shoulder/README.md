# 낚싯대 v3 · 어깨 휴대 비교 시안

상태: 사용자가 3번 MYSTIC을 선택했습니다. 승인된 어깨 휴대 방향으로 제작·연결하며, 활성 원본과 확인 범위는 godot-arcana/art/source/fishing-v3-mystic/README.md를 따릅니다. mystic-carry-preview.gif는 출력 프레임으로 만든 제작용 미리보기입니다.

확정된 공통 방향: 같은 캐릭터, 같은 남동쪽 시점, 한 손으로 손잡이를 잡고 낚싯대를 어깨 뒤로 기대는 휴대 자세. 낚싯대를 든 이동 모션은 디자인 선택 후 제작합니다.

후보:
1. ARCANA: 따뜻한 나무, 남색 손잡이, 황동 고리와 작은 별 장식.
2. RUSTIC: 대나무, 가죽 감기, 소박한 빨강·상아색 찌.
3. MYSTIC: 짙은 목재, 청금색 장식과 작은 보석, 파랑·상아색 찌.

제작 도구: 내장 image_gen. 초기 비교판의 앞쪽 들기 자세를 어깨 뒤로 기댄 자세로 한 번 보정했습니다. 최종 시안은 design-comparison-v1.png이며 실제 게임 자산이나 애니메이션 시트가 아닙니다. 프롬프트 원문은 generation-prompt.txt 및 shoulder-correction-prompt.txt입니다.

참조: 보관된 스타듀 투영 두 시트와 front-orthographic-45.png는 투영·상대 크기 기준, identity-v1/references/run_se-00.png는 인물 외형 기준, fishing-v2/concept-v1.png는 기존 아르카나 낚시의 소재·분위기 기준입니다.

선택 후: 기존 얼굴·의상·몸 비례·이동 속도·낚시 판정을 보존하고 8방향 대기·이동·정지·낚시 전환을 제작합니다. 방향/걸음 위상별 손·손잡이·어깨 접촉과 머리카락 가림을 등록하며 PixelPen 원본 편집·보정·저장/재열기·출력 후 게임 연결과 웹 빌드를 진행합니다. 사용자 요청 없이 플레이 테스트나 브라우저 조작을 실행하지 않습니다.
