# 마법학교 1·2층 상세 배치

## 본편 광장 학교 외관

- [2D 외관 원본](../../../godot-arcana/art/export/reference/academy-2d.png)의 넓은 양날개, 푸른 쌍첨탑과 오른쪽 천문대, 중앙의 별·책 문장과 뾰족아치 정문을 입체로 제작했습니다.
- 원본 모델은 24×10칸 안에 들어갑니다. 광장 인스턴스는 캐릭터 키에 맞춰 확대했고 평면 충돌 범위는 28.08×12칸입니다. [Blender 편집 원본](../../../godot-arcana/art/source/plaza-academy-blender/academy-exterior.blend)과 [Godot으로 내보낸 GLB](../../../godot-arcana/art/source/plaza-academy-blender/academy-exterior.glb)는 월드 타일 한 칸을 Blender 1단위로 맞춥니다. Blender에서는 `−Y`, Godot에서는 `+Z` 쪽이 정면입니다.
- [본편 광장 씬](../../../godot-arcana/scenes/plaza_3d_v2.tscn)의 `Academy` 기준점은 `(24, 0, −21)`이고 정문은 4칸 폭 학교길과 연결됩니다. 기존 아카데미 ID와 1층 도착점, 내부 계단을 사용합니다.

## 요청과 현재 단계

- 지역 ID: `arcana_academy:1`, `arcana_academy:2`.
- 사용자 요청: “너가 알아서 디테일 있게 마법학교 1 2층을 만들어봐”.
- 후속 위임: “알아서 검토도 하고 부족하면 개선도 해줘”. 이 지시로 학교에 한정한 실행 검토·회귀 검사·보완을 진행했습니다.
- 범위: 기존 2D 학교의 가구 상세 배치·재사용 사물 등록·고정 조명·본편 연결.
- 단계: 엔진·GPU 검토와 보완 완료, 로컬 웹 산출물 갱신 및 제공 확인 완료. 실제 웹 계정의 전체 플레이는 별도 미확인입니다. 새 원화 제작·컨셉 변경은 없습니다.
- 원장: `docs/studio/board.json`의 `ACADEMY-DETAIL-20261106`.
- 원본: `godot-arcana/scenes/native_2d/academy_first_floor.tscn`, `academy_second_floor.tscn`.

## 디자인과 공간

기존 상아색 석재, 청금색 러그, 금빛 천체 문양과 창을 유지합니다. 이미 바닥에 그려진 러그·중앙 천체 문양에 다른 러그를 덮지 않습니다. 기존 방·문·계단·가구 Transform과 저장·상호작용 ID를 유지하고 새 가구만 추가합니다. 캐릭터와 카메라, 실내 크기도 유지합니다.

| 층 | 구역 | 추가 구성 |
| --- | --- | --- |
| 1층 | 도서관 | 참고 도서 수레, 공동 열람·필사 테이블, 독서등. 기존 열람 테이블과 서가를 함께 사용합니다. |
| 1층 | 기초 강의실 | 칠판 앞 긴 수업 좌석, 모서리 조명. 출입은 기존 서쪽 틈으로 유지합니다. |
| 1층 | 수정 실습실 | 약초·시약 보관장, 유리병과 표본대, 남동쪽 작업등. 기존 실습 책상과 연결되는 시각 구역입니다. 새로운 조제 기능은 없습니다. |
| 1층 | 중앙 회랑 | 기존 천체의와 입구·계단 동선을 보존합니다. |
| 2층 | 집무·연구 | 자료 서가 2개와 충돌, 집무등·화분·상담 대기 의자. 기존 문과 집무 책상을 유지합니다. |
| 2층 | 천문·열람 | 관측 자료 수레, 별도 열람 테이블과 독서등, 유리 표본대. 기존 망원경과 천문 바닥 문양을 유지합니다. |
| 2층 | 별빛 정원 | 약초·관찰 보관장, 차탁과 독서 안락의자. 기존 식물·벤치·식물 휴게 구역을 활용합니다. |

추가 가구는 1층 8개, 2층 12개입니다. 각 소품의 접지·충돌은 독립 인스턴스에 함께 저장됩니다. 기둥·벽과 인접한 장식은 하나의 군집으로 두며 그 사이를 통행로로 취급하지 않습니다. 중앙 도착점과 계단 접근 구역에는 새 가구를 넣지 않습니다. 새 가구·효과는 기본 Scale (1,1)입니다.

## 자산과 실제 연결

| 재사용 자산 | 등록·소비 경로 |
| --- | --- |
| 학교 서가·책상·열람 테이블·수레·좌석·식물·등 | 기존 `godot-arcana/scenes/props/academy-first-floor/`, `academy-second-floor/` 인스턴스 |
| 약초·시약 보관장 | `godot-arcana/scenes/props/academy-shared/storage/reagent-cabinet.tscn` → 기존 `art/export/shop-2d/herb-cabinet.png` |
| 유리 표본대 | `godot-arcana/scenes/props/academy-shared/tables/specimen-stand.tscn` → 기존 `art/export/shop-2d/potion-island.png` |
| 차탁·안락의자 | 기존 `scenes/props/inn/tables/inn-tea-table.tscn`, `seating/inn-armchair.tscn` |
| 학교 고정 조명 | `scenes/props/academy-shared/lighting/study-light.tscn` → 여관과 같은 GradientTexture2D 방식, 새 PNG 없음 |
| 사물 색인 | `godot-arcana/data/prop-library.json`의 `academy-shared/*` 3개 |

공용 보관장과 표본대는 기존 PNG를 원래 크기와 등록 foot로 사용하며, 상점 전용 수집기 대신 학교 `region_layout.gd`가 수집할 원본 픽셀 충돌을 제공합니다. 장식에 새 상호작용 ID를 만들지 않습니다.

`data/regions.json` → `scripts/region_registry.gd` → 해당 층 `.tscn` → `scripts/region_layout.gd`와 `scripts/native_2d_world.gd`가 실제 표시·충돌을 읽습니다. 새 manifest만 추가한 연결이 아닙니다.

양 층 root에 `scripts/native_2d_academy_lighting.gd`를 연결했습니다. 고정 조명 1층 10개·2층 7개를 램프와 책상 자식으로 배치해 부모를 움직이면 빛도 함께 움직입니다. `native_2d_world.gd`가 `sync_lighting`을 호출하며 효과를 끄면 기본 밝기로 돌아가고 광원이 꺼집니다. 조명에는 깜박임이나 이동이 없습니다.

| 연결 | 보존 값 |
| --- | --- |
| 1층 입장 Arrival | (768,1040) 원본 픽셀 |
| 1층 StairArrival | (768,608) 원본 픽셀 |
| 2층 Arrival / StairArrival | (768,776) 원본 픽셀 |

## 검토에서 발견하고 보완한 항목

- 학교의 16논리픽셀 AStar 격자가 좁은 입구를 놓치거나 벽을 가로지르는 경로를 만들어 클릭 이동이 중단됐습니다. 학교만 4논리픽셀·96×88 셀로 세분화하고 좌표 변환을 같은 cell_size에 맞췄습니다. 다른 지역의 기존 간격은 유지합니다.
- 동일 격자 크기에서 층이 바뀌면 이전 층의 solid가 남았습니다. 현재 층의 모든 셀을 true/false 양쪽으로 다시 설정합니다. 실제 이동·충돌 함수는 유지합니다.
- 서버용 online-layout에 새 가구가 빠져 있었습니다. 최종 stage에서 재생성해 학교 충돌 직사각형이 1층 39개·2층 30개로 갱신됐습니다. 이 수량은 벽·경계를 포함한 충돌 개수이며 가구 개수가 아닙니다.
- 기존 저장이 새 가구 안에 놓일 때 학교 복구가 생략됐습니다. src/online/world.ts에서 학교도 현재 층 유효 좌표를 검사해 무효 위치만 안전한 층 시작점으로 복구합니다. 실제 사용자 저장은 직접 수정하지 않았습니다.
- 양 층에 순수 검정 외곽 Polygon2D를 추가했습니다. 기존 가구와 ID·Transform은 보존했습니다.

검토 도구는 godot-arcana/tools/review_academy_interior.gd입니다. API·계정·사용자 저장을 읽거나 쓰지 않는 격리된 World+native_2d_world 검토입니다. 최종 이동·캡처 결과는 이 명세 옆 review/report.json, 전체 이미지는 review/floor-1-overview.png와 review/floor-2-overview.png입니다. 실행 로그와 PCK 증거는 .runtime/godot/online-build-academy-review-20261106/에 보존합니다.

남은 미확인은 **웹브라우저에서 실제 계정 로그인 후 Main UI를 통해 학교 출입·계단·방 선택과 서버 응답까지 이어지는 전체 플레이**입니다. 격리 World의 신호 성공과 로컬 파일 제공을 실제 계정 플레이 성공으로 대신 기록하지 않습니다.

## 복숭아빛 석재와 외곽 마감 시안

사용자가 제시한 복숭아빛 석재, 선명한 청금색과 금장, 두꺼운 외벽 단면을 두 층에 적용하는 개정입니다. 현재 단계는 색감과 외곽의 적용 시안 승인 대기입니다.

- [확인할 시안](source/exterior-finish-v2/concept.png)은 왼쪽이 1층이고 오른쪽이 2층입니다. [사용자 참고 이미지](source/exterior-finish-v2/reference-user.png)와 [내장 ImageGen 프롬프트 및 참조](source/exterior-finish-v2/prompt.md)를 함께 보존합니다.
- 사용자 이미지의 대표색은 밝은 덮개석 `#FADAB1`, 중간 석재 `#CC9978`, 외벽 그늘 `#694B4F`, 청금 러너 `#26429E`, 금장 `#E9AA3F`, 등불 심지 `#FDFAD0`입니다. 해당 부위의 작은 표본을 기준색으로 삼습니다.
- 후면 네 창 사이의 석재 띠와 기둥, 측벽과 앞벽의 모서리, 밝은 덮개석과 짙은 단면을 모듈로 제작합니다. 2층 전면 난간은 내부 계단 앞까지 이어집니다.
- 1층 정문 시안의 청금색 면은 문짝처럼 보일 수 있습니다. 실제 제작에서는 출구 `(768, 1216)`와 `x632–904` 개구부에 열린 아치와 문턱을 맞춥니다. 실제 가구와 계단 치수·좌표는 현행 씬을 기준으로 합니다.
- 승인 후 새 벽과 문턱의 2D 모듈을 제작해 PixelPen 저장·재열기·PNG 출력을 완료합니다. 두 층 씬의 실제 텍스처 오버라이드와 표시 범위를 갱신하고, 전체·384×824 화면 및 기존 이동 11개 경로와 계단 왕복을 확인한 뒤 로컬 웹 산출물에 반영합니다.

## 1층 네 방 배치

[승인 시안](source/first-floor-reference.png)을 기준으로 중앙 홀의 북쪽 계단과 남쪽 정문 사이에 별 문양을 놓고, 서쪽에 도서관·수정 실습실, 동쪽에 기초 강의실·교무실을 배치했습니다. 교무실은 자유 통행 공간이며 교장실 상호작용은 2층에 있습니다. NPC는 배치하지 않았습니다. 새 타일·러그·소품의 원본은 `godot-arcana/art/source/academy-interior/first-floor/`에 있습니다.

Godot 4.5.1의 실제 이동과 충돌로 광장 정문 접촉, 네 방 진입, 출구 접근 및 층 왕복을 확인했습니다. 1440×1024 전체 뷰와 384×824 모바일 화면을 검토했습니다. 온라인 서버는 씬에서 내보낸 좌표로 양쪽 계단, 방 접근과 기존 위치 복구를 판정합니다. 서버 판정은 격리 검사로 확인했으며, 로그인한 브라우저에서의 전체 플레이는 이 검사에 포함하지 않았습니다.

## 1층 시안 파츠 분석과 재제작

[시안의 부위별 확대](source/first-floor-material-study.png)를 먼저 대조했습니다. 아래 분석을 기준으로 부품을 제작한 뒤 씬에 배치합니다.

| 시안에서 본 파츠 | 기존 화면과 차이 | 분리 제작·재사용 결정 |
| --- | --- | --- |
| 홀과 양쪽 통로의 밝은 석판 | 가로 띠처럼 이어져 판의 네 귀가 안 보임 | 밝은 줄눈, 어두운 모서리 맞물림이 있는 반복 석판. 홀과 통로의 타일 원점을 공유. |
| 도서관·강의실·교무실의 목재 | 옆으로 흐르는 단순 반복이라 시안의 길이 방향이 사라짐 | 세로로 깐 판재와 엇갈리는 이음, 절제된 결. |
| 실습실의 보랏빛 석판 | 어두운 바닥에도 줄눈과 모서리 돌이 드러남 | 홀과 다른 팔레트·크기의 판석과 따뜻한 가장자리. |
| 북쪽 벽 | 기존에는 수직 벽돌만 보임. 시안은 짙은 상단 아래로 따뜻한 안쪽 면이 보임 | 가로 덮개석과 벽 안쪽 면을 별도 스프라이트로 배치. |
| 남쪽과 방 앞의 잘린 벽 | 벽돌 띠가 바닥에 얹힌 듯 보임. 시안은 상단과 그 아래 어두운 단면이 구분됨 | 짙은 가로 덮개석, 짧은 단면, 외곽 하부 기단을 분리. |
| 세로 외벽과 중앙 홀의 옆벽 | 가로 벽돌을 세로로 반복해 카메라 방향이 틀어짐 | 길이 방향으로 결이 이어지는 좌우 전용 덮개석. 교차점에서 상단이 이어지도록 접합. |
| 네 방 문턱과 정문 | 방마다 재질 경계가 날것으로 맞닿음 | 북쪽 방의 목재 단, 남쪽 방의 낮은 석재 문턱, 남쪽 정문 문턱을 각각 독립 배치. |
| 별 문양·러너·창·큰 계단·가구·조명 | 홀을 읽는 기준이며 이번 교정에서 필요한 비교 대상 | 기존 자산을 사용해 벽·바닥과 맞물리는 위치를 비교. |

실제 바닥 폭과 발 충돌 기준은 기존 씬을 유지합니다. 상단 폭과 하부 단면은 표시용이며 이동 경계나 저장 좌표에 추가하지 않습니다.

[배치 전 파츠와 접합부 비교판](review/first-floor-parts-v2.png)의 13개 파츠는 PixelPen에서 저장·재열기한 뒤 PNG와 픽셀·알파가 일치하는지 확인했습니다. 원본과 게임 출력은 각각 `godot-arcana/art/source/academy-interior/first-floor/materials/`, `godot-arcana/art/export/academy-interior/first-floor/materials/`입니다.

배치 후 [1층 전체](review/first-floor-materials-v2.png)와 [서쪽 문턱 근접 화면](review/first-floor-thresholds-v2.png)을 Godot에서 확인했습니다. 뒤 벽 상단은 책장과 칠판보다 높게 두고, 앞벽은 상단과 아래 단면이 함께 보이도록 분리했습니다. 통행 경계·상호작용 좌표·기존 가구 배치는 이전과 동일합니다. 별도 플레이 테스트는 하지 않았습니다.

## 1층 원화 트레이싱 교정 (v3)

사용자 피드백: 기존 파츠의 디테일이 부족하며, 생성한 파츠 원화 위에 PixelPen에서 직접 그리는 방식이 제작 기준입니다. 코드로 만든 이미지를 PixelPen 파일로 옮기는 방식은 대체 경로로 쓰지 않습니다.

- 검토용 [파츠 원화](source/first-floor-material-concept-v3/concept.png)와 [생성 프롬프트](source/first-floor-material-concept-v3/prompt.md)를 보존했습니다.
- 원화는 왼쪽 위부터 밝은 석판, 세로 목재, 보라색 슬레이트, 북쪽 벽, 좌우 벽 상단, 남쪽 벽 단면, 모서리·끝단, 두 문턱, 열린 문 접합 예시입니다.
- 사용자가 v3 원화를 승인했습니다. 원화의 해당 부분을 파츠별 참조 레이어에 넣고, PixelPen API로 새 레이어에 그린 15개 파츠를 저장했습니다. 저장 파일을 다시 열어 원화 레이어가 숨겨진 상태에서 PNG를 출력하고 픽셀과 알파가 일치하는지 확인했습니다. 원본은 `godot-arcana/art/source/academy-interior/first-floor/traced-materials/`에 있습니다.
- [파츠와 접합부 비교판](review/first-floor-traced-parts-v3.png)을 확인한 뒤 바닥·벽을 연결하고 모서리와 문 끝단을 배치했습니다. [전체](review/first-floor-traced-v3.png)와 [문턱 근접 화면](review/first-floor-traced-thresholds-v3.png)을 Godot에서 확인했습니다.
- 로컬 웹 패키지를 갱신했고 HTTP 응답을 확인했습니다. 통행 경계·상호작용 좌표·기존 가구 배치는 이전 씬과 같습니다. 브라우저 플레이는 별도 확인 범위입니다.

## 1층 표면 디테일 보강

트레이싱한 15개 PixelPen 원본 위에 표면 디테일 레이어를 추가했습니다. 석재의 미세한 얼룩과 잔금, 나뭇결과 못 자국, 벽 상단·문턱의 닳은 면을 보강했습니다. 원본은 `godot-arcana/art/source/academy-interior/first-floor/detail-materials/`에 있습니다. 원본을 다시 열어 레이어와 PNG 출력을 확인했고 기존 파츠와 크기 및 알파가 일치합니다.

[파츠 확대 비교](review/material-detail-comparison.png)와 [Godot 문턱 근접 화면](review/first-floor-detail-doors.png)을 확인했습니다. 로컬 웹 패키지를 갱신했고 HTTP 응답을 확인했습니다.

## 1층 3D 전환 시안 (v1)

[1층 3D 시안](source/first-floor-3d-concept-v1.png)은 사용자 검토용입니다. 기존 1층의 정문, 천체의가 있는 중앙 회랑, 뒤쪽 계단과 세 방의 배치를 유지하고, 밝은 석재와 청금색·금장, 낮춘 앞벽을 적용한 모습을 제안합니다. 이미지의 투영은 배치·재질 검토용이며 제작 카메라는 본편 2:1 직교 투영을 사용합니다.

ImageGen에는 기존 1층 전체 캡처를 배치·색감 참조로, 실내·야외 타일셋을 비례·재질 참조로, 기존 기하 가이드를 수직선과 기존 공간을 이해하기 위한 참조로 입력했습니다. 승인 후 Blender에서 바닥·벽·문틀·계단을 제작하고 앞벽은 독립 파츠로 나눕니다. GLB를 가져온 Godot 씬에서 정문과 계단 연결, 충돌, 앞벽 가림을 구성합니다. 이 단계의 산출물은 시안 이미지입니다.

## 1층 3D 전환 시안 (v2)

[식물과 빛을 테마로 한 1층 시안](source/first-floor-3d-concept-v2.png)은 따뜻하고 신비로운 분위기를 위한 대안입니다. 호박빛 유리창, 밝은 석재, 짙은 녹색 천을 사용합니다. 중앙 홀에는 빛나는 어린 나무와 떠오르는 씨앗을 두고, 왼쪽 도서관에는 압화와 식물 도감을, 오른쪽에는 수업 책상과 약초 실습대를 배치했습니다.

ImageGen에 기존 1층은 동선 참조로, 여관 캡처와 실내·야외 타일셋은 재질 및 비례 참조로, 기존 기하 가이드는 수직선 참조로 입력했습니다. 이 이미지는 분위기와 재질 검토용입니다. 벽에 가려진 강의실·실습실 문과 통로 폭은 기존 씬을 기준으로 잡고, 모델링에서는 본편 2:1 직교 카메라에 맞춥니다.

## 1층 3D 전환 시안 (v3)

[빛 마법 수업을 테마로 한 1층 시안](source/first-floor-3d-concept-v3.png)은 v2에서 사용자가 좋다고 한 오후 햇살과 창살 그림자, 따뜻한 석재와 목재 색을 이어갑니다. 중앙 화단은 공중에 뜬 유리 프리즘과 낮은 석재 받침으로 바꾸고, 강의실에는 굴절 도식, 실습실에는 떠 있는 유리 렌즈, 도서관에는 책 위에 떠 있는 깃펜을 놓았습니다. 입구 양옆과 몇몇 표본병에 식물을 남겼습니다.

ImageGen의 편집 대상은 v2 시안이며, 실내·야외 타일셋과 기존 기하 가이드를 보조 참조로 사용했습니다. 이 이미지는 분위기와 재질 검토용이며, 실제 본편 카메라와 방 출입구의 기준은 v2와 같습니다.

## 1층 공간 구성 제안

1층은 방문객과 신입생이 마법을 처음 보고, 수업에서 원리를 배우고, 작은 주문을 직접 연습하는 층으로 제안합니다. 3안의 햇살과 프리즘을 첫인상으로 쓰고, 빛은 첫 수업의 소재로 잡습니다.

| 공간 | 방문 이유 | 배치 |
| --- | --- | --- |
| 입학 홀 | 수업 안내를 읽고, 친구를 기다리고, 공중에 뜬 시연용 프리즘을 봅니다. | 정문 앞은 대기 벤치와 작은 안내대, 중앙은 프리즘과 양옆 통로, 뒤쪽은 2층 계단입니다. |
| 기초 서고 | 교재를 찾거나 수업 중 본 주문을 책과 도면에서 찾아봅니다. | 왼쪽 창가에 열람석, 바깥벽에 서가를 둡니다. |
| 입문 강의실 | 칠판과 교탁 앞에서 교수의 주문 시연을 봅니다. | 오른쪽 앞에 배치합니다. 정문에서 가깝고 중앙 홀에서 바로 들어갑니다. |
| 주문 실습실 | 렌즈 각도를 바꿔 빛을 표식에 맞추는 식으로 작은 주문을 연습합니다. | 오른쪽 뒤 창가에 배치합니다. 창에서 실습대까지 빛이 닿도록 가운데를 비우고 도구장은 옆벽에 붙입니다. |

기존 1층의 서고·강의실·실습실 구성을 활용하되, 오른쪽 앞뒤 두 방의 위치를 바꿔 실습실에 큰 창을 배정하는 안입니다. 각 방 문은 중앙 홀로 직접 열리며 정문과 2층 계단은 홀로 연결됩니다. 수업·실습 예시는 공간의 용도를 설명하기 위한 기획이며, 제작 단계에서는 문 폭, 프리즘 양옆 통행, 창과 실습대의 관계를 우선 확인합니다.

### 1층 평면 설계도 (v1)

[1층 평면 설계도](source/first-floor-plan-v1.png)에 문, 창, 계단, 가구의 점유 면적과 주 이동 동선을 표시했습니다. 블록아웃 제안 치수는 외곽 25×21칸, 벽 1칸, 광장 쪽 정문 3칸, 세 방의 문 2칸입니다. 중앙 홀 9칸 너비에 지름 3칸의 프리즘 받침을 두어 양옆에 각각 3칸을 확보합니다. 뒤쪽 실습실의 큰 창에서 들어오는 빛이 렌즈 실습대에 닿도록 배치했습니다.

이 치수는 배치 검토용입니다. Blender 블록아웃에서 학교 외관의 정문 위치 및 2층 도착점과 맞춘 뒤 확정합니다.

## 평면 설계도 적용 3D 시안 (v4)

[1층 3D 시안 v4](source/first-floor-3d-concept-v4.png)에 확정한 방 구성을 적용했습니다. 왼쪽은 기초 서고, 오른쪽 앞은 입문 강의실, 오른쪽 뒤 큰 창가는 주문 실습실입니다. 정문과 중앙 회랑, 프리즘, 뒤쪽 계단이 이어지며 각 방은 홀로 열립니다. 3안에서 선호한 오후 햇살과 호박빛 유리, 낮은 석재 받침의 프리즘을 반영했습니다.

ImageGen에는 25×21칸 평면 설계도와 해당 배치를 옮긴 2:1 직교 투영 가이드를 기하 참조로, 3안과 실내·야외 타일셋을 재질과 조명 참조로 사용했습니다. 실제 모델의 치수와 출입구는 평면도를 따르며, 계단 상단은 2층 도착점과 연결되도록 모델링합니다.

### 휘장 색상 적용 (v5)

사용자 지정에 따라 [파란 휘장 시안](source/first-floor-3d-concept-v5.png)을 제작했습니다. 4안을 ImageGen으로 편집해 벽, 정문, 안내대와 실습대의 휘장 바탕에 짙은 파란색을 적용했습니다. 금색 문양과 테두리를 함께 사용합니다.

## 1층 Blender 모델 (v1)

- 편집 원본은 [arcana-academy-first-floor.blend](source/blender-v1/arcana-academy-first-floor.blend), 전체 장면은 [최종 렌더](source/blender-v1/arcana-academy-first-floor-preview.png)입니다. [제작 스크립트](source/blender-v1/build_academy_floor.py)는 Blender 4.5에서 `--background --python`으로 실행합니다. 가구와 마법·휘장 제작 부분은 같은 폴더의 `furniture.py`, `magic.py`에 있습니다.
- 25×21칸 평면과 파란 휘장 시안을 기준으로 정문, 중앙 프리즘, 2층 계단, 기초 서고, 입문 강의실, 주문 실습실을 모델링했습니다. 2:1 직교 카메라, 평면 카메라, 정문·세 방의 문턱·계단 상단 기준점을 저장했습니다.
- 왼쪽 외벽을 서고에서 정문 쪽 코너까지 연속으로 연결하고, 왼쪽과 뒤쪽 외벽 상단을 바닥 기준 8단위로 맞췄습니다. 정문이 있는 앞쪽 벽은 낮은 단면으로 두었습니다.
- 2층 문은 폭 3단위를 유지하며, 계단참에서 아치가 시작되기까지 2.6단위, 반원 아치 꼭대기까지 4.1단위를 확보했습니다. 저장한 `.blend`를 Blender 4.5.15에서 다시 열어 벽 높이와 문 개구부가 열린 범위를 확인했습니다.
- 서고·입문 강의실·주문 실습실 사이의 칸막이 8개는 가구와 이동 동선이 보이도록 바닥 기준 0.25타일 높이의 단면으로 표시합니다. 저장한 Blender 파일에서 8개 상단 높이를 확인했습니다.
- 화면 아래쪽 두 외벽도 0.25타일 높이로 맞췄습니다. 정문 좌우의 앞벽과 오른쪽 외벽이 만드는 아래 모서리는 1×1타일짜리 덮개석 한 장으로 마감했습니다. 저장한 Blender 파일에서 두 벽의 끝면과 모서리 석재의 끝면이 일치하는지 확인했습니다.
- 뒤쪽 벽의 석재 줄을 벽 전체 너비에 걸쳐 하나의 패턴으로 쌓고, 창 여섯 곳과 2층 문 개구부와 겹치는 부분만 잘라냈습니다. 창마다 생기던 세로 경계를 정리하고 창턱과 문·창 안쪽 모서리를 벽면 안에서 마감했습니다.
- 왼쪽과 뒤쪽 외벽 상단은 같은 1타일 간격의 덮개석으로 마감했습니다. 저장한 Blender 파일에서 양쪽 덮개석의 높이 8과 돌 폭, 창과 2층 문 개구부를 확인했습니다.
- Blender의 길이 스케일은 1.0입니다. 이 모델의 바닥 한 칸은 1×1 Blender 단위이며, 아르카나 Godot 3D의 1×1 월드 단위 타일과 대응합니다.

| 학생 책상 | 4 | 1.52 × 0.80 | 0.90 |
| 학생 의자 | 4 | 0.68 × 0.62 | 0.55 |
| 서고 열람 탁자 | 2 | 2.60 × 1.18 | 0.90 |
| 서고 의자 | 8 | 0.68 × 0.64 | 0.55 |
| 교탁 | 1 | 1.66 × 0.69 | 1.10 |

강의실 가운데 통로는 0.90칸, 앞줄 의자 뒤에서 뒷줄 책상까지는 0.75칸입니다. 칠판 윗변은 바닥에서 2.25칸이고 대기 벤치 좌판은 0.60칸입니다. 가구를 옮길 때는 [1층 이동 레이아웃](../../../godot-arcana/scripts/academy_first_floor_layout.gd)의 충돌 범위도 같은 치수로 맞춥니다.

## 1층 게임 연결

- 활성 `arcana_academy:1`은 [3D 1층 씬](../../../godot-arcana/scenes/academy_first_floor_3d.tscn)을 사용합니다. 이 씬은 [Blender GLB](../../../godot-arcana/art/source/academy-first-floor-blender/academy-first-floor.glb)를 같은 1타일 스케일로 불러옵니다. [GLB 내보내기 스크립트](source/blender-v1/export_academy_first_floor.py)는 편집 원본을 유지하고 Godot에서 쓸 정적 메시를 출력합니다.
- [1층 이동 레이아웃](../../../godot-arcana/scripts/academy_first_floor_layout.gd)의 정문·계단·방 좌표와 충돌을 클라이언트와 서버 데이터에서 함께 사용합니다. 기존 지역 ID로 광장 입장·귀환과 2층 왕복을 연결합니다. 2층은 `arcana_academy:2`에서 관리합니다.
- Godot 4.5.1 내보내기에서 1층 씬, GLB, 계단 기준점과 렌더 설정을 패키지에서 확인했습니다. 새 이동 레이아웃을 읽도록 로컬 서버를 다시 시작했고, `localhost:3000`이 제공하는 압축 PCK를 해제해 빌드 파일과 SHA-256이 같은 것을 확인했습니다.

## 텍스트 모드 실내 맵

내 집·식당과 같은 5×5 격자를 모바일 세로 화면에 사용합니다. 월드맵에서 마법학교에 들어오면 1층 실내 맵을 열고, 정문 칸에 입장 위치를 표시합니다. 이후에는 실제로 있는 층의 맵을 표시합니다. 중앙 세로줄은 회랑과 계단으로 연결하고, 방 이름과 아이콘은 실제 출입 방향에 맞춰 둡니다. 아래 좌표는 5×5의 왼쪽 위가 `(0, 0)`인 텍스트 지도 좌표입니다.

| 층 | 칸 (열, 행) | 표시 이름 | 선택했을 때 |
| --- | --- | --- | --- |
| 1층 | (2, 0) | 2층 계단 | 2층 계단참에 도착합니다. |
| 1층 | (4, 1) | 수정 실습실 | 청강 등록과 이론 수업을 마치면 수정 제어 실습을 진행합니다. |
| 1층 | (0, 2) | 도서관 | 노엘에게 안내를 받습니다. 첫 수업을 마치면 관측탑 의뢰를 받을 수 있습니다. |
| 1층 | (2, 2) | 중앙 회랑 | 프리즘이 있는 홀에서 수업 안내를 확인합니다. |
| 1층 | (4, 3) | 기초 강의실 | 청강 등록 뒤 리네 교수의 이론 수업을 듣습니다. |
| 1층 | (2, 4) | 정문 | 분수 광장으로 나갑니다. |
| 2층 | (0, 1) | 교장실 | 에드윈에게 청강생 등록을 신청하거나 첫 수업을 마쳤다고 보고합니다. |
| 2층 | (4, 1) | 천문 관측탑 | 도서관에서 관측탑 의뢰를 수락한 뒤 천문판을 살펴봅니다. |
| 2층 | (0, 3) | 별빛 정원 | 스텔라를 만납니다. |
| 2층 | (2, 4) | 1층 계단 | 1층 계단 앞에 도착합니다. |

- 밝은 석재색 회랑으로 중앙축을 읽게 하고, 방의 연한 바닥색과 벽선의 문틈으로 구획을 나타냅니다. 현행 텍스트 맵처럼 현재 칸은 하늘색 테두리와 모서리 표시를 사용합니다. 책·정문은 공용 아이콘을 우선 사용하고, 새 24×24 도트는 계단·프리즘·칠판·수정·교장 책상·화분·망원경을 후보로 잡습니다. 계단은 같은 실루엣에 위·아래 방향을 표시합니다.
- 방을 누르면 해당 장소 설명을 바로 표시하고, 입장 가능한 방은 기존 학교 이동에 연결합니다. 이동 성공 후 현재 방 표시와 해당 방의 이야기·선택지를 함께 갱신합니다. 잠긴 방은 칸에 자물쇠를 표시하고, 누르면 지금 필요한 조건을 맵 아래에서 안내합니다. 현재 위치는 그대로 표시합니다.
- 이동 시안에서는 주인공의 얼굴 초상화가 현재 칸의 아이콘 자리에 놓입니다. 열린 방을 누르면 복도와 문을 지나 그 방으로 움직이고, 계단에 도착하면 층을 바꿔 반대편 계단참에 표시합니다. 개정 얼굴은 주인공 v12의 연보라 단발에 둥근 보라색 눈과 작은 미소를 더한 32×32 도트입니다. 내장 ImageGen에 v12 정면 얼굴을 참조로 넣어 단순하고 귀여운 정면 얼굴 시안을 만든 뒤, 앞머리·눈·볼을 32픽셀 격자에 맞춰 PixelPen에서 다시 그렸습니다. 머리·얼굴과 표정은 두 레이어로 편집할 수 있습니다. [얼굴 시안](../../text-mode-mobile-v1/academy-player-portrait-v2-concept.png) · [PixelPen 원본](../../text-mode-mobile-v1/academy-player-portrait-32.pxpen) · [투명 PNG](../../text-mode-mobile-v1/academy-player-portrait-32.png)
- 방 ID와 잠금 안내는 `academyMap`의 서버 값을 사용합니다. 첫 방문의 `courtyard`는 정문 칸에 표시하며, 정문에서 나가기는 `exit` 동작에 연결합니다. 층이 바뀌면 현재 방보다 도착한 계단참을 우선 표시합니다. 재접속이나 실패에서도 실제 층과 마지막으로 확정된 위치를 기준으로 표시합니다. 하단 월드맵은 기존 공용 버튼을 사용합니다.
- 첫 수업은 2층 교장실 등록 → 1층 기초 강의실 이론 → 수정 실습실 → 도서관 안내 → 2층 교장실 보고 순서입니다. 관측탑은 이후 도서관 의뢰를 받은 뒤 공용 계단으로 올라갑니다.

본편 텍스트 모드는 정문 입장과 계단 이동 뒤 실제 층의 맵을 표시합니다. 월드맵과 실내·실외 지역 지도는 같은 얼굴 초상화와 칸 이동을 사용합니다. 월드맵에서는 표시된 길, 실내에서는 벽과 문틈을 기준으로 경로를 그립니다. 실내 지도 표시는 기본 크기의 75%로, 이전 50%에서 가로와 세로가 각각 50% 커졌습니다.
