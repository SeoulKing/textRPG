# 뿔소 초원

## 요청과 현재 단계

- 지역 ID는 `arcana_meadow_field`입니다.
- 아르카나 월드맵 (5, 5)에서 초원으로 이동하고, 진흙코 뿔소를 쓰러뜨리면 고기 `rawMeat`를 얻습니다.
- 게임 연결과 기존 자산을 활용한 배치를 진행합니다. 별도 환경 미술 시안은 사용자 승인 대기 중입니다.

## 디자인 기준과 승인

- [초원뿔소 외형 후보 5종](monster-concept-options.png) 중 2번 진흙코 뿔소를 사용자님이 선택하셨습니다. 위 왼쪽부터 풀잎뿔소·진흙코 뿔소·밤송이 뿔소, 아래 왼쪽부터 조약돌 뿔소·구름얼룩 뿔소입니다.

- [이전 초원뿔소 시안](concept-v2.png)은 검은 바위뿔과 등갑, 가늘게 뜬 황금빛 눈, 앞발을 벌리고 머리를 낮춘 돌진 준비 자세를 보여줍니다. [초기 시안](concept.png)의 초원 구도와 남쪽 진입로를 사용합니다.
- [월드 제작 기준](../../../docs/roles/WORLD_BUILDING.md)에 따라 통행 영역과 표시 위치를 맞춥니다.
- 게임 장면은 `godot-arcana/art/export/reference/`의 `grass.png`, `grass-clump.png`, `flowers.png`를 재사용합니다.
- 환경 시안은 사용자 확인 대기 중입니다.

## 지역 구조

- 월드맵의 다섯 번째 열과 다섯 번째 행은 내부 0 기반 좌표 `Vector2i(4, 4)`에 대응합니다. 저장되는 지도 데이터의 축 좌표는 `q=5, r=5`입니다.
- [지역 장면](../../../godot-arcana/scenes/native_2d/meadow_field.tscn)의 이동 범위는 `(0, 0)–(384, 320)`입니다. 지도 X는 오른쪽, Y는 아래로 증가합니다.
- 진입점은 `(192, 272)`입니다. 진흙코 뿔소의 기본 위치 `(192, 160)`까지 가운데에 통행 공간을 둡니다. 씬의 원본 도트 좌표는 각각 `(768, 1088)`, `(768, 640)`입니다.
- 광장에서 월드맵의 뿔소 초원을 선택하면 초원의 3×3 내부맵으로 들어갑니다. 진흙코 뿔소는 가운데 칸 (2, 2), 초원 입구는 아래 가운데 칸 (2, 3)에 있습니다. 초원 입구를 누르면 분수 광장으로 돌아갑니다.
- [지역 레지스트리](../../../godot-arcana/data/regions.json)에서 씬과 카메라 범위를, [서버 지역 데이터](../../../src/game/arcana-meadow.ts)에서 지도 위치와 이동 기준점을 관리합니다.

## 진흙코 뿔소 도트

- [PixelPen 편집 원본](../../../godot-arcana/art/source/monsters/meadow-ox/meadow-ox.pxpen)의 64×64 프레임 3장을 가로로 이어 [게임용 투명 PNG](../../../godot-arcana/art/export/monsters/meadow-ox.png)로 출력합니다. 왼쪽부터 대기, 돌진 준비, 돌진이며 발 기준점은 각 프레임의 (32, 56)입니다.
- PixelPen의 각 프레임에 후보 2번 참조 레이어를 숨겨 두었습니다. 저장한 원본을 다시 열어 출력하고, 1배와 4배에서 외곽선과 세 자세의 발 기준점을 확인했습니다. 실제 사용 색은 불투명 18색이며 투명도는 0과 255입니다.
- 게임의 기존 저장 ID `meadow_ox`와 `meadow-ox`가 같은 진흙코 뿔소를 가리킵니다.

## 적용과 확인

| 항목 | 확인 범위 |
| --- | --- |
| 지역 연결과 기존 저장 | 현재와 과거 콘텐츠 버전에서 초원과 왕복 경로를 읽는 코드를 확인합니다. |
| 시점과 배치 | 씬과 서버 이동 범위의 참조를 확인합니다. 기본 카메라와 실제 접지는 Godot 편집기에서 확인합니다. |
| 플레이 확인 | 월드맵 (5, 5)에 들어가서 진흙코 뿔소를 사냥한 뒤, 소지품의 고기 수량이 늘어나는지 확인합니다. |
