# 상점 3D 픽셀 시제품 — 진행 중

- 범위: 현재 상점의 배치와 거래·출입을 유지하면서 블렌더 3D 모델과 픽셀 표현을 시험합니다.
- 승인된 전체 시안: `approved-concept.png` (사용자 승인). 시안은 최종 게임 렌더가 아닙니다.
- 블렌더 원본: `shop-cabinets.blend`; 원본 생성 코드: `build_cabinets.py`.
- 약초·포션·여행 진열장 실험 모델: `herb-cabinet.glb`, `potion-cabinet.glb`, `travel-cabinet.glb`.
- `cabinet-workbench0001.png`는 입체 형상 확인용 Blender Workbench 렌더입니다. 실제 조명·픽셀 렌더가 아닙니다.
- 위 세 모델은 초기 실험본입니다. 아래의 개선된 모델을 상점에 연결했으며 실제 게임 화면 확인은 남아 있습니다.
- 생성 시 Blender 5.3의 EEVEE 미리보기 실행이 종료되어 Workbench로 전환했습니다. 원인은 확인하지 못했습니다.
- 기존 상점은 `scenes/shop_2d.tscn`의 배치로 `scenes/shop_3d.tscn`을 조립하며, 상호작용·충돌·출입 좌표는 이 데이터가 원본입니다.
- Godot AI에 연결된 편집기 세션이 없어 게임 장면의 실제 3D 뷰포트는 확인하지 못했습니다.

## 참고한 렌더링 원칙

사용자가 제공한 [Pixel Perfect 영상](https://www.youtube.com/watch?v=Mp7eQsiZ_wA)과 [제작자의 보충 설명](https://www.patreon.com/RedGiraffe404/posts/post-mortem-ep-1-153340013)을 기준으로 합니다. 영상 본문은 도구에서 직접 열리지 않아 영상 전체를 시청했다고 간주하지 않습니다.

- 일정한 저해상도 격자와 최근접 샘플링으로 화면 픽셀 크기를 통일합니다. 원본 구현은 고해상도 렌더 후 축소를 소개하지만, 제작자는 이후 낮은 해상도 직접 렌더도 사용했다고 설명합니다.
- 색 제한은 OKLab 같은 지각 색 공간을 고려합니다. 고정 팔레트의 실시간 반복 탐색보다 미리 계산한 LUT를 검토합니다. 팔레트가 캐릭터·기존 미술에 미치는 영향은 별도로 확인합니다.
- 픽셀 격자와 움직이는 카메라의 흔들림은 별도 문제입니다. 이 영상의 정지 화면 효과를 움직임의 안정성이 확보된 것으로 취급하지 않습니다.
- 프로젝트의 실제 사용자 화면은 `main.gd`의 SubViewport로 표시되며 UI는 별도입니다. 변경 전 입력 좌표 변환, 화면 크기, UI 선명도와 기존 캐릭터 색 보존을 확인합니다.

## 입체 진열장과 상점 픽셀 격자 연결

- 블렌더 원본: `shop-cabinets-detailed.blend`, 제작 코드: `build_detailed_cabinets.py`, 형상 미리보기: `cabinet-detailed-preview.png`.
- 승인된 기존 진열장 PixelPen 출력의 앞면·윗면 그림을 재사용하고, 입체 몸체·기둥·금장 돌출부를 제작했습니다. 이 버전은 선반 속 상품을 그림으로 보존했으며 아래의 v3에서 입체 상품으로 교체했습니다.
- 이전 제작 GLB 3종은 `godot-arcana/art/source/shop-cabinets-3d-v2/`에 있습니다. `shop_room_geometry_3d.gd`는 기존 배치와 크기에서 모델을 불러오고 원래 충돌 데이터를 연결했습니다. 현재 연결은 아래 v3입니다.
- 상점 월드에만 `shop_pixel_grid.gdshader`의 최근접 정수 격자를 적용합니다. UI는 별도 합성됩니다. 기존 캐릭터와 가구 색 보존을 위해 OKLab 팔레트 양자화는 적용하지 않았습니다.
- Godot 4.5.1 편집기 가져오기로 세 GLB를 PackedScene으로 가져왔고, 오류로 드러난 main.gd 타입 선언을 수정했습니다.
- Godot AI v4 플러그인은 Godot 4.7 이상이 필요해 현재 4.5.1 프로젝트에서 활성화되지 않습니다. 따라서 Godot 뷰포트의 실제 화면, 움직임 중 격자 안정성, 거래·출입은 확인하지 않았습니다. 웹 산출물도 새로 내보내지 않았습니다.
## 선반 상품 입체 모델 v3

- Blender 원본은 `shop-cabinets-3d-wares.blend`, 재생성 스크립트는 `build_3d_wares.py`입니다. 기존에 열린 Blender 문서는 변경하지 않았습니다.
- `cabinet-3d-wares-preview.png`는 모델 형태 확인용 Workbench 렌더, `cabinet-3d-wares-pixel-preview.png`는 400×240 저해상도 Blender 렌더입니다. 두 이미지는 실제 Godot 상점 캡처가 아닙니다.
- 포션 15병, 약초·바구니, 책·여행 가방·두루마리·나침반은 각각 3D 기하로 제작했습니다. 진열장 몸체의 선반은 깊이가 있으며, 기존 도트 이미지는 나무·기둥·장식에만 사용합니다.
- 게임 연결: `godot-arcana/art/source/shop-cabinets-3d-v3/`의 세 GLB를 `shop_room_geometry_3d.gd`에서 선택합니다. 같은 진열장 종류를 원래 배치만큼 인스턴스화하고 기존 크기·충돌을 사용합니다. `main.gd`의 상점 전용 정수 픽셀 격자가 3D 물체에도 적용됩니다.
- 각 GLB는 하나의 메시이며 약초장 2,756, 포션장 3,472, 여행장 1,184개 삼각형입니다.
- Godot 4.5.1 가져오기를 완료했습니다. 이 프로젝트의 Godot AI 플러그인은 4.7 이상에서만 활성화되므로 Godot 뷰포트의 색상·조명·이동 중 픽셀 안정성과 거래·출입은 미확인입니다. OKLab 팔레트 양자화와 웹 내보내기는 적용하지 않았습니다.
## 포션병 부드러운 음영

- 사용자의 요청에 따라 열려 있던 블렌더 작업에서 포션 색 재질의 옆면만 Shade Smooth로 설정했습니다. 병마개·선반·가구의 모서리는 변경하지 않았습니다.
- 작업 사본은 `shop-cabinets-smooth-v1.blend`, 게임에 연결한 GLB는 `godot-arcana/art/source/shop-cabinets-smooth-v1/`입니다. 열린 원본의 미저장 상태와 선택은 보존했습니다.
- 블렌더 정점·면 수는 변경되지 않았으며, 내보낸 약초장 2,756개·포션장 3,472개 삼각형도 이전과 같습니다.
- 기존 v3 생성 스크립트는 이 수동 음영 수정과 열려 있던 파일의 편집을 포함하지 않습니다. 게임용 모델을 재생성할 때는 부드러운 음영이 적용된 작업 사본을 사용합니다.
- Godot 4.5.1에서 두 모델을 다시 가져왔습니다. Blender 뷰포트에서는 부드러운 음영을 확인했으나 실제 Godot 상점 화면은 확인하지 않았습니다.
## Godot 상점 화면 확인

- Godot 4.5.1의 Compatibility 렌더러에서 실제 `native_2d_world.gd`, `shop_3d.tscn`, 현재 연결된 GLB와 상점 픽셀 셰이더를 사용한 오프라인 GPU 화면을 확인했습니다. 계정·서버·저장 데이터를 사용하지 않았습니다.
- [상점 전체](godot-review/godot-shop-overview.png), [진열장 확대](godot-review/godot-shop-bottles.png). 확대 화면은 검사 카메라를 선반에 맞춘 이미지입니다.
- 포션병의 부드러운 음영과 모델 표시를 확인했습니다. 10면 병의 픽셀 외곽에는 각이 일부 남고, 불투명 단색 재질은 유리보다 플라스틱처럼 보입니다.
- HUD, 실제 서버·거래·이동과 움직일 때 픽셀 안정성은 이 정지 화면에서 확인하지 않았습니다. Godot AI 플러그인의 4.5.1 미호환 상태는 그대로입니다.
