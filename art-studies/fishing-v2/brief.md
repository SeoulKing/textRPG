# 강 낚시 v2 · 승인 후 제작

대상: Godot 아르카나의 낚싯대 장비, 전방 강물 판정, 던지기·입질·포획 월드 연출.
상태: 사용자가 concept-v1.png를 승인하고 낚싯대 장비·전방 강물 낚시·웹 빌드를 요청했습니다. 컨셉 자체를 잘라 쓰지 않고 기존 캐릭터의 동일 방향 원본에서 낚시 자세를 제작했습니다. 현재 제작·연결 정보와 검증 범위는 아래 README를 따릅니다.

## 기능과 연결 범위

- 기존 강 낚시 4개 지점 제한을 전방 강물 판정으로 교체합니다. 육지 위 플레이어의 바라보는 방향에서 낚싯줄 사거리 안의 실제 강물 지점을 찾습니다. 다리 상판·건물·일반 바닥에는 찌를 놓지 않습니다. 양쪽 둑과 이동된 강의 실제 기하를 따릅니다.
- 강 영역과 다리 제외 영역은 저장된 활성 강 장면에서 추출해 클라이언트와 서버가 공유합니다. 낚시 자리 목록을 또 다른 수작업 좌표 목록으로 늘리지 않습니다. 서버는 자신의 플레이어 위치·방향·장비로 재판정합니다.
- 낚싯대는 새 아이템으로 등록하고, 소지품 → 장비의 생활 도구 슬롯에서 장착·해제합니다. 장착 상태는 서버에 저장합니다. 첫 기본 낚싯대 1개를 기존·신규 캐릭터에 한 번 지급하는 방안으로 준비하며, 이후 새로고침·낚시 때 중복 지급하지 않습니다.
- 전투 슬롯과 별개의 생활 도구 슬롯을 사용합니다. 낚싯대 소유와 장착을 모두 확인하고, 전투·낚시 중에는 교체를 막습니다. 미장착 시 필요한 행동을 짧게 안내합니다.
- 장착한 낚싯대는 캐릭터의 손과 연결합니다. 던지기 → 대기 → 입질 → 챔질/릴 조작 → 포획 또는 실패/취소 → 대기 복귀의 상태 전환을 둡니다. 연출 종료가 보상 재지급 요청을 만들지 않게 합니다.
- 던질 때 준비·팔 스윙·찌의 포물선·착수 파문, 입질에는 찌 흔들림·잠김·작은 물방울, 릴 조작에는 휘는 낚싯대·긴장한 줄, 성공 시 물고기 호 궤적·물방울·회수를 표현합니다.
- 현재 중앙 낚시창이 캐릭터와 찌를 가리지 않도록 조작 영역을 재배치합니다. 기존 Space/E·터치 누르기/떼기와 숙련도·아이템의 서버 확정 규칙을 유지합니다.

## 제작 기준

- 기존 백발 단발·보랏빛 눈·하늘색 숄·흰 드레스·작은 손·가는 손목·발 피벗을 보존합니다. 도구/찌/물고기 이펙트를 별도 자산으로 두며 기존 기본 동작 시트를 덮어쓰지 않습니다.
- 낚싯대는 갈색 나무 몸체, 남색 손잡이, 작은 황동 결속, 빨강/상아색 찌입니다. 최종 물고기와 도구 크기는 승인 캐릭터와 같은 픽셀 밀도에서 조정합니다. 시안의 배경은 새 지도나 강 교체 지시가 아닙니다.
- 같은 방향의 확정 인물 원본에서 핵심 자세를 편집하고, 기존 CHARACTER_ANIMATION_PIPELINE.md에 따라 PixelPen에서 일관성을 보정합니다. 후보 편집 원본·프레임·출력·실제 연결 상태를 구분합니다. 방향별 손잡이·줄 끝·찌 위치·가림을 함께 확인합니다.
- 승인 후 필요한 서버/클라이언트 변경과 웹 내보내기를 수행합니다. 테스트·브라우저 조작은 사용자 요청이 있을 때만 합니다.
