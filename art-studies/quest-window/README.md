# 아르카나 퀘스트 창

2026-10-29 승인 시안: [approved-concept.png](approved-concept.png). 내장 ImageGen으로 제작한 검토용 이미지이며 예시 의뢰·수량을 게임 데이터로 추가하지 않습니다.

- 아이보리 바탕, 남색 글자, 파란 강조와 얇은 금색 테두리.
- 조건 이름과 현재 / 필요 수량을 표시합니다. 미달 수량은 주황색, 달성 수량은 초록색입니다.
- 진행바, 부족·충족·남음 문구, 체크 표시와 색상 범례를 넣지 않습니다.
- 승인 후 추가 지시: 아이템 조건에만 해당 아이템 썸네일을 사용합니다. 안내·이론·실습·처치 등 행동 조건에는 썸네일과 빈 아이콘 칸을 넣지 않습니다. 썸네일이 없는 아이템은 기존 텍스트를 유지하며 임시 그림으로 대체하지 않습니다.
- 진행 중·미수락·완료 목록, 보고 가능 상태, 보고 대상과 실제 보상을 표시합니다. 위치는 기존 지도 메뉴로 연결하며 자동 추적 기능을 새로 만들지 않습니다.

원본: `godot-arcana/scripts/quest_view.gd`, 연결: `game_ui.gd`, `main.gd`.
서버 표시 데이터: `src/game/quest-guidance.ts`, `arcana-economy.ts`, `schemas/session.ts`, `service.ts`. 학교 보고 가능 여부는 실제 완료 행동의 조건으로 판정하며 게임 규칙·보상·저장 상태를 변경하지 않습니다.
