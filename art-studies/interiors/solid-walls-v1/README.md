# 실내 벽 정리와 공통 카메라

상점·여관 윗벽의 창문을 제거한 변형입니다. 기존 cornice와 양끝 마감을 유지하며, 활성 자산은 shop-interior/back-wall-solid.png(904×262) 및 inn-lobby/wall-solid.png(276×216)입니다. 큰 master.png는 생성 원화이며 게임에 직접 표시하지 않습니다. 재패키징: node scripts/package-solid-interior-walls.cjs.

여관 책장을 z4.2에서5.0으로 내려 벽 상단 돌출을 해소하고, 로컬·서버 충돌 사각형 y를42에서55로 맞췄습니다.

공통 실내 카메라는 방 전체가 화면에 보이면 방 중심, 가로·세로 어느 축이든 잘리기 시작하면 캐릭터 중심입니다. 실제 방 크기와 화면 비율로 판정합니다. 상점·여관·학교·기타 실내에 공통 적용합니다. overview/zoom 이미지는 Godot 오프라인 렌더이며 실제 브라우저 플레이 검증은 실행하지 않았습니다.
