# 게임 규칙과 서사 학습 메모

[학습 메모 색인으로 돌아가기](../LESSONS.md). 현재 작업에 해당하는 항목만 확인합니다. 각 행의 재검토 조건을 함께 적용합니다.

| 범위 | 관찰 또는 실패 지문 | 다음 결정 | 재검토 조건 |
| --- | --- | --- | --- |
| 재고 노드 설계 | 사용자는 내용물이 비어도 남는 보관함과, 모두 수집하면 장소·진입 선택지가 사라지는 더미를 서로 다른 종류로 봅니다. | 보관함은 `depletionBehavior: "remain"`을 유지하고, 소진 시 사라질 더미에만 `"disappear"`를 지정합니다. | 사용자가 재생성·리필되는 세 번째 재고 노드 유형을 요구할 때 |
| 시스템 노트 표기 | 시스템 노트는 아이템·시간·장소·능력치·퀘스트 등 실제 상태 변화만 보여줍니다. 변화가 없는 선택지 이름이나 메뉴 이탈 문구를 대체 문구로 표시하지 않습니다. 아이템 칩은 `systemNoteEntries`의 `item` delta와 `+수량 아이템명` 순서를 사용합니다. 아이템 획득 칩은 기존 게임 문법인 `+수량 아이템명` 순서를 사용하며, 문자열 조립 대신 `systemNoteEntries`의 `item` delta로 저장해야 초록색 칩과 현재 아이템명을 일관되게 적용할 수 있습니다. | 시스템 노트는 이전 상태와 다음 상태의 차이에서 생성하고, 변화가 없으면 비웁니다. 보상은 중앙 포매터를 통해 `+1 캔 음식 / +1 진통제`처럼 표시합니다. 노트는 현재 `.scene-story-block` 안에서 서사의 끝과 16px 간격으로 배치해 스크롤용 최소 높이가 노트를 밀어내지 않게 합니다. 보상 시스템 노트는 중앙 포매터를 통해 `+1 캔 음식 / +1 진통제`처럼 만들고 `+캔 음식 1개`나 `캔 음식 1개` 같은 자유 문자열을 새로 만들지 않습니다. | 사용자가 시스템 노트의 표시 대상이나 표기 규칙을 변경할 때 사용자가 시스템 노트 표기 규칙 자체를 변경할 때 |
| NPC 선택 후 서사 | 사용자는 두 문단을 `첫 문단=행동`, `둘째 문단=배경`처럼 고정하면 단조롭게 느낍니다. 선택별 선행 문단이 결과와 어긋나고, NPC 반응과 다음 선택을 분리하면 한 턴에 두 호출이 필요합니다. | 두 문단 모두 플레이어의 말·행동·시선·거리·사물·소리를 장면에 맞게 섞고 선택지마다 순서와 호흡을 바꿉니다. 단, NPC의 새 반응은 다음 `npc_reply` 역할에 남깁니다. NPC 반응·다음 답변 세 개·짧은 속말을 한 요청으로 받고 클릭 중에는 속말만 표시합니다. 실제 선택한 말과 반응은 결과에서 연결하며, 속말을 NPC가 들은 대사로 취급하지 않습니다. 부분 실패는 유효한 본문을 유지하고 잘못된 선택·속말만 로컬 보완합니다. | 사용자가 대화 서사의 문단 수나 역할 분담을 다시 지정할 때 사용자가 역할별 분리 생성이나 선행 서사 방식을 다시 명시할 때 |
| 아르카나 전투 시간 표시 | 사용자는 적 공격 예고와 파이어볼·회피 쿨타임을 숫자 카운트다운보다 줄어드는 바로 보는 것을 선호합니다. 사용자는 던전런의 밋밋함을 정보 전달 부족과 연결해 지적했습니다. | 바의 왼쪽을 고정하고 오른쪽 끝이 왼쪽으로 줄게 하며, 서버의 남은 시간과 일시정지를 따릅니다. 파이어볼·회피 쿨타임은 선택지 전체의 약간 진한 배경으로 표시합니다. 선택지 공통 자식 위치·레이어 규칙보다 구체적인 선택자를 사용하고 비활성 투명도로 바가 흐려지지 않게 합니다. 플레이어·적 체력 모두 빨간 현재 HP와 지연 감소하는 주황색 피해 잔상으로 구분합니다. 적 예고 문구는 3초 전부터 ‘도약 준비 중’, 1초 전부터 ‘도약 임박’만 표시하고 그전에는 비웁니다. 보라색 공격 예고 바도 3초 전부터만 표시하고, 3초 구간을 100%로 삼아 도약 순간까지 줄입니다. 회피 준비 안내는 붙이지 않습니다. 스킬 연출은 무음으로 만들고 명중 순간에 피격 모습·피해 숫자·체력 감소를 맞춥니다. 현재 단계·적의 예고·대응 스킬·실제 결과를 먼저 보여주고, 선택 효과는 현재 수치와 선택 후 수치로 비교합니다. 별빛 회랑의 전투 기록과 전리품 세부 정보는 주요 행동 아래에 둡니다. 아르카나 평원 전투는 적 일러스트·이름·체력·공격 예고를 하나의 카드로 묶고, 본문에 장소명·플레이어 능력치·성장 정보·최근 전투 기록을 중복 표시하지 않습니다. 상황 설명과 전투 결과 문장은 적 카드 아래의 본문 서사 영역에 둡니다. 아르카나에서는 상단과 상태의 기력바를 경험치바로 바꾸고, 상태에 마력(마법 공격력)을 별도 수치로 표시하며 성장 요약 문구는 두지 않습니다. | 사용자가 시간·피해 표시 방식을 다시 지정할 때 사용자가 서사 중심이나 다른 전투 화면 구성을 명시할 때 |
| 선택 직후 독백 | 사용자는 미리 작성한 행동 서사가 결과 장면과 맞지 않아 탐색과 NPC 대화에서 제거하고, 계산대의 “돈이 좀 있을래나.”처럼 상황을 짚는 짧은 속말을 원합니다. | 탐색의 독백은 기존 결과 요청에서 다음 선택지와 함께 생성하고 클릭 즉시 서사 영역에 타이핑합니다. 선택지 안에는 독백을 넣지 않습니다. 숨은 물건·수량·성공·행동 완료를 단정하지 않으며, 결과 본문에는 실제 행동부터 쓰고 속말은 반복하지 않습니다. 추가 요청이나 미래 행동 결과의 사전 생성은 하지 않습니다. 구버전 NPC 선행 문단은 대화 기억의 사실 문맥에도 넣지 않습니다. | 사용자가 독백 위치나 선행 서사 방식을 다시 지정할 때 |
| 선택지 UI | 사용자는 대피소 시안을 확인한 뒤 표형 선택지의 공통 적용을 승인했습니다. 서사와 같은 배경, 행 사이 간격 없음, 얇은 구분선, 왼쪽 선택 문구·오른쪽 효과 설명을 선호합니다. 사용자는 한 장면에 선택지가 길게 늘어나는 구성을 부담스럽게 느끼며, 일반적으로 3개를 선호합니다. | 모든 일반 게임 선택지에 공통 스타일을 사용하고 긴 문구·설명은 잘리지 않게 줄바꿈합니다. 탐색의 기본 선택지에는 방 상태 재정리나 기존 이동 메뉴와 중복되는 일반 지역 이동·귀환을 넣지 않고, 가능한 행동이 적으면 반복 행동으로 개수를 채우지 않습니다. 손에 쥐기·보관·놓기 같은 세부 조작은 주변과 물건에 두고, 기본 추천은 대화·주요 생계 활동·발견처럼 다양한 실제 목적을 우선합니다. 보이는 인물과의 대화는 접근까지 한 의도로 제공하며, 선택 선호가 안전·새 발견·실행 조건을 앞서지 않도록 합니다. 새 디자인 방향을 시험할 때는 한 화면에서 먼저 비교합니다. Unity 게임 UI는 둥근 바깥 카드·서사 말풍선 없이 평평한 상태줄, 그림 아래 서사, 구분선 선택지로 구성합니다. 미리보기 수정 시 로컬 Unity 소스·빌드 스크립트·WebGL 산출물을 함께 맞춰 재빌드로 이전 디자인이 돌아오지 않게 합니다. 장면의 핵심 선택지는 3개를 목표로 하고, 아이템·도구 등 상황별 추가 선택지를 포함해도 총 5개를 넘기지 않습니다. 웹 게임의 일반·퀘스트·제작·던전 선택지는 모두 카드 배경·둥근 외곽선·그림자 없이 얇은 구분선으로 나눕니다. 선택 가능·강조 상태도 카드 형태로 되돌리지 않습니다. | 장소 내 서사 연속성 | 사용자는 탐색의 선행 행동 서사와 결과의 어긋남을 없애고 대기를 자연스럽게 만들길 원합니다. | 선택 직후 서사 영역에 짧은 속말을 추가하고 그때 한 번만 넘깁니다. 중복 입력 잠금을 지키며, 결과는 속말 아래 같은 페이지에 이어 붙이고 다시 넘기지 않습니다. 선택지 채움 연출은 1초로 하되, LLM 응답이 먼저 준비되면 연출이 끝날 때까지 일부러 지연하지 않습니다. 선택지 대기 표시는 왼쪽에서 오른쪽으로 한 번 차오른 뒤 유지하고, 반복 쓸기·점멸 효과를 넣지 않습니다. 타이핑 건너뛰기에는 다시 스크롤하지 않습니다. 이전 문단 읽기와 숨긴 스크롤 막대는 유지합니다. | 사용자가 대기 중 본문 이동이나 장면 연결 방식을 새로 지정할 때 |
| 기존 저장의 콘텐츠 수정 | 사용자는 삭제한 요리와 통합한 재료가 기존 게임에도 즉시 반영되기를 기대합니다. 새 게임과 Studio 데이터만 바꾸면 저장에 고정된 콘텐츠 버전이 옛 목록을 되살립니다. 고정된 옛 선택 ID는 실제 생존 경로를 검증하지 못하며, 객체 순서를 보존하는 메모리 저장소만으로는 JSONB 복원 후 선택지가 달라지는 오류를 놓칩니다. | 명시적 삭제·통합은 런타임 레지스트리에서 적용해 목록·조건·실제 효과·재료 획득 경로를 함께 맞춥니다. 보관된 버전 원본과 플레이 진행은 유지하고, 옛 저장을 불러오는 테스트를 포함합니다. 탐색 어댑터나 선택 ID를 바꾸면 생존 경로도 현재 서버가 제공하는 선택으로 실행하며 재료·시간을 주입하지 않습니다. 저장되는 동적 선택지는 객체 키를 재정렬하되 배열 순서는 보존한 뒤 실제 정규화 경로를 거쳐, 표시·재조회 ID의 일치와 각 표시 행동의 실행을 확인합니다. 새 세계는 소지품 이전과 손 상태 정규화를 끝낸 뒤 최초 선택지를 계산하고, 첫 재조회에도 같은 선택이 유지되는지 검사합니다. | 사용자가 특정 저장에 구버전 규칙을 유지하라고 명시할 때 해당 지역이 생존 경로에서 빠지거나 저장소·선택지 계약이 바뀔 때 검증 범위를 다시 판단합니다. |
| 탐색 서술 시점 | 사용자는 지역 탐색·수집을 텍스트 렌더링으로 전환하고, 기존 선택의 의도된 대기 연출을 유지하기를 원합니다. 자신을 나로 두되 나는·나의 반복을 줄이고, 직접 겪는 행동·감각·결과로 소설처럼 이어지는 글을 원합니다. | 텍스트 월드는 사용자가 고른 B 문체인 감각과 시선이 머무는 소설체로, 주어를 주로 생략한 1인칭 현재 시제로 작성합니다. 여러 동작은 관찰과 접촉 안에 연결하고 짧고 긴 문장을 섞되 데이터에 없는 감각이나 감정·사연을 만들지 않습니다. 실제로 하지 않은 자세 변경과 이동·수집 결과의 생략, 출입구 혼동은 관찰된 생성문을 기준으로 검사합니다. | 사용자가 시점·시제 또는 서술 방향을 새로 지정할 때 |
