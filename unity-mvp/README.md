# 폐허 서울: 숲 Unity MVP

기존 웹 게임의 **숲**을 한 장면으로 옮긴 Unity 6 프로토타입입니다. 플레이어는 방향키로 움직이지 않습니다. 화면의 선택지를 누르면 캐릭터가 해당 관심 지점까지 자동으로 걸어가고, 도착한 뒤 행동을 선택합니다.

## 실행

1. Unity Hub에서 `unity-mvp` 폴더를 기존 프로젝트로 추가합니다. Unity 6.0 에디터로 엽니다.
2. 첫 임포트가 끝나면 `Assets/Scenes/ForestMvp.unity` 장면이 자동 생성되어 열립니다. 생성되지 않으면 메뉴 **Tools → Ruined Seoul → Recreate MVP Scene**을 누릅니다.
3. 에디터 상단 **Play**를 누릅니다. 모바일 화면은 Game 뷰에서 세로 비율로 확인할 수 있습니다.

프로젝트에는 Unity 2D Tilemap과 uGUI 패키지만 명시했습니다. 숲 배경, 생존자, 나무 및 세 관심 지점은 `Assets/Resources/Art`의 원본 픽셀풍 이미지로 표시합니다. 이동 경로는 논리 격자에서 계산하며, 기존 타일맵은 배경 아래에 숨겨져 있습니다. 프레임과 버튼 테두리는 코드에서 생성합니다. 실행에 API 키는 필요하지 않습니다. 한글 글꼴은 기존 프로젝트의 `KoPubBatangMedium.ttf`를 복사했습니다.

UI는 [공개 웹 게임](https://textrpg-8ic8.onrender.com/)의 플레이 화면을 기준으로 구성했습니다. 밝은 상태 표시줄, 숲 장면 배너, 흰 서사 카드, 제목과 보조 설명이 있는 선택지, 하단의 메뉴·아이템·상태·퀘스트·이동 메뉴를 표시합니다. 숲 월드는 RenderTexture로 배너 안에 실시간 렌더링합니다. 가로와 세로 Game 뷰에 따라 배너와 선택지 배치가 달라집니다.

## 웹에서 실행

저장소 루트의 `scripts/build-unity-preview.ps1`에 이 프로젝트의 경로를 넘기면 웹 미리보기를 만들 수 있습니다. 이 스크립트는 프로젝트 복사본을 사용하므로 원본 Unity 프로젝트의 버전과 설정을 바꾸지 않습니다. WebGL 모듈이 설치된 Unity 에디터가 필요합니다.

```powershell
.\scripts\build-unity-preview.ps1 -ProjectPath .\unity-mvp
```

기본 빌드 에디터는 WebGL 모듈이 설치된 Unity 6000.6.3f1입니다. 다른 에디터를 쓰려면 `-EditorPath`를 지정합니다. 결과는 `assets/unity-preview`에 생성되고, 기존 웹 게임 홈의 **유니티 웹**에서 열 수 있습니다. 실제 웹 게임 저장 데이터와는 연결되지 않습니다.

## 체험 흐름

| 관심 지점 | 행동 | 웹 게임과 동일하게 반영한 결과 |
| --- | --- | --- |
| 무너진 울타리 | 벌목 / 손도끼 벌목 | 30분, 목재 판자 +3 / +5, 손도끼 사용 시 내구도 -1 |
| 낡은 안내판 | 수색 | 30분, 빈손 50%, 캔 음식 10%, 목재 20%, 고철 10%, 천 10% |
| 덤불 | 덩굴 꼬기 / 간이 칼로 자르기 | 30분, 끈 묶음 +2 / +4, 칼 사용 시 내구도 -1 |
| 덤불 | 먹을 것 찾기 / 간이 칼로 덤불 뒤지기 | 30분, 숲 정의의 확률에 따라 들풀·빵·캔 음식·천 또는 빈손, 칼 사용 시 내구도 -1 |

MVP에서 도구 조건부 행동도 바로 시험할 수 있도록 **손도끼 내구도 8, 간이 칼 내구도 10**을 시작 장비로 지급합니다. 도구 내구도가 0이 되면 해당 선택지는 사라집니다. 캐릭터는 나무 장애물을 피하는 격자 A* 경로로 이동합니다.

이 프로젝트는 숲 행동의 상호작용을 검증하는 독립 프로토타입입니다. 웹 게임의 저장 데이터·서버·Gemini 연결과는 아직 연동하지 않았습니다. 숲 행동의 기준은 `src/game/data/regions/forest/location.ts`와 `src/game/data/items.ts`입니다.
