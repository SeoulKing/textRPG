# 숲 그래픽 생성 프롬프트 세트

Unity MVP용 6개 이미지는 Codex의 내장 `image_gen`으로 생성했습니다. 기존 게임의 자산을 복제하지 않는 원본 픽셀풍 그림을 요청했습니다.

| 파일 | 프롬프트의 핵심 대상과 구성 |
| --- | --- |
| `ForestBackdrop.png` | 가로 3:2, 등각 시점의 서울 외곽 폐허 숲. 늦은 오후의 황금빛, 짙은 소나무와 자작나무, 이끼 낀 공원 시설, 물과 낙엽. 중앙 1/3은 캐릭터와 상호작용 물체를 놓을 수 있도록 비운 숲 공터. 글자와 인물 없이 16비트 시대의 정교한 픽셀풍. |
| `Survivor.png` | 주황색 낡은 비옷, 어두운 바지, 부츠와 작은 가방을 멘 생존자 1명. 아래쪽 오른쪽을 향한 3/4 등각 시점, 전신, 투명 배경, 뚜렷한 픽셀 실루엣. |
| `Evergreen.png` | 이끼와 황금빛 잎이 조금 걸린 침엽수 1그루. 뿌리와 줄기까지 보이는 등각 시점, 투명 배경, 짙은 녹색 픽셀 군집. |
| `WoodPile.png` | 무너진 공원 울타리 옆에 모인 통나무와 목재 판자, 이끼, 양치식물, 작은 버섯. 벌목 행동을 표시하는 낮은 등각 소품, 투명 배경. |
| `TrailSign.png` | 이끼 낀 낡은 공원 안내판, 녹슨 금속, 찢어진 작은 지도, 흐릿한 황금색 화살표. 글자 없이 수색 행동을 표시하는 등각 소품, 투명 배경. |
| `Bramble.png` | 덩굴, 짙은 녹색 잎, 붉은 열매, 걸린 낡은 천 조각이 있는 낮은 덤불. 채집 행동을 표시하는 등각 소품, 투명 배경. |

모든 소품에는 16비트 시대의 사각 픽셀 군집, 따뜻한 호박색 하이라이트, 짙은 숲 그림자, 선명한 외곽을 공통으로 요청했습니다. 로고, UI, 워터마크, 다른 캐릭터, 별도의 바닥 타일과 특정 기존 게임의 자산 모방은 제외했습니다.
