# 지역 작업 명세

작업 시작 시 이 파일을 `art-studies/regions/<region-id>/brief.md`로 복사하고 필요한 항목만 채웁니다. 경로는 저장소 루트 기준으로 적습니다. 이 파일은 작업 기록이며 런타임이 읽는 지역 데이터가 아닙니다.

## 요청과 현재 단계

- 지역 ID / 이름:
- 사용자 요청과 완료 조건 한 문장:
- 요청 범위: 설계 / 시안 / 자산 제작 / 게임 연결 / 웹 반영 중 해당 범위
- 현재 단계:
- 다음 행동:
- 미정 사항과 가정:
- 중단 원인 / 재개 조건(해당할 때):

## 디자인 기준과 승인

- 적용 가이드와 최신 관련 항목:
- 실제로 확인한 기준 이미지:
- 기존 장면 / 활성 자산 경로:
- 승인 대상 컨셉 경로 / 버전:
- 승인 근거가 되는 사용자 지시:
- 승인 범위 / 수정 지시:
- 최종 미술 승인 여부:

승인되지 않은 항목은 비워두거나 승인 대기로 적습니다. 생성 완료·게임 연결을 승인 근거로 쓰지 않습니다.

## 자산 계획과 등록

| 자산 ID | 재사용/신규 | 원본·등록 명세 | 게임 출력 | 배치 노드·용도 |
| --- | --- | --- | --- | --- |

신규 자산은 실제 manifest에 다음 정보를 남기고 이 명세에서 해당 경로를 연결합니다. 기존 자산의 등록값을 이곳에 중복 복사하지 않습니다.

- 생성 프롬프트 / 디자인 참조 / 투영 참조 / 재제작 명령과 덮어쓰기 대상.
- 원본·최종 PNG 경로 / 캔버스 크기 / 자르기 영역 / 수동 보정 원본.
- 이미지 픽셀 기준 문턱·발 기준점과 대응하는 월드 기준점.
- 월드 폭·깊이·높이 / 바닥 점유 영역 / 충돌 영역과 단위.
- 카메라 yaw·pitch / 원본 픽셀 밀도 / 배치 Transform / 표시 배율.
- 팔레트·알파·필터 / 레이어·가림 / 조명 보조 데이터가 있는 경우 용도와 한계.
- 실제 로드하는 코드·장면 경로. 새 manifest의 스키마는 해당 소비 코드에 맞춥니다.
