# 아르카나 맵 제작

이 스킬은 프로젝트 전용입니다. 저장소 루트는 현재 textRPG 작업 공간을 사용합니다.

1. 저장소의 `MAP_AGENT.md`를 읽고 맵 제작 담당 역할을 수행합니다. 문서 내 경로는 저장소 루트 기준입니다.
2. 기존 지역 작업이면 `art-studies/regions/<region-id>/brief.md`에서 현재 단계·승인 범위·다음 행동을 확인합니다.
3. 새 작업이면 [지역 작업 명세](assets/region-brief.template.md)를 위 경로로 복사하고 요청에서 이미 알려진 내용을 채웁니다. 설계·시안·게임 적용 중 요청된 범위를 기록합니다.
4. 역할 문서가 안내하는 현행 미술 가이드와 실제 활성 연결을 확인합니다. 새 디자인은 기존 컨셉 승인 절차를 따릅니다. 사용자가 제작 기준으로 확정한 시안을 재현하거나 교정할 때는 그 시안을 기준으로 진행합니다.
5. [3D 맵 제작 흐름](../../docs/roles/WORLD_BUILDING.md#3d-맵-제작-흐름)에 따라 **시안·동선 분석 → Blender 외형 제작 → GLB 내보내기 → Godot 씬 조립·연결** 순서로 3D 공간을 작업합니다. 지역 명세에 원본·출력·씬과 연결 기준점을 남깁니다.
6. 2D 환경 자산은 **시안 분석 → 파츠 원화 생성·승인 → PixelPen 트레이싱·확인 → 씬 배치** 순서로 작업합니다. 3D 자산에 쓰는 도트 텍스처를 그릴 때도 같은 원화·픽셀 확인 기준을 적용합니다.
   - **분석:** 실제 기준 이미지에서 작업 범위의 파츠를 위치별로 나눠 명세에 남깁니다. 바닥은 타일 크기·줄눈·반복 방향, 벽은 위에서 보이는 상단과 각 방향에서 실제로 보이는 옆면·단면, 출입구는 모서리·끝단·문턱과 발이 지나가는 면을 구분합니다. 가구·조명·장식은 새로 만들지 재사용할지 결정합니다. 시안과 현재 장면이 왜 다르게 보이는지 먼저 설명할 수 있어야 합니다.
   - **파츠 원화:** 새로 그리거나 품질을 다시 잡을 파츠는 이미지 생성 도구로 서로 분리된 원화 시안을 먼저 만듭니다. 사용자가 준 전체 시안은 색·형태·투영의 기준으로 삼고, 생성한 파츠 원화는 실제로 따라 그릴 밑그림으로 사용합니다. 사용자가 그 파츠 원화를 이미 제공하거나 승인했으면 다시 생성·승인하지 않습니다. 단순 수정과 기존 파츠 재사용에도 이 단계를 반복하지 않습니다.
   - **제작:** 승인 원화에서 파츠별 영역을 잘라 PixelPen의 별도 참조 레이어로 깔고, 게임 규격의 투명 레이어 위에 실루엣·명암·질감과 접합부를 직접 따라 그립니다. 원화나 코드로 생성한 PNG를 그대로 가져와 PixelPen 파일로 저장하는 것은 트레이싱으로 보지 않습니다. 원본을 저장·재열기하고 참조 레이어를 숨겨 게임용 PNG를 출력합니다. 기본 배율에서 개별 파츠와 대표 접합부(반복 이음, 모서리, 열린 문)를 모은 비교판을 먼저 봅니다.
   - **배치:** 파츠 확인을 마친 뒤 배치합니다. 시각적 두께와 충돌을 따로 확인하고, 미술만 수정할 때는 통행 폭과 출입·저장 기준점을 보존합니다. 실제 씬에서 시안과 같은 방향으로 놓인 파츠가 제 역할을 하는지 확인합니다.
7. 명세에 원본·재제작 경로·실제 확인과 미확인 항목을 남기고 요청 범위에 맞게 인계합니다.

지역명과 분위기만 주어진 경우 연결 위치는 기존 맵을 확인하여 제안하고, 게임 반영 범위가 불명확하면 검토 가능한 시안까지 진행합니다. 시안 승인은 사용자에게 받으며 자동으로 승인 처리하지 않습니다.

이 스킬과 템플릿은 작업 절차를 제공합니다. 예약 실행, 별도 에이전트 실행, 데이터의 자동 런타임 로딩을 등록하지 않습니다.
