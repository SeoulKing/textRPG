# 아르카나 맵 제작

이 스킬은 프로젝트 전용입니다. 저장소 루트는 현재 textRPG 작업 공간을 사용합니다.

1. 저장소의 `MAP_AGENT.md`를 읽고 맵 제작 담당 역할을 수행합니다. 문서 내 경로는 저장소 루트 기준입니다.
2. 기존 지역 작업이면 `art-studies/regions/<region-id>/brief.md`에서 현재 단계·승인 범위·다음 행동을 확인합니다.
3. 새 작업이면 [지역 작업 명세](assets/region-brief.template.md)를 위 경로로 복사하고 요청에서 이미 알려진 내용을 채웁니다. 설계·시안·게임 적용 중 요청된 범위를 기록합니다.
4. 역할 문서가 안내하는 현행 미술 가이드와 실제 활성 연결을 확인합니다. 새 미술은 기존 컨셉 승인 절차를 따르고, 승인 후 요청된 제작·배치·연결을 이어갑니다.
5. 명세에 원본·재제작 경로·실제 확인과 미확인 항목을 남기고 요청 범위에 맞게 인계합니다.

지역명과 분위기만 주어진 경우 연결 위치는 기존 맵을 확인하여 제안하고, 게임 반영 범위가 불명확하면 검토 가능한 시안까지 진행합니다. 시안 승인은 사용자에게 받으며 자동으로 승인 처리하지 않습니다.

이 스킬과 템플릿은 작업 절차를 제공합니다. 예약 실행, 별도 에이전트 실행, 데이터의 자동 런타임 로딩을 등록하지 않습니다.
