# 아르카나 함께 만들기

사용자와 개발자가 같은 `scenes/plaza.tscn`을 수정합니다. 이 장면에 저장된 배치가 실제 게임의 건물·소품·캐릭터 시작 위치·출입점·지면 충돌의 원본입니다.

## 바로 배치하기

1. 위쪽 **광장 함께 편집** 버튼을 누르거나 파일 패널에서 `scenes/plaza.tscn`을 엽니다.
2. 왼쪽 장면 트리에서 **상점_01**, **분수_01**, **주인공_시작위치_01**, **여행자_01** 등을 선택합니다. **F**로 선택한 물체에 시점을 맞춥니다. 화면의 물체를 직접 클릭해 선택해도 됩니다.
3. **W** 이동 도구로 빨간 X축·파란 Z축 화살표를 끌어 배치합니다. 초록 Y축 높이는 0으로 두세요. **E** 회전 도구는 Y축을 사용합니다. 오른쪽 Transform에서 숫자로 조절할 수도 있습니다.
4. **Ctrl+S**로 저장합니다. **F6**은 이 광장 장면으로 같은 게임을 시작하고 **F5**는 전체 게임을 시작합니다. 실제 게임 진행에는 기존 로컬 서버가 필요합니다.
5. 게임을 켜 둔 채 편집기로 돌아와 배치하고 저장하면 약 0.5초 뒤 로컬 게임이 장면을 다시 읽습니다. 저장 전 드래그 상태는 공유되지 않습니다. 웹 버전은 Web export 후 반영됩니다.

## 무엇이 같이 움직이나요?

- 건물을 옮기면 문 앞의 **Interaction** 표시와 주황색 충돌 영역도 같이 옮겨집니다. Interaction 자식은 별도로 움직여 출입점을 조정할 수 있습니다.
- **주인공_시작위치_01**을 옮기면 새 게임 시작 위치가 바뀝니다. 실행 중 저장으로 이 위치를 바꾸면 광장에 있는 주인공도 새 위치로 옮겨집니다. 기존 저장으로 처음 진입할 때는 저장 위치를 우선합니다.
- **여행자_01**을 옮기면 여행자의 배회 기준 위치와 대화 위치도 옮겨집니다. 두 캐릭터의 배율과 시작 방향도 반영됩니다.
- **Ctrl+D**로 장식·나무·소품·캐릭터를 복제할 수 있습니다. 기존 게임 역할을 가진 물체를 장식용으로 복제하면 Inspector의 **Gameplay Id**를 비우고 **Interaction Kind**를 decoration으로 바꾸세요. ID 중복은 경고가 표시되며 첫 물체에만 게임 역할을 연결합니다.
- **Model Kind**로 기존 모델 종류를 고를 수 있습니다. **Collision Footprint**는 로컬 X/Z의 지면 충돌 사각형입니다. 회전한 충돌은 지면의 외접 사각형으로 계산하므로 모서리에서 여유가 생길 수 있습니다.

## 함께 작업할 때

배치가 끝나면 저장하고 어떤 대상을 바꾸셨는지 알려 주세요. 개발자도 그 장면 파일을 기준으로 기능을 붙입니다. 장면은 자동 재생성하지 않으므로 사용자 배치를 덮어쓰지 않습니다. 같은 물체를 동시에 수정할 때는 Godot의 외부 변경 알림에서 저장되지 않은 편집을 먼저 확인해 주세요.

현재 직접 배치하는 범위는 광장의 건물·나무·소품·주인공·여행자입니다. 바닥의 길 무늬, 도시 경계·강, 실내 구성은 아직 코드에서 만듭니다. 편집 화면도 게임과 같은 모델·재질 무늬·단계 명암과 낮 조명을 사용합니다. 편집 시 자유롭게 돌려볼 수 있도록 게임의 고정 카메라용 깊이 압축과 외곽선은 적용하지 않으며, 게임 화면의 저해상도·64색 후처리도 편집 뷰포트에 적용하지 않습니다. 최종 게임 시점과 도트 출력은 F6/F5 실행에서 확인합니다. 지면의 이동·충돌은 기존 2D 규칙을 유지하므로 높이 이동·X/Z축 기울이기는 사용하지 않습니다.
