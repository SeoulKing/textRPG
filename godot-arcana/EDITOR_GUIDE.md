# 아르카나 함께 만들기

사용자와 개발자가 같은 `scenes/plaza.tscn`을 수정합니다. 이 장면에 저장된 배치가 실제 게임의 건물·소품·캐릭터 시작 위치·출입점·지면 충돌의 원본입니다.

## 바로 배치하기

1. 위쪽 **광장 함께 편집** 버튼을 누르거나 파일 패널에서 `scenes/plaza.tscn`을 엽니다.
2. 왼쪽 장면 트리에서 **상점_01**, **분수_01**, **주인공_시작위치_01**, **여행자_01** 등을 선택합니다. **F**로 선택한 물체에 시점을 맞춥니다. 화면의 물체를 직접 클릭해 선택해도 됩니다.
3. **W** 이동 도구로 빨간 X축·파란 Z축 화살표를 끌어 배치합니다. 초록 Y축 높이는 0으로 두세요. **E** 회전 도구는 Y축을 사용합니다. 오른쪽 Transform에서 숫자로 조절할 수도 있습니다.
4. **Ctrl+S**로 저장합니다. **F6**은 이 광장 장면으로 같은 게임을 시작하고 **F5**는 전체 게임을 시작합니다. 실제 게임 진행에는 기존 로컬 서버가 필요합니다.
5. 게임을 켜 둔 채 편집기로 돌아와 배치하고 저장하면 약 0.5초 뒤 로컬 게임이 장면을 다시 읽습니다. 저장 전 드래그 상태는 공유되지 않습니다. 웹 버전은 Web export 후 반영됩니다.

## 무엇이 같이 움직이나요?

- 건물을 옮기면 문 앞의 **Interaction** 표시와 주황색 충돌 영역도 같이 옮겨집니다. Interaction 자식은 별도로 움직여 출입점을 조정할 수 있습니다.
- **주인공_시작위치_01**을 옮기면 새 게임 시작 위치가 바뀝니다. 실행 중 저장으로 이 위치를 바꾸면 광장에 있는 주인공도 새 위치로 옮겨집니다. 기존 저장으로 처음 진입할 때는 저장 위치를 우선합니다.
- **여행자_01**을 옮기면 여행자의 배회 기준 위치와 대화 위치도 옮겨집니다. 두 캐릭터의 배율과 시작 방향도 반영됩니다.
- **Ctrl+D**로 장식·나무·소품·캐릭터를 복제할 수 있습니다. 기존 게임 역할을 가진 물체를 장식용으로 복제하면 Inspector의 **Gameplay Id**를 비우고 **Interaction Kind**를 decoration으로 바꾸세요. ID 중복은 경고가 표시되며 첫 물체에만 게임 역할을 연결합니다.
- **Model Kind**로 기존 모델 종류를 고를 수 있습니다. **Collision Footprint**는 로컬 X/Z의 지면 충돌 사각형입니다. 회전한 충돌은 지면의 외접 사각형으로 계산하므로 모서리에서 여유가 생길 수 있습니다.
- **분수는 예외로 밑면에 꼭 맞는 원형 충돌을 자동 사용합니다.** 사각형 Collision Footprint 항목은 숨깁니다. 주황색 원이 실제 밑면 충돌이며 파란색 상자는 편집기에서 모델을 선택하기 위한 범위입니다. 분수를 옮기면 모델·원무늬·충돌이 같은 중심을 따라갑니다. 원무늬 전체와 옛 사각형 모서리는 통행할 수 있습니다.
- 장면 트리의 맨 위 **Plaza**를 선택하면 **Plaza Radii**로 광장 포장의 X/Z 반경을, **Paved Areas**로 큰길·골목·건물 앞마당의 직사각형을 편집할 수 있습니다. 단위는 물체 배치와 같은 3D X/Z입니다. Rect2의 Position은 왼쪽 위 X/Z, Size는 가로·세로 길이이며 최대 24개를 사용합니다. 포장은 편집기와 게임이 같은 값을 사용합니다. 광장 중심은 분수의 수반 위치를 따릅니다. 건물을 크게 옮겼을 때는 문 앞까지 이어지는 골목도 함께 조정해 주세요.

## 함께 작업할 때

**Plaza 루트는 좌표계이므로 Transform을 이동하거나 기울이지 않습니다.** 배치는 그 안의 건물·분수·나무 등의 자식 노드를 옮겨 주세요. `main.tscn`의 Plaza 인스턴스에 별도 Transform을 주면 모델과 배치 기반 지면·판정의 기준이 달라질 수 있어 게임 초기화에서 단위 좌표계로 정규화합니다. 시작 장면도 공유된 `plaza.tscn`을 추가 이동 없이 사용합니다.

배치가 끝나면 저장하고 어떤 대상을 바꾸셨는지 알려 주세요. 개발자도 그 장면 파일을 기준으로 기능을 붙입니다. 장면은 자동 재생성하지 않으므로 사용자 배치를 덮어쓰지 않습니다. 같은 물체를 동시에 수정할 때는 Godot의 외부 변경 알림에서 저장되지 않은 편집을 먼저 확인해 주세요.

현재 직접 배치하는 범위는 광장의 건물·나무·소품·주인공·여행자와 광장 크기·도로·앞마당입니다. 바닥의 석판 무늬, 도시 경계·강, 실내 구성은 코드에서 만듭니다. 편집 화면도 게임과 같은 모델·재질 무늬·단계 명암과 낮 조명을 사용합니다. 편집 시 자유롭게 돌려볼 수 있도록 게임의 고정 카메라용 깊이 압축과 외곽선은 적용하지 않으며, 게임 화면의 저해상도·64색 후처리도 편집 뷰포트에 적용하지 않습니다. 최종 게임 시점과 도트 출력은 F6/F5 실행에서 확인합니다. 지면의 이동·충돌은 기존 2D 규칙을 유지하므로 높이 이동·X/Z축 기울이기는 사용하지 않습니다.

## 슬라임 도트 직접 편집

하단 **슬라임 도트** 패널에서 공통 레이어나 특정 프레임의 도트를 칠하고 지울 수 있습니다. 공통 레이어는 모든 동작에 반영되고 프레임별 좌표 수정은 재출력해도 유지합니다. **저장 + 시트 반영** 후 게임을 다시 실행해 주세요. 패널이 없으면 프로젝트 설정 → 플러그인에서 **슬라임 도트 작업실**을 켭니다.

서버 없이 동작과 한 칸 크기를 보려면 `scenes/monsters/slime_preview.tscn`을 열고 **F6**을 누릅니다. Slime의 **Preview Animation**으로 대기·점프·준비·공격·피격·소멸을 고릅니다. 원본/프레임 수정·재출력의 자세한 절차는 [슬라임 원본 안내](art/source/monsters/README.md)에 있습니다.

## 주인공 도트와 걷기 직접 편집

하단 **주인공 도트** 패널에서 8방향·동작·레이어·프레임을 고르고 도트를 칠하거나 지울 수 있습니다. 이전 프레임 겹쳐보기·재생·되돌리기를 지원하며 **저장 + 시트 반영**으로 게임 시트를 갱신합니다. 이 수정은 재출력해도 보존됩니다.

**PixelPen 원본**은 선택한 공통 레이어 PNG 경로를 복사하고 PixelPen을 엽니다. Import로 열고 수정한 뒤 같은 PNG로 Export하고 시트를 반영합니다. **SpriteFrames**는 Godot 기본 프레임 편집기, **보행 미리보기 장면**은 서버 없이 F6으로 볼 수 있는 방향·속도 비교 화면입니다. TileMapLayer의 바닥도 기본 TileSet 편집기로 수정합니다.

설정 → 플러그인에 PixelPen과 주인공 도트 작업실이 켜져 있어야 합니다. 첫 설치 후 새 패널이 없으면 에디터를 다시 여세요. [원본·편집·재출력 절차](art/source/heroine/README.md)를 따릅니다.

## 공통 2D 뼈대 기반 주인공

주인공 도트 패널의 **공통 뼈대**는 선택한 방향의 실제 Skeleton2D·Bone2D·Polygon2D·AnimationPlayer 장면을 엽니다. AnimationPlayer의 대기/걷기/정지/정지회전 트랙을 편집하고 저장한 뒤 **뼈대 재출력**을 누릅니다. 원본·뼈대 변경에는 이 과정이 필요하며, 프레임 도트만 고칠 때는 기존 **저장 + 시트 반영**을 사용합니다. **PixelPen 원본**은 현재 skeletal/ 원본을 가리킵니다. 좌우 다리 원본은 해당 폴더의 leg PNG이고 신발은 parts/입니다. 출력은 기존 게임에 쓰는 도트 시트이며 런타임에 신체 방향을 따로 혼합하지 않습니다. 자세한 순서는 art/source/heroine/README.md를 따릅니다.


## 성벽과 탑: Godot 기본 타일맵

`scenes/walls/city_walls.tscn`을 열고 **2D** 작업 공간으로 이동합니다. 기존 3D 성벽 대신 남문 양쪽에 일러스트 성벽 22구간과 탑 2개를 배치했습니다. 이 레이어에서 기존 칸을 수정하거나 이어 그릴 수 있습니다.

1. `Walls`를 선택하고 하단 **TileMap → Terrains(지형)**에서 **성벽**을 선택합니다. **Connect(연결)** 모드로 드래그하면 직선·모서리·끝·T자·십자 연결이 자동으로 골라집니다. 일반 Tiles 브러시는 선택한 조각만 반복하므로 자동 연결에는 Terrains를 사용합니다.
2. `Towers`를 선택하고 **Tiles**에서 파란 지붕 탑(아틀라스 소스 1)을 골라 찍거나 드래그합니다. 성벽과 탑을 같은 칸에 겹쳐 놓을 수 있습니다.
3. 지우개로 해당 레이어의 칸을 지우고 저장합니다. `plaza.tscn`의 `CityWalls`가 같은 타일 데이터를 3D 공간의 2D 그림과 충돌로 읽습니다. 편집기 3D 미리보기는 저장 후 갱신되며 실행 중 게임에는 다시 실행이 필요합니다. 웹 게임은 웹 내보내기가 필요합니다.

성벽 편집 한 칸은 **월드 3단위(이동 격자 3칸·게임 좌표 48)**입니다. 기둥 사이 한 구간을 온전히 그리므로 창문·깃발이 타일 중간에서 잘리지 않습니다. 2D 편집 격자는 정면형 3/4 투영에 맞춘 192×136픽셀이며 캐릭터·건물과 같은 64원본픽셀/단위로 표시합니다. `(0,0)`칸의 중심은 월드 `(3,47)`입니다. +X가 동쪽, +Y가 남쪽이며 음수 행으로 도시 안쪽에 그릴 수 있습니다. 3D `CityWalls`의 Grid Origin으로 원점을 바꿀 수 있습니다.

다른 맵에서는 이 장면을 복사해 별도 칠하기 데이터를 저장하고, `wall_tilemap.gd`를 붙인 Node3D의 Map Scene에 연결합니다. `art/resources/wall_tileset.tres`를 공유하면 같은 성벽·탑 그림을 재사용합니다. 자주 쓰는 모양은 Godot 기본 패턴 기능으로 저장할 수 있습니다. 한 TileMapLayer에는 회전·배율을 적용하지 않고 칸을 이동해서 편집합니다.

도트 원본은 `art/export/walls/wall-terrain.png`(16종 연결)와 `gate-tower.png`이며 원화 기반 타일 조립은 `scripts/build-wall-tiles.cjs`입니다. `build-wall-tiles.py`는 같은 제작기로 연결하는 호환 진입점입니다. 탑 원화는 `art-studies/city-walls/source/gate-tower.png`이며 `scripts/build-wall-tower.cjs`로 다시 출력합니다. `wall_examples.tscn`은 별도 연결 예제로 실제 도시 맵에 배치되지 않습니다. TileSet 편집은 Godot 기본 편집기에서 합니다. `tools/build_wall_tileset.gd`는 최초 자산 제작용으로, 다시 실행하면 TileSet 수동 수정이 덮어써지므로 일반 맵 편집에는 실행하지 않습니다. 칠한 장면은 이 제작 도구가 덮어쓰지 않습니다.

성벽 배치를 바꾼 뒤 서버 전투에서도 같은 충돌을 쓰려면 `scripts/build-godot-arcana.ps1`로 지형 데이터와 웹 산출물을 갱신하고 서버를 다시 시작합니다. 일반 Godot 실행의 이동 충돌은 장면에서 직접 읽습니다.


승인된 성벽 v2는 16종 연결×4종 완성된 벽 구간이며, 탑은192×512·발(96,480)입니다. 성벽은 원본 약241픽셀, 탑은440픽셀로 캐릭터 약110픽셀 대비 각각 약2.2배/4배 높이입니다. 탑 충돌도1.8×1.6월드 단위로 넓혔습니다. 표시 노드의 scale을 키우지 않고 원화에서 새 해상도로 출력합니다.

성벽 미술 재제작은 `scripts/build-wall-tiles.cjs`, 탑은 `scripts/build-wall-tower.cjs`를 실행한 뒤 `scripts/build-city-walls.ps1`로 TileSet·지형 데이터·웹을 함께 갱신합니다. 이 작업은 에디터 애드온·검토용 캡처를 제외한 별도 런타임 사본에서 수행합니다. `tools/update_wall_art_phases.gd`는 이전1단위 격자를 한 번만3단위로 이전하며 이후 칠한 구간은 이동하지 않습니다. 미술 재출력 시 구간 변형 그림만 갱신합니다.
