# 아르카나 네이티브 2D

현재 활성 플레이 표시기는 `scripts/native_2d_world.gd`입니다. `main.tscn`은 이 폴더의 `plaza.tscn`을 도시 배치 원본으로 사용합니다. 기존 3D 장면은 보관 원본이며 기본 실행·웹 패키지의 표시 장면으로 사용하지 않습니다.

## 편집 기준

- 도시·실내·상점·플레이어는 원본 픽셀의 가로·세로 비율을 보존하고 노드 Scale (1, 1)을 사용합니다.
- 논리 게임 좌표 16은 원본 표시 64픽셀입니다. 변환은 `native_2d_coordinates.gd`를 기준으로 하며 세로 압축은 없습니다.
- 도시의 수동 배치 166개, 문 위치, 충돌과 입구 정보를 이관했습니다. 바닥은 64×64 타일이며, 상점의 반 칸 타일은 32×32입니다.
- 도시의 Placements 아래 노드들은 왼쪽 위 공통 기준점을 사용합니다. Visual Offset으로 그림을 배치합니다. 배치 노드 Position을 옮기면 표시와 논리 충돌이 같은 이동을 따릅니다.
- 기존 배치의 확대는 파생 이미지에 반영했습니다. 파생 이미지는 `art/export/native-2d/`의 압축 리소스로 공유합니다. 원본 미술은 보존합니다.
- 도시 성벽, 여관, 학교 1·2층과 식당은 별도 2D 장면입니다. 사냥 공간은 같은 야외 장면의 남쪽 구역과 논리 이동을 유지합니다.

## 표시와 게임 연결

플레이어의 기존 달리기·대기·시전·대시·착석 프레임 및 타이밍, 슬라임의 전투 프레임, 분수·포털·안내원 애니메이션을 2D로 표시합니다. 캐릭터 그림 자체를 늘리지 않습니다. 카메라와 캐릭터는 최종 화면 픽셀 격자에 맞춥니다.

전투 조준·투사체·충격·데미지 숫자·적 체력 표시·퀘스트 표시·다른 플레이어·이름표는 네이티브 2D 표시기와 연결합니다. 3D 비교 메뉴는 기본 메뉴에서 제거했습니다. 서버 API·저장 ID·논리 이동 규칙은 유지합니다.

게임 판정은 `world.gd`와 서버가 담당합니다. 배치 노드의 `registered_transform`은 과거 출입 방향과 충돌을 보존하는 기하 데이터이며, 3D 렌더 노드를 생성하지 않습니다. 전투 내보내기는 이 2D 장면의 저장 데이터를 읽습니다.

## 이관 도구와 확인 범위

`tools/export_native_2d_city.gd`, `export_native_2d_rooms.gd`, `export_native_2d_walls.gd`, `finish_native_2d_layout.gd`, `export_native_2d_restaurant.gd`는 최초 이관용입니다. 기존 2D 편집 장면을 자동 재생성하거나 덮어쓰지 않습니다. 정상 빌드는 이 도구들을 실행하지 않습니다.

구문 검사, 웹 내보내기, 서버 빌드 및 서버 기동을 확인했습니다. 브라우저 플레이와 시각 검증은 실행하지 않았습니다. 직접 확인할 경로는 도시 이동 → 각 실내 진입·퇴장 → 학교 층 이동 → 착석 → 슬라임 선택·공격·회피 → 다른 플레이어와 퀘스트 표시입니다.
