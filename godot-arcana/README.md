# 아르카나 · 별빛의 도시 (Godot)

기존 아르카나 게임을 직접 걸어 다니는 2D 도트 월드로 연결한 Godot 4.5.1 프로젝트입니다. 홈의 **아르카나 · 도트 월드**에서 `/godot/`로 들어갑니다.

## 실행과 수정

- `godot-arcana/project.godot`를 Godot 4.5.1에서 엽니다. 게임 서버는 기존처럼 `npm.cmd start`로 실행합니다.
- 로컬 도구 준비: `python scripts/download-godot-tools.py` (저장소 루트에서 실행). 공식 Godot 편집기와 해당 버전의 **단일 스레드 Web release** 템플릿만 `.runtime/godot`에 받습니다. 템플릿은 원격 ZIP의 필요한 엔트리만 읽고 CRC를 확인합니다.
- 웹 빌드: `powershell -NoProfile -File scripts/build-godot-arcana.ps1`. `-GodotPath`로 편집기 경로를 지정할 수 있습니다.
- 결과는 `godot-web/`이며 기존 Fastify 서버가 `/godot/`에서 제공합니다. WebGL 2, WebAssembly, Compatibility 렌더러를 사용하고 COOP/COEP 헤더는 요구하지 않습니다.
- 서버 빌드(`npm.cmd run build`)와 Godot 빌드는 별개입니다. Godot 소스를 바꾸면 웹 빌드도 다시 만들어야 합니다.

## 구성

- `scripts/world.gd`: 연속된 도시·평원, 시설 내부, 학교 공간, 장애물과 A* 이동, 입력과 카메라.
- `scripts/art_library.gd`, `art/`: 분수 광장의 PNG 자산, 32×32 TileSet, 32×48 SpriteFrames, 64색 팔레트와 편집 원본입니다. 제작 기준은 루트 `ARCANA_ART_GUIDE.md`, 재출력은 `python scripts/bake-arcana-art.py`를 사용합니다.
- `scripts/pixel_art.gd`: 첫 리아트 범위 밖인 학교 외벽·내부 인물·포탈·슬라임의 기존 임시 그래픽을 유지합니다.
- `scripts/main.gd`: 기존 `/api/games` 스냅샷과 행동 API 연결, 서버 소유의 게임 규칙·저장·시간·전투.
- `scripts/game_ui.gd`: 모바일·데스크톱 UI, 상황 행동, 소지품, 의뢰, 기록, 시설과 던전 화면.
- `web-shell.html`: 내보내기 템플릿, 로딩·오류 안내, 창 전환 처리, 전체화면, 읽기용 `render_game_to_text()`.

## 현재 지원 범위

- 분수 광장·상점·여관·식당·귀환 포탈·남문·도시 앞 평원을 걸어 다닙니다. 건물 가까이에서 상호작용해 들어가며 내부의 출입문으로 나옵니다.
- 학교의 교장실·강의실·실습실·도서관·관측탑·정원은 기존 `academyMap`의 입장 조건을 따릅니다. 등록, 스텔라와의 만남, 수업과 관측탑 의뢰를 기존 서버 행동으로 진행합니다.
- 파이어볼·회피·포션·레벨·경험치·구매·휴식·비전 작업대은 기존 서버 판정을 사용합니다. 학교 대화와 제작의 세부 진행은 상황 창에서 선택합니다.
- 웹에서 기존 텍스트 저장이 아르카나에 있으면 첫 입장 시 같은 진행을 연결합니다. 이후 Godot 이어가기 ID와 위치는 별도로 기억합니다. 자동 저장되는 서버의 현재 진행을 불러오며 메뉴의 저장으로 수동 저장 시점도 남깁니다. 기존 텍스트 홈의 저장 연결을 자동으로 덮어쓰지 않습니다.
- 현실로 귀환한 후 **텍스트 게임에서 이어가기**를 선택하면 수동 저장하고 기존 홈의 이어하기에 연결합니다.
- Godot 클라이언트는 현재 게임 서버를 필요로 합니다. 오프라인 독립 게임, 무한 절차 생성 월드, 새 채집 보상·새 전투 규칙은 추가하지 않았습니다.

## 조작

모바일에서는 화면 왼쪽 아래 영역에 손을 대면 그 위치에 가상 조이스틱이 나타납니다. 평소에는 숨겨져 있으며, 손을 댄 지점을 중심으로 밀어 이동합니다. 대각선을 포함한 전 방향으로 움직이며 기울기에 따라 속도를 조절하고, 손을 떼면 멈추면서 조이스틱도 사라집니다. 오른손으로 살펴보기·불꽃·회피·포션 버튼을 함께 누를 수 있습니다. 메뉴를 열거나 화면을 벗어나면 스틱 입력을 해제합니다.

오른쪽 아래의 큰 원형 버튼은 상호작용이며 작은 `E` 배지로 키보드 연결을 표시합니다. 주변 네 퀵슬롯은 `1~4` 키와 연결되며 기본 배치는 불꽃·회피·마나 포션·빈 슬롯입니다. 아이콘, 포션 보유량, 줄어드는 재사용 대기 바를 표시합니다. 빈 슬롯 또는 **메뉴 → 퀵슬롯 설정**에서 스킬·아이템을 배치하거나 비울 수 있고, 배치는 기기에 저장됩니다. 현재 배치 가능한 항목은 불꽃·회피·마나 포션입니다.

길 클릭·터치 / WASD·방향키: 이동. E·Space: 가까운 대상 상호작용. 1~4: 해당 퀵슬롯 사용. M: 지도. I: 소지품. J: 의뢰. Esc: 메뉴·닫기. F: 전체화면.

지도에서 목적지를 고르면 실제 경로를 따라 걷습니다. 상호작용은 도착 후 실행합니다. 메뉴와 창 전환 시 서버 시간을 멈추며, 대기 시간과 적의 공격 예고는 줄어드는 바로 표시합니다.

## 분수 광장 미술 제작

월드는 384×824 화면 전체에 렌더링하며 HUD를 겹칩니다. 이동 격자는 16단위, 그림은 32픽셀 타일과 32×48 인물 프레임입니다. 메뉴의 낮 / 해질녘과 환경 효과 전환으로 같은 광장을 비교할 수 있습니다. 제작 결과와 미검증 항목은 [제작 기록](art/PRODUCTION.md)을 확인해 주세요.

## 실제 3D 도트 렌더러

현재 기본 `/godot/` 화면은 `pixel3d_world.gd`의 실제 3D 장면입니다. `pixel3d_models.gd`가 재사용 메시를 만들고 `pixel3d_actor.gd`가 캐릭터 관절을 움직입니다. 기존 `world.gd`의 좌표·충돌·진행과 서버 API를 계속 사용하며 저장 형식은 바꾸지 않습니다. 화면 터치는 Camera3D의 지면 레이 교차로 원래 이동 좌표에 대응합니다.

도트 모드는 월드만 절반 해상도로 렌더링하고 픽셀에 맞춰 확대합니다. 메뉴의 **3D 원본 비교**로 같은 입체 모델의 원래 해상도를 볼 수 있습니다. 오프라인 미술 출력은 `pwsh -File scripts/render-godot-pixel3d-art.ps1`, 웹 반영은 기존 빌드 스크립트를 사용합니다. [실제 출력과 구현 범위](art/PRODUCTION.md)의 마지막 항목에서 플레이 검증과 미술 확인을 구분합니다.

## Godot 편집 화면에서 함께 배치하기

`scenes/plaza.tscn`이 광장 배치의 원본입니다. Godot 위쪽의 **광장 함께 편집**으로 열고 물체를 선택한 뒤 X/Z축으로 이동하고 저장합니다. 건물의 출입점·충돌과 캐릭터 시작 위치도 이 장면에서 가져옵니다. 로컬 에디터로 실행 중인 게임은 장면 저장을 감지해 배치를 갱신합니다. F6으로 광장 장면을 실행해도 같은 게임을 시작하며, 웹 배포에는 기존 Web export가 필요합니다. [직접 배치하는 방법과 현재 범위](EDITOR_GUIDE.md)를 참고해 주세요.

## 주인공 3D 모델

`scenes/characters/hero.tscn`을 열면 현재 주인공의 실제 입체 모델을 볼 수 있습니다. 현재 `scripts/blender_hero.gd`가 Blender의 스킨 메시·텍스처·대기/걷기를 불러오며, 게임과 광장의 `hero` 미리보기에 같은 모델을 연결합니다. 편집 원본은 저장소 루트의 `art-studies/arcana-hero/blender/hero.blend`이고, `pwsh -File scripts/build-blender-hero.ps1`로 다시 출력합니다. 이전 `hero_actor.gd` 모델은 시제품으로 보존합니다. 기존 2D 원화·시트는 보존합니다. 네 방향 모델 확인은 `pwsh -File scripts/render-hero3d.ps1`로 출력합니다.

## 현재 주인공 · 백발 단발 미소녀

현재 hero는 사용자가 선택한 2번 원화를 따르는 여성입니다. `scenes/characters/heroine.tscn`에서 입체 모델을 볼 수 있습니다. 원본은 저장소 루트 `art-studies/arcana-hero/white-bob-heroine/blender/heroine.blend`, 재제작은 `pwsh -File scripts/build-blender-heroine.ps1`입니다. `art/models/heroine/heroine.glb`와 `scripts/blender_hero.gd`가 게임과 편집기 배치에 공통 연결됩니다. 남성 모델·원화는 이전 자료로 보존합니다.
