# 하이브리드 버전 1 · 작은 손

현재 확정 전신에 필요한 양손을 [조립 색인](../assembly/parts.json)에서 연결합니다. 과거 캐릭터의 나머지 이미지 없이 이 폴더의 편집 원본과 출력만 사용합니다.

각 방향의 `hands.pxpen`이 PixelPen 원본이며 `hand_l.png`, `hand_r.png`가 실제 출력입니다. `manifest.json`의 원본/출력 해시·레이어·피벗과 `source-extraction.json`의 추출 근거를 따릅니다. 손 크기와 가는 손목을 유지하고 커프 틈을 감추기 위해 손 전체를 키우지 않습니다.

손은 상체 보정 후의 손목 위치를 따릅니다. 양손 레이어를 임의로 합치거나 좌우 피벗을 공유하지 않습니다. 원본 저장→재열기→해당 레이어 PNG 출력 후 등록을 갱신하며 수동 원본을 덮어쓰지 않습니다. 현재 동작과 본편 확인 상태는 [인계](../assembly/CURRENT_STATUS.md)에 기록합니다.
