# 하이브리드 버전 1 · 전신 조립

확정 외형과 부위별 편집 원본의 색인은 [묶음 안내](../README.md), 현재 게임 연결·확인 범위는 [인계](CURRENT_STATUS.md)에 둡니다. 본편과 제작실은 같은 파츠·조립기·보정값을 사용합니다.

## 기계 명세

- [parts.json](parts.json): 머리·통합 상체·골반·전체 다리·신발·작은 손의 방향별 원본과 등록.
- [assembly.json](assembly.json): 3등신 길이·목/허리/다리 연결·방향별 미술 등록·카메라 프레이밍.
- [motion-polish.json](motion-polish.json): 허벅지·무릎·팔·소매·부츠·지지발의 조립 보정값.
- [shared-run.json](../shared-run.json): 원본 공통3D 동작. 조립 보정을 위해 원본 키를 덮어쓰지 않습니다.

96×136은 전신 제작 캔버스, 48×48은 파츠의 논리 등록 좌표입니다. 전체 다리 텍스처는 첨부 원본 해상도·RGBA를 유지합니다. 시트 순서가 서로 다르므로 S·SE·E·NE·N·NW·W·SW 이름으로 연결합니다.

실제16관절 Skeleton3D를 새 캐릭터 비례로 리타깃합니다. 다리는 저장된 Polygon2D UV·가중치를 보존하며 3D 골반·무릎·발목의 투영으로 움직입니다. 상체는 방향별 그림의 중립 연결점에 3D 팔의 중립 대비 이동량을 더합니다. 머리는 목, 부츠는 각 발목, 작은 손은 보정된 손목에 붙입니다. 실제3D 관절 오버레이와 상체의 미술 등록 오프셋은 구별합니다.

허리 벨트는 골반이 한 번만 소유합니다. `upper-body-assembly/`는 상체 원본의 벨트 재질·해당 선만 가린 **한 장의 조립용 텍스처**입니다. 팔·몸통을 나누지 않고 소매·커프와 PixelPen 원본을 보존합니다. 상체 원본을 재출력한 뒤 `res://tools/characters/hybrid_v1/prepare_reference_assembly_textures.gd`로 갱신하며 수동 변경된 사본을 덮어쓰지 않습니다. 원본 외곽선 위에 추가 선을 적용하지 않습니다.

## 동작 보정

허벅지 회수 폭0.72배, 무릎 굽힘100°부터 완화해 약115° 제한, 팔 흔들림과 소매 투영 길이·팔꿈치 굽힘을 완화합니다. 부츠는 원본 발끝 방향을 참고하되 종아리와의 상대 회전 차이를 제한하고 실제 발 부분 실루엣으로 지지발 높이를 계산합니다. 짧은 구간에 최대1px 비행을 허용합니다. 정확한 수치는 JSON이 원본이며 문서의 요약값으로 덮어쓰지 않습니다.

[이동 실험](../../../../scenes/characters/hybrid-v1/experiment.tscn)의 **동작 보정**, [전신 작업실](../../../../scenes/characters/hybrid-v1/workbench.tscn)의 같은 옵션으로 비교합니다. 같은 카메라·방향·위상의 중립과 달리기0/25/50/75%를 사용합니다.

`review/`의 [전후 GIF](review/motion-before-after.gif)와 [검토 기록](review/motion-polish-review.json)은 이관 전 제작용 GPU 비교입니다. 왼쪽은 보정 전·오른쪽은 후이며 E 방향0.5배속입니다. 이관 후 본편 게임·상호작용을 실행해 검증한 자료로 취급하지 않습니다.
