# 하이브리드 버전 1 · 현재 상태

2026-11-05 사용자께서 **현재 캐릭터 외형을 최종 확정하고 본편 연결**을 요청하셨습니다. 단일 원본은 [hybrid-v1 묶음](../README.md)이며 본편 주인공과 같은 프로젝트의 제작실이 함께 사용합니다. 외형 확정과 모든 동작의 체감 검수는 구별합니다.

## 저장·연결한 내용

| 항목 | 현재 상태 |
| --- | --- |
| 확정 외형 | 가느다란3등신·96×136 전신 기준. 백발/연보라 단발·보라 눈·크림 셔츠·갈색 가죽·붉은 장식·크림 커프 부츠. |
| 파츠 원본 | 머리·상체·골반·부츠·양손의 PixelPen/PNG·등록을 한 묶음으로 이관했습니다. E 신발은 W의 정확한 반전입니다. |
| 전체 다리 | 사용자가 첨부한 원본과 대응 RGBA를 그대로 유지한 Polygon2D입니다. 부분 알파도 유지하며 팔레트·축소·알파 변환을 하지 않습니다. |
| 조립 | 실제16관절 Skeleton3D와 공통3D 동작, 팔·몸통 통합 Polygon2D, 다리당두뼈, 저장된UV·가중치를 사용합니다. |
| 달리기1차 보정 | 무릎·허벅지·지지발·부츠 회전·팔 흔들림·소매 변형을 조립 보정값으로 조절합니다. 미술·공통 동작 원본은 보존합니다. |
| 본편 연결 | `scripts/native_2d_hero.gd`에서 `scripts/characters/hybrid_v1/native_actor.gd`로 진입합니다. 새 원본으로 이동·가림·초상화와 기존 행동 인터페이스를 연결했습니다. |
| 제작실 | 본편 `scenes/characters/hybrid-v1/`의 이동 실험·전신 비교·상체/다리 작업실을 사용합니다. |
| 달리기 키 편집 | `scenes/characters/hybrid-v1/run-keyframes.tscn`의 AnimationPlayer `run`을 직접 편집합니다. 상단 키 기록 → Ctrl+S로 `run-keyframes.tres`에 저장하며 본편도 같은 파일을 읽습니다. |

시전·벤치 앉기·운반·낚시는 같은 확정 캐릭터의 **절차 포즈와 기존 게임 인터페이스를 연결한 상태**입니다. 각각의 완성된 전용 애니메이션 클립을 새로 제작한 것은 아닙니다. 현재 걷기도 공통 동작의 속도·블렌드이며 전용 완성 걷기 클립이 아닙니다. 의상 교체·새 표정·망토 물리는 이번 확정·연결에 포함하지 않습니다.

## 확인한 범위와 한계

- **실제 본편 실행:** Godot 4.5.1의 실제 GPU 실행에서 별도 저장 프로필로 서버 입장, 16관절 조립, 8방향 이동과 정지를 확인했습니다. 8개 입력 방향과 표시 방향이 모두 일치했고 캐릭터 이미지가 비어 있지 않았습니다. 기존 사용자 저장은 사용하지 않았습니다.
- **웹 실행:** 같은 버전으로 웹을 내보내고 독립 PCK의 캐릭터·지역 리소스를 확인했습니다. 서버 제공 파일의 해시 일치와 브라우저의 실제 입장·캐릭터 표시·방향키 이동을 확인했습니다. 현재 로컬 주소는 `http://localhost:3000/godot/`입니다.
- **수정한 실행 문제:** 네이티브 로컬 서버 주소를 검증된 IPv4 루프백으로 바꾸고, 이미지 가져오기와 이동된 침대 TileSet 참조를 정리했습니다. 공통 스프라이트 셰이더가 색·알파를 두 번 곱하던 오류를 수정했습니다.
- **기존 제작 자료:** `review/`는 이관 전의 제작용 GPU 고정 자세·E 방향 전후 비교입니다. 같은 렌더 조건의 중립 S/E/N에서 보정 전후RGBA차이0이었던 기록과 파일 보존 자료를 유지합니다. 이번 본편 검증 결과로 바꾸어 해석하지 않습니다.
- 발 디딤 수치는 평면 바닥과 실제 부츠 실루엣을 사용한 제작 포즈 기준입니다. 입장·방향 이동·정지의 기능 확인과 모션의 최종 미술 승인은 다릅니다. 경사지·급회전의 체감과 시전·벤치·낚시의 전체 플레이는 별도 검수 대상입니다.
- 구버전 생성 출력 133개 폴더(7,287,554,581바이트)와 구 편집 원본·코드의 복구 보관본을 영구 삭제했습니다. 사용자가 현재 버전만 사용하겠다고 명시적으로 승인한 뒤 정리했으며, 이전 독립 작업실의 캐시·플러그인 껍데기도 삭제했습니다. 현재 캐릭터의 PixelPen 원본·리그·동작·비교 자료는 이 묶음에 보존합니다.

## 사용자가 직접 확인할 순서

1. 본편 `main.tscn`을 실행해 기존 세계에 하이브리드 버전1이 보이는지, 직선·사선 이동과 출발·정지·회전에서 발·가림이 자연스러운지 확인합니다.
2. 시전·벤치·낚시에서 같은 외형이 유지되고 손/도구 접점과 복귀 자세가 맞는지 확인합니다. 절차 포즈의 미술 마감은 별도 개선 대상입니다.
3. [이동 실험](../../../../scenes/characters/hybrid-v1/experiment.tscn)에서 WASD/방향키·Shift와 **동작 보정** 전후를 비교합니다.
4. [전신 작업실](../../../../scenes/characters/hybrid-v1/workbench.tscn)에서8방향·같은 달리기 위상을 보고 특히 후면/사선의 강하게 굽힌 소매·손 가림·다리/부츠 커프의 겹침을 확인합니다.

이후 우선순위는 실제 이동 체감 → 남은 소매·부츠 변형 마감 → 걷기·대기·달리기·출발/정지/회전의 연결입니다. 완성도는 프레임 수·구문 통과·저장 성공과 별도로 판단합니다.
