# 하이브리드 버전 1 · 원본 그대로 쓰는 전체 다리

사용자가 직접 첨부한 [원본 이미지](reference.png)를 유지합니다. 공유 링크나 새 그림으로 대체하지 않으며 **허벅지와 정강이를 두 이미지로 나누지 않습니다.** [전신 조립](../assembly/README.md)에서 한 장의 Polygon2D를 두 뼈로 움직여 본편에 연결합니다.

## 원본·등록과 리그

- `reference.png`: 첨부 PNG 사본.
- `{방향}/leg.png`: 원본 해상도의 전체 다리. 해당 원본 사각형과 RGBA가 정확히 일치합니다. **축소·재채색·팔레트 변환·알파 정규화 없이 부분 알파까지 보존**합니다.
- `manifest.json`: 원본 영역·해시·골반/무릎/발목 기준점·텍스처 표시 영역과 원본/논리 좌표의 관계.
- `source-preview.png`: 원본 다리들을 재배열한 제작 비교.
- [8방향 리그](../rigs/legs/s.tscn): Polygon2D 정점·UV·Bone2D 가중치의 수동 편집 원본.
- [다리 작업실](../../../../scenes/characters/hybrid-v1/leg-workbench.tscn): 방향·고정 위상·신발 표시 비교.

원본에는 방향 글자가 없어 앞서 제공된 골반·신발과 같은 왼쪽부터 **SW·W·NW·N·NE·E·SE·S**로 등록했습니다. 원본 영역과 방향 이름을 manifest로 추적합니다.

한 다리는 텍스처1장·Polygon2D1개·Bone2D2개입니다. 골반→무릎의 허벅지 뼈와 무릎→발목의 정강이 뼈를 사용하고 무릎 주변 가중치를 혼합합니다. 무릎 그림을 잘라 움직이거나 새 그림으로 채우지 않습니다.

논리 표시는 48×48 등록 좌표이며 텍스처 파일 자체를 줄이지 않고 메시·UV로 크기를 맞춥니다. 현재 등록은 가로0.06·세로0.08 원본 대비 축척을 사용하며 정확한 표시 영역은 manifest가 기준입니다. 공통 [3D 동작](../shared-run.json)을 새3등신 길이에 맞춰 투영하고 신발은 각 발목에 별도로 붙입니다.

## 보존과 확인

이 세트에는 신규 도트의 이진 알파·제한 팔레트를 강제로 적용하지 않습니다. 사용자의 **원본 이미지 그대로** 지시가 우선입니다. 색 수정이 별도로 요청되기 전에는 원본 PNG 바이트와 대응 RGBA 영역을 보존합니다. 표시 갱신이 수동 UV·가중치를 재생성하지 않도록 합니다.

Bone2D 편집 가이드가 출력에 섞이지 않게 작업실 인스턴스에서만 뼈 표시를 숨기며 저장 리그의 편집 표시와 Polygon2D 스키닝은 유지합니다. 원본 픽셀 보존·구문 확인·본편 이동/부츠 겹침의 시각 검수를 구분합니다. 공통 기준은 [캐릭터 아트 담당](../../../../../docs/roles/CHARACTER_ART.md), 현재 확인 범위는 [인계](../assembly/CURRENT_STATUS.md)를 따릅니다.
