# 메이 · 광장 안내원

사용자가 이름을 **메이**로 확정했습니다. 광장 표시 이름과 대화창은 메이를 사용하며 내부 ID `plaza_guide`는 유지합니다.

사용자가 승인한 `approved-concept.png`의 갈색 묶은 머리·호박색 눈·초록 망토·별 브로치·크림 블라우스·청록 치마·지도·갈색 부츠를 유지합니다.

현재 생성 원본은 `guide-source-v3.png`이며, 첫 원본 `guide-source.png`는 보존합니다. 승인 시안은 인물 정체성, 활성 `heroine-reference-bright-v10/heroine-idle.png`는 도트 화풍과 인물 비례 참조로 사용했습니다. 정면 전신 1명, 투명 배경, 손을 몸 가까이 두고 지도를 드는 대기 자세, 큰 색 덩어리와 제한된 셀 명암으로 제작했습니다.

- 출력: `art/export/plaza-guide/plaza-guide.png`, 96×136, 발 (48,116), 64px/단위.
- 인물 높이: 활성 주인공 정면 대기 프레임에서 측정한 99픽셀. 비균등 확대 없이 비율을 유지합니다.
- 기존 월드 LUT, 이진 알파, nearest, 손실 없는 압축, 밉맵 없음.
- 등록: `python scripts/package-plaza-guide.py`. 생성 원본과 승인 시안은 덮어쓰지 않습니다.
- 비교: `hero-guide-native-4x.png`는 두 실제 게임 PNG를 같은 배율로 4배 확대했습니다. 게임 실행 화면은 아닙니다.
- `scenes/plaza.tscn`의 광장_안내원, (32,0,32.5), 단위 배율, gameplay_id `plaza_guide`.
- `illustrated_art.gd`와 `illustrated_prop.gd`가 공통 조명·가림·발 등록을 사용합니다. 기존 resident 상호작용으로 안내 대사를 연결합니다.
- 현재는 `idle-v2/mei-idle.pxpen`의 정면 대기 애니메이션을 사용합니다. 호흡·눈깜빡임 보정 10자세이며 보행·방향 전환은 포함하지 않습니다. 상세 편집과 반영은 `idle-v2/README.md`를 따릅니다.

정적 연결과 PNG 비교를 확인했습니다. 게임 실행·브라우저 테스트·웹 내보내기는 수행하지 않았습니다.

## 인체 비율 보정

사용자가 첫 결과의 인체 비율 불일치를 지적했습니다. 전체 키만 99픽셀로 맞추면 머리 크기·어깨 폭·허리와 치맛단 높이가 같아지지 않습니다. 주인공의 큰 머리와 짧은 몸통을 기준으로 전신을 다시 그렸습니다. 머리만 잘라 확대하거나 신체를 비균등하게 늘리지 않았습니다.

v2 제작 지시는 약 2.3등신, 머리 높이 약 42%, 큰 머리와 짧은 몸통·치마·다리, 몸 가까이 지도를 든 작은 손입니다. 해당 수치는 생성 목표이며 결과의 정확한 관절 실측으로 간주하지 않습니다. 실제 출력 비교는 `hero-guide-native-4x.png`, 이전 비교는 `hero-guide-before-4x.png`입니다. 프레임/발/표시 밀도/광장 배치는 유지합니다.

입 보정: 사용자가 시안처럼 입을 그려 달라고 요청하여 v2를 참조한 국소 이미지 편집으로 작게 벌린 웃는 입을 추가했습니다. v3를 같은 96×136/99픽셀 높이로 등록했으며 실제 도트 비교에서 입의 가독성을 확인했습니다. v2도 보존합니다.

사용자는 `approved-standard-proportions-4x.png`의 메이를 게임에 사용할 버전으로 재확정하고, 이 비교 이미지의 신체 비율을 일반 캐릭터의 기본으로 지정했습니다. 활성 PNG와 비교 이미지 오른쪽의 픽셀이 같은 배율에서 일치함을 확인했습니다. 제작 공통 기준은 ARCANA_ART_GUIDE.md의 일반 캐릭터 확정 비율을 따릅니다.

웹 반영 완료: 승인된 v3 메이 PNG를 포함한 별도 런타임 사본에서 가져오기와 Web 내보내기를 완료하고 godot-web에 교체했습니다. PCK 인덱스의 메이 자산과 빌드 사본/원본 PNG 해시 일치, localhost:3000/godot/index.pck의 HTTP 200 및 디스크/서버 SHA256 일치를 확인했습니다. PCK SHA256: a3f467293d056edc1070c7211a07a61cc0ed6c1c82463a79ec8f127299f2c89d. 브라우저 플레이는 실행하지 않았습니다.


## 웹 애니메이션 프레임 로딩

메이의 대기는 `scripts/package-mei-idle.py`가 저장된 native-frames로 묶은 `art/export/plaza-guide/mei-idle.png` 한 장을 사용합니다. SpriteFrames는 같은 시트의 10개 AtlasTexture 영역으로 96칸 타임라인을 유지하고, `mei_sprite.gd`는 재생 중 `frame_cell`만 바꿉니다. GPU 픽셀 읽기·ImageTexture 생성·재생 중 sampler 교체를 하지 않습니다. 개별 pose PNG도 기존 참조를 위해 보존합니다. PixelPen 원본·12FPS·발 기준점은 유지하며, 원본 수정 뒤에는 같은 패키저를 실행합니다. PixelPen 저장본을 네이티브 API로 다시 열어 10자세의 레이어·알파·96칸 참조를 확인했습니다. 모두 3,092 불투명 픽셀이며 기존 출력과 일치합니다. 검사 근거와 비교판은 `idle-v2/frame-audit/`에 있습니다. 정적 PNG와 시트의 중복 UID를 분리하고 패키저의 UID 복사를 제거했습니다. 수정 표시기와 내보낸 PCK의 96칸 GPU 출력은 모두 12,368 불투명 픽셀(2배 출력)로 유지되고, 반복 시작·동작 줄이기도 중립 프레임과 일치합니다. 웹 내보내기를 완료하여 godot-web에 반영했습니다. 브라우저 플레이는 실행하지 않았으며 당시 localhost:3000은 연결이 거부되어 서버 제공 여부는 확인하지 못했습니다.
