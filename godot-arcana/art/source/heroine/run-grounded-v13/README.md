# 부츠 연결 및 다리 회수 보정 · 오른쪽 8프레임

v12에서 부츠가 따로 움직여 보인다는 사용자 지적에 따른 후속 후보입니다. 대기 자세의 다리 두께·스타킹 색·부츠 도트를 유지하면서 다음을 수정했습니다.

- 부츠 윗단의 원본 좌표 (46,105)를 회전 중심으로 사용하고 종아리 끝과 같은 위치에 연결했습니다. 이전 (47,109) 중심의 독립적인 발 회전은 사용하지 않습니다.
- 허벅지와 종아리의 중심 길이를 각 12픽셀로 잡고 발 위치에서 무릎 위치를 역으로 구했습니다. 무릎은 진행 방향으로 굽히며, 관절 및 부츠 윗단에 연결 도트를 보완했습니다.
- 착지·체중 지지·밀어내기·공중·회수 순서로 부츠 윗단의 궤적을 다시 구성했습니다. 지지 구간은 밑창을 평평하게 두고 회수 구간은 종아리 방향에 맞춰 부츠가 돌아갑니다.

`pixelpen/run_e.pxpen`은 PixelPen 네이티브 API로 수정·저장·재열기한 원본입니다. 제작기는 `godot-arcana/tools/refine_heroine_run_grounded.gd`, 포장 도구는 `scripts/package-heroine-run-grounded.py`입니다. 원본 얼굴·상체·의상과 팔레트를 보존했습니다. 화면에서 마우스로 직접 그린 작업은 아닙니다.

`preview/idle-before-after.gif`는 왼쪽 대기 기준 / 가운데 v12 / 오른쪽 이번 후보입니다. `preview/run_e-native.gif`는 수정본 단독입니다. GIF는 저장본의 12fps 편집 타이밍이며 게임 재생 검증은 아닙니다. 정지 프레임에서 연결을 비교했으며 사용자 동작 평가는 아직 받지 않았습니다.

이번 범위는 오른쪽 후보 8프레임입니다. 활성 게임 연결·다른 방향·웹 출력은 변경하지 않았습니다. 기존 v12 편집본도 보존합니다.
