# 상태 간 연속성 보정 v3 · 2026-10-28

기본 의상의 대기·시전·앉기를 같은 96×136, 발 (48,116), 64px/단위, 기존 32색·이진 알파로 등록합니다. 최신 사용자 지시로 복원된 **run-v1 전신 달리기는 그대로 사용합니다.** motion-v2의 재구성 달리기·전환 클립을 다시 연결하지 않습니다.

## 편집 원본

`pixelpen/`의 17개 `.pxpen`이 이번 보정의 편집 원본입니다. 대기 8방향×4, 시전 8방향×6(중립 앞뒤 포함), 정면 벤치 8자세입니다. 기존 idle-v1/cast-v1/bench-v1/motion-v2 원본은 보존합니다.

- 대기는 motion-v2에 보존된 **그림으로 그린 방향별 중립 자세**를 가져왔습니다. 계산으로 재구성한 달리기 다리를 가져온 것이 아닙니다. 호흡은 목·밑단 사이의 몸통을 최대 1픽셀 움직이고, 깜빡임은 눈 부분만 수정합니다. 머리·머리카락·신발이 호흡마다 다른 그림으로 바뀌지 않습니다.
- 시전은 기존 시트의 전신을 공통 높이에 등록하고, 방향이 같은 중립 원본의 정지 다리로 공중에 들린 달리기 다리를 보정했습니다. 팔이 머리 높이까지 올라가는 기존 동작을 보존합니다. 시전 얼굴은 기존 원화라 중립과 세부 선화 차이가 남습니다.
- 시전의 처음·마지막은 대기 중립과 픽셀 단위로 동일합니다. 기존 발사 .32초와 전체 .68초는 보존하며, 중립 .00–.04 / 준비 .04–.12 / 응축 .12–.32 / 발사 .32–.48 / 회복 .48–.60 / 중립 .60–.68입니다.
- 벤치는 정면 중립과 같은 머리 레이어를 자세 높이에 맞춰 배치합니다. 앉은 호흡·깜빡임은 앉은 기본 자세에서 편집합니다. 서기 프레임 0은 대기와 동일합니다. 기존 몸 낮추기·일어나기 포즈와 좌석 정렬은 보존합니다.

## 수동 편집 반영

PixelPen에서 `.pxpen`을 저장한 뒤 `python scripts/author-heroine-continuity.py --sync`를 실행합니다. 기존 팔레트와 캔버스 크기를 유지합니다. 게임 아틀라스, 개별 PNG, 비교판과 GIF를 다시 출력합니다. 인자 없는 최초 제작은 편집 원본이 있으면 중단하므로 수동 편집을 덮어쓰지 않습니다.

게임은 `scripts/heroine_run.gd`에서 `art/export/heroine-continuity-v3/`의 세 시트를 사용합니다. 캐스트 미리보기의 기존 0..3 주소는 준비/응축/발사/회복을 계속 가리킵니다. 다른 의상은 기존 fallback입니다.

## 확인 자료와 범위

`preview/state-comparison.png`는 구 대기 / 새 중립 / 들숨 / 깜빡임 / 시전 준비 / 발사 / 회복 / 중립 복귀를 같은 배율로 비교합니다. `idle.gif`, `cast.gif`, `bench.gif`는 등록된 프레임과 타이밍의 자산 미리보기이며 실제 게임 플레이 영상은 아닙니다. `registration.json`은 주소와 경계 픽셀 차이를 기록합니다.

이미지 도구로 만든 후보는 방향 행이 빠져 채택하지 않았습니다. `art-studies/arcana-hero/white-bob-heroine/continuity-v3/cast-correction-rejected.png`는 검토용 보존본이며 게임에 연결하지 않습니다. 최종 자산은 기존 원본의 인덱스 레이어를 편집한 결과입니다. 생성 도구와 프롬프트는 같은 폴더의 제작 기록을 참고합니다.

자산 비교·패키지 확인·실제 브라우저 플레이를 구별하며, 최종 자연스러움 승인은 사용자의 플레이 확인으로 남깁니다.

Web 가져오기·내보내기와 같은 광장의 GPU 출력은 완료했습니다. art/reference/heroine-continuity-v3/에서 실제 장면 배율의 중립/들숨/발사/승인된 달리기를 볼 수 있습니다. 웹패키지와 로컬서버 제공파일 해시가 일치합니다. 자동플레이 없이 확인한 범위이며 실제 플레이의 전환 감각과 벤치 접촉은 사용자 확인 항목입니다.
