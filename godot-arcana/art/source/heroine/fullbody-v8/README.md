# 코 명암만 제거 v8

사용자가 v7에도 코 부근의 이상한 명암이 남았다고 지적했습니다. 원본 복원 과정에서 코·입 부근을 보호해 남겼던 금색/갈색/붉은 픽셀과 밝은조각이 원인이었습니다. 코 영역은 원본에 있더라도 해당명암을 복원하지 않습니다.

등록된 얼굴로컬코영역:정면x45~50/y48~51,대각선x58~61/y49~51,측면x62~65/y49~51. 반대방향은발x48기준반전,앉은높이와각프레임머리/상체변위를 적용합니다. 이영역에서밝은피부/진한피부/금색/갈색조각만기본피부14번 #edc3b1로 바꿉니다. 다른얼굴영역·눈·턱윤곽·머리카락·몸·움직임은전혀재제작하지않습니다.

25개PixelPen프로젝트152프레임을실제PixelPen네이티브API에서수정·저장·재열기·PNG출력했습니다. 변경은정면14/대각선7/측면8픽셀씩총904픽셀입니다. 등록된코영역밖의v7대비변경0,수정픽셀값오류0은nose-audit.json에기록합니다. native-frames/는실제저장결과이고preview/nose-before-after-front.png는실제저장본비교입니다. 이전v7은보존합니다.

일반수동반영:python scripts/sync-heroine-fullbody.py --source fullbody-v8 --export heroine-fullbody-v8

plan-heroine-nose-cleanup.py와네이티브패치는최초보정용입니다. PixelPen에서수동저장한이후에는일반동기화만사용하며이미편집한원본을제작계획으로다시덮어쓰지않습니다. 게임및패키지반영결과는PRODUCTION.md최신기록을따릅니다.
