# 전신 기준 및 PixelPen 프레임 보정 v5

## 사용자 확정 기준

기준은 사용자가 선택했던 `run-v1/pixelpen/run-{direction}.pxpen`의 달리기 원본입니다. 머리만 통일한 v4는 머리 크기·목 연결·몸통 비율을 함께 보정하지 않아 사용자가 거부했습니다. v4의 완료 주장은 이 작업의 완료 근거로 사용하지 않습니다.

기준 대표는 각 방향의 두 번째 달리기 자세(0기반 frame1)입니다. 원본의 뒤 대각선/옆방향 혼합을 피하기 위해 NW/W/SW의 인물 기준은 NE/E/SE 전신의 발 x=48 반전에서 가져옵니다. 승인된 달리기 원본 자체와 이전 후보를 덮어쓰지 않습니다.

## 이번 전신 보정

- 원본96×136,발(48,116),64px/단위,기존32색·이진알파를 유지합니다.
- 기준 원본 머리 윗점은 방향별 y16~17입니다. v4의 y10/큰 머리와 달리기 몸통을 합친 비율을 폐기했습니다.
- 프레임별 전체 도트의 가로 축척과 머리/목/허리/치맛단/발 등록을 함께 보정합니다. 기본 등록 목표는 목58,허리76,밑단94,발116이며 앉기는 실제 몸 낮추기 높이를 반영합니다. 움직이는 팔·옷·다리를 같은 연결 좌표 안에서 이동합니다. 물리적3D뼈 길이를 측정했다고 주장하지 않습니다.
- 얼굴은 기준 달리기 원본의 얼굴색·눈·선화를 사용하고 목 위치를 몸통과 함께 등록합니다. 피부 기본색은 달리기 원본의 `#edc3b1`이며 기존 그림자 범위를 사용합니다.
- 깜빡임은 기준 얼굴의 눈 좌표를 직접 수정합니다. 높이 든 팔은 원래 소매/손 픽셀 경로를 보존해 얼굴 아래에서 잘리지 않게 보정했습니다. 분리된 잔여 도트는 제거했습니다.
- 시전 앞뒤 중립과 벤치 서기는 새대기 전신과 동일하게 연결합니다. 발사.32초/전체.68초와 기존 이동/충돌은 유지합니다.

이 기록은 상태별 단순 팔레트 공유나 머리 불투명 픽셀 비교를 전신 검수로 대신하지 않습니다. 포즈별 옷 주름·소매·치맛단 변화는 의도된 움직임이며 원화 설계의 모든 세부 선이 동일하다는 뜻은 아닙니다.

## 실제 PixelPen 편집·저장

`plans/*.json`에는152프레임의 각각의 `(frame,x,y,expected,index)` 수정 좌표가 있습니다. `tools/patch_heroine_fullbody.gd`가 설치된 PixelPen1.1.4의 ProjectPacker/IndexedColorImage API로 원본을 열고, 도트를 수정하고, 별도 `.pxpen`으로 저장하고, 다시 열어 픽셀을 확인하고 PNG를 내보냈습니다. Python으로 `.pxpen` ZIP을 새로 써서 PixelPen에서 수정한 것처럼 표시한 결과가 아닙니다. 마우스로 하나씩 그렸다는 주장도 하지 않습니다.

`pixelpen/`25개 프로젝트와 `native-frames/`152개 PNG가 실제 저장 결과입니다. 최초 전신 수정 이후에는 달라진 클립만 추가 보정했습니다. 마지막 `plans/native-result.json`의 프레임 수는 마지막 증분 배치 수이며 전체152개 수를 뜻하지 않습니다. 전체 등록은 `native-package-audit.json`입니다.

수동 편집은 PixelPen에서 `pixelpen/`의 `.pxpen`을 열어 저장한 뒤 `python scripts/sync-heroine-fullbody.py`로 게임 시트에 반영합니다. `plan-heroine-fullbody.py`와 네이티브 패치는 최초/후보 제작 도구이므로 수동 저장 이후 일상 동기화에 다시 실행하지 마십시오.

## 검토 자료

`preview/*-native-all-frames.png`는 실제 PixelPen 저장본의 모든 프레임을 펼친 자료입니다. `native-state-flow.gif`는 같은 저장본의 전환 미리보기입니다. `fullbody-before-after.png`는 보정안 비교자료이며 실제 저장 결과는 native표시 자료를 우선합니다. 게임 장면 출력과 Web반영 범위는PRODUCTION.md 최신 기록을 따릅니다. 실제 브라우저 자동플레이는 하지 않습니다.
## 눈·몸통 수치 규격 후속

사용자가 눈 크기·위치를 픽셀 수로 계산해 최대한 규격화하도록 추가 지시했습니다. 기준 정면 눈은 달리기 원본의 눈을7×7픽셀 창으로 등록하고 좌우에 같은 도트를 사용합니다. 홍채 외접은4×4, 눈 중심 간격12픽셀입니다. 대각선 가까운 눈7×7/먼 눈5×7, 측면6×7의 눈 창으로 등록하며, 반대쪽 방향은 x48기준 반전입니다. 뒷면은 눈을 넣지 않습니다. 각 방향의좌표·홍채실픽셀수·팔레트별픽셀수는pixel-standard.json에 저장했습니다.

같은 방향의 모든 대기/달리기/시전/벤치 눈 창을 비교해160개 창(깜빡임10개 포함)의 좌표·도트 차이0을 확인했습니다. 이 수치는 눈 규격에 대한 증거이며 전신 자연스러움의 증명을 대신하지 않습니다. 전체 전신의 같은배율 비교판과 실제 장면 출력도 별도로 확인합니다. 일반 수동 편집 후에는 sync-heroine-fullbody.py로 반영하고 눈규격 확인이 필요하면 audit-heroine-pixel-standard.py를 사용합니다.

몸통 가로 비율은 머리 폭으로 정하지 않고 선택한 달리기 원본의 몸통/치맛단 중앙연결 폭(소스y80~92의중앙연결 폭 중앙값)을 기준으로 정합니다. 기준달리기의 목 아래 전신 자세는 유지하고 대기·시전·벤치의 몸 크기를 이에 맞춥니다. 따라서 머리만 같은 그림을 붙이고 몸의 크기를 그대로 두는 이전v4 경로를 재사용하지 않습니다.
