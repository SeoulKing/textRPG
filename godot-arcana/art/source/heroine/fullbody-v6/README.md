# 얼굴 얼룩 제거와 상체 연동 v6

사용자가 v5의 고정된 머리와 얼굴의 화상처럼 보이는 명암을 지적했습니다. 기존 규격은 눈을 얼굴 안에서 유지해야 하는데 사실상 머리를 같은 화면 좌표에 붙이는 결과였습니다. 이 두 문제만 저장된 v5 PixelPen 원본에서 수정합니다. 선택한 달리기 원본·전신 비율·의상·이동과 충돌은 유지합니다.

## 얼굴

피부는 #edc3b1 한 톤으로 정리했습니다. 얼굴 내부의 밝은 조각과 붉은 그림자를 기본색에 합쳤고, 코·볼의 금색·회색 얼룩을 지웠습니다. 보랏빛 눈·진한 외곽선·머리카락은 유지하고 입은 작은 두어 도트로 표시했습니다. 감긴 눈은 같은 피부 바탕과 별도 눈꺼풀 도트입니다. 정면/대각선/옆모습과 반대방향의 명시적인 얼굴 영역에만 적용하며 머리카락이나 전신 팔레트를 전역 치환하지 않습니다.

## 움직임

달리기는 기존8자세의 접지·압축·회수에 맞춰 상하 -2/0/+1픽셀, 좌우 -1/0/+1픽셀의 상체 움직임을 사용합니다. 프레임별 head_offset은 머리만의 독립 이동이 아닙니다. 머리·목·어깨·가슴에 같은 정수 이동을 적용하며 가슴 아래부터 허리/치맛단까지 점차 줄입니다. 발과 지면 접촉은 고정합니다. 대기 들숨과 앉은 호흡은 -1픽셀, 응축은 -1/발사는 +1픽셀로 상체가 따라갑니다.

앉기의 기존 자세 높이를 먼저 적용하므로 머리/목/어깨에 같은 좌표계를 유지합니다. 숫자는 registration.json의 head_offset/seat_offset/upper_transform_full_until_y/blend_end_y에 있습니다. 무작위 떨림·머리만의 재크기 조정·별도 런타임 머리 오버레이는 사용하지 않습니다.

눈 규격은 얼굴 로컬 좌표입니다. pixel-standard.json은 각프레임 상체 이동과 앉은 높이를 보정해 눈창160개(깜빡임10개)를 비교했으며 차이0입니다. motion-audit.json은 목/어깨 구간51072픽셀이 머리와 같은 이동으로 보존되는지 확인한 자료이며 차이0입니다. 이는 연동 구현의 증거로, 최종 자연스러움에 대한 사용자 미술 승인을 대신하지 않습니다.

## 실제 편집 원본과 반영

25개의pixelpen/*.pxpen,152프레임을 PixelPen1.1.4 네이티브 API에서 수정·저장·재열기·PNG출력했습니다. plans/native-result.json과 .runtime/godot/fullbody-v6-face-motion-native.log에 기록합니다. 이전v5원본은 보존합니다. 마우스로 모든 픽셀을 직접 클릭해 그렸다는 뜻은 아닙니다.

일반 수동 편집 후 반영:

python scripts/sync-heroine-fullbody.py --source fullbody-v6 --export heroine-fullbody-v6

눈 규격 확인:

python scripts/audit-heroine-pixel-standard.py --source fullbody-v6

plan-heroine-face-motion.py와네이티브패치는 최초 보정용이므로 수동 편집본에 다시 적용하지 마십시오. preview/의 전체프레임 비교판과native-state-flow.gif는 저장된 원본의 실제출력입니다. face-before-after.png는 같은 좌표의 명암 보정 전후자료입니다. 실제게임 반영·장면출력 범위는PRODUCTION.md최신기록을 따릅니다.
