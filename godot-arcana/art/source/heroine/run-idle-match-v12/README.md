# 오른쪽 대기 자세를 기준으로 한 달리기 수정 후보

사용자가 v11 달리기의 얇은 다리를 거절하고 오른쪽 대기 자세와의 일관성을 요청했습니다. 이후 PixelPen 기능 호출 방식으로 우선 결과물을 만들도록 지시했습니다.

이번 후보는 **오른쪽 달리기 8프레임만** 수정했습니다. 원본은 `pixelpen/run_e.pxpen`이며, 기준은 보존된 `run-stride-v11/pixelpen/idle_e.pxpen`입니다. 허벅지/종아리를 기준의 약 11/10도트 폭으로 맞추고, 대기의 실제 스타킹 색 분포 및 부츠의 발등·밑창·금색 띠를 활용했습니다. 얼굴·머리·상체의 상단 84행은 수정 전과 동일합니다.

`refine_heroine_run_idle_match.gd`가 설치된 PixelPen API로 도트를 수정하고 저장·재열기했습니다. 화면에서 마우스로 찍은 작업은 아닙니다. 최초 제작용이므로 저장본을 수동 편집한 뒤 다시 실행하지 않습니다. `package-heroine-run-idle-match.py`는 저장된 PixelPen을 읽어 시트/GIF만 포장하며 픽셀을 다시 그리지 않습니다.

- `preview/idle-before-after.gif`: 왼쪽 대기 기준 / 가운데 거절된 v11 / 오른쪽 수정 후보.
- `preview/run_e-native.gif`: 수정본 단독, 저장된 12fps 기준 편집용 재생.
- `run-e-sheet.png`: 96×136 셀 8개를 가로로 배치한 투명 시트.
- `package.json`: 기준 및 저장본 해시, 보존 확인과 제작 범위.

사용자 검토용 후보로 저장했습니다. 다른 방향, 활성 게임 연결 및 웹 산출물은 변경하지 않았습니다. 게임/브라우저 테스트는 수행하지 않았습니다.
