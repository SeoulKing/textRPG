# 공원 벤치 모션 · 승인 시안 v1

- 사용자 승인: 2026-10-28, `approved-concept.png`의 앉기·휴식·일어나기.
- 원본: `bench-sheet-source.png` (내장 image_gen), 4열×2행의 공통 전신 포즈. 벤치를 포함하지 않습니다.
- 등록: 96×136, 발 (48,116), 공통 64px/월드 단위, 기존 32색 팔레트·이진 알파. 서 있는 첫 자세와 현재 대기의 높이를 맞춘 단일 배율을 모든 자세에 적용합니다. 앉은 자세를 따로 확대하지 않습니다.
- 포즈: 서기 / 무릎 굽히기 / 몸 낮추기 / 앉기 / 호흡 / 눈깜박임 / 일어나기 / 다리 펴기.
- 연결: `world.gd`의 approach → sit (0.52초) → seated → stand (0.42초), `heroine_run.gd`의 벤치 전용 시트. 서기/이동/시전 시트 주소는 보존합니다.
- 공원 벤치 5개: `plaza.tscn`의 `park_bench_01`~`05`. 기존 배치·충돌은 보존합니다. 실제 발 위치는 벤치 앞의 걸을 수 있는 지점에 유지하고 표시 위치만 좌판에 맞춥니다. 근처에서 상호작용하면 접근 후 앉습니다. 다시 상호작용하거나 키보드/조이스틱/목적지 입력 시 일어납니다.
- 기본 카메라와 벤치는 모두 정면 빌보드이므로 이번 포즈는 정면 한 방향입니다. 다른 의상의 Blender fallback에는 없는 모션을 억지로 적용하지 않고 안내합니다.
- 전투·시전·대기 중인 전투 요청이 있으면 앉을 수 없습니다. 앉아 있는 동안 전투 명령을 막고 장소/배치 변경 시 상태를 정리합니다. 메뉴/탭 일시정지를 따르며 연출 감소/효과 해제 시 앉은 대기 동작을 고정합니다.
- 제작 명령: `python scripts/package-heroine-bench.py`. `frames/`와 게임 시트를 원본에서 재생성하므로 직접 도트 수정 후에는 재패키징하지 마십시오.
- 제작용 화면: `tools/render_bench_interaction.gd` → `art/reference/bench-interaction/`. 실제 브라우저 조작 확인과 구별합니다.

## 생성 프롬프트

참조: 승인된 벤치 모션 시안과 기존 idle-front.png. 캐릭터만 투명 배경의 4×2 동일 격자에 제작하고 벤치·그림자·바닥·문자는 제외합니다. 모든 자세는 정면형 3/4, 백발 단발·보랏빛 눈·하늘색 숄·상아색 드레스·남색 리본·회갈색 부츠를 유지합니다. 서기→무릎 굽히기→앉기→휴식/호흡/눈깜박임→일어나기의 전신을 같은 축척과 발 기준으로 그리며 앉은 자세는 실제 굽힌 무릎과 드레스의 접힘으로 표현합니다.

## 소파 확장

여관 소파도 같은 클립과 상태 전환을 사용합니다. 기존 접근점 `(112,164)`와 충돌은 유지하고 표시 발 기준만 `(112,158)`로 중앙 쿠션에 맞췄습니다. 일반 사용자에게도 앉기를 제공하며 개발자용 `dev_sofa_rest`의 서버 HP·MP 회복 규칙은 유지합니다. 기존 이동/대기/시전 모션이 별도로 갱신될 수 있으므로 벤치 표시기는 일반 pose 전의 복원과 pose 후의 덮어쓰기로 연결합니다.
