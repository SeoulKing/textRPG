# 승인된 아르카나 침대 · 2×3칸

사용자가 승인한 스타듀 밸리 같은 정면형 3/4 침대입니다. 청금색 이불, 상아색 침구, 호두나무 프레임과 금색 별을 유지합니다.

- 편집 원본: `bed.pxpen`. Godot 4.5.1 / PixelPen 1.1.4 네이티브 인덱스 API로 2개 레이어를 작성하고 저장·재열기·PNG 출력을 완료했습니다. GUI 브러시 조작은 아닙니다.
- 승인 시안을 원본 해상도의 트레이싱 밑그림으로 준비한 후 PixelPen에서 재질별 색상 정리, 고립 픽셀 보정, 별 자수·베개 주름·목재 마감을 수행했습니다. 축소본만 최종 파일로 사용하지 않았습니다. 수치는 `pixelpen-audit.json`입니다.
- 캔버스 176×272, 발 기준 (88,250), 64px/월드 단위, 바닥 점유 2×3칸. 그림의 여백·머리판·이불 돌출은 점유 영역과 구별합니다. 투명 알파와 최근접 필터를 사용합니다.
- 완성 PNG: `res://art/export/bed-stardew-v1/bed.png`. `preview-4x.png`는 최근접 확대 미리보기입니다.
- 3D 월드 배치: `res://scenes/props/bed.tscn`을 인스턴스화합니다. 루트가 앞쪽 중앙 바닥 기준이며 침대는 -Z 방향으로 3칸 뻗습니다. 기존 illustrated_prop 렌더러를 사용합니다.
- 2D 배치: `res://scenes/props/bed_2d.tscn` 또는 `bed_tileset.tres`의 장면 타일을 사용합니다. 타일맵 장면 항목 하나로 침대 전체를 배치하고 주변 2×3칸을 비웁니다. 기존 상점 반 칸 편집 격자에서는 4×6셀입니다.
- 자체 물리 충돌은 포함했지만 기존 방의 내비게이션은 별도 사각형을 사용합니다. 실제 방에 배치할 때 manifest의 점유 사각형을 해당 방 배치 데이터에도 등록해야 합니다.
- 실제 방·사용자 배치·게임 기능·웹 산출물은 수정하지 않았습니다. 게임 플레이와 브라우저 검증은 실행하지 않았습니다.

재제작은 `node scripts/prepare-arcana-bed.cjs` → `pwsh -File scripts/author-arcana-bed.ps1`입니다. 기존 `.pxpen`이 있으면 재제작 스크립트가 중단하여 수동 편집을 보존합니다. 새 버전 경로로 복제해 사용하며 기존 원본을 삭제하지 않습니다. 후속 수동 편집은 PixelPen에서 원본을 열고 같은 경로의 PNG로 내보내시면 됩니다.

오프라인 미술 출력: tools/render_bed.gd가 기존 illustrated_prop 렌더러와 정사영 yaw0°/하향45°에서 현재 주인공을 나란히 출력합니다. scale-comparison.png는 공통 64px/단위의 크기 비교이며 실제 방 배치나 게임 플레이 검증이 아닙니다.
