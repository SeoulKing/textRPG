# 벽걸이 퀘스트판 v2

- 사용자 지시: 아래 두 다리와 받침을 제거하고 벽에 걸기. 초승달·게시물·보라색 천은 유지.
- 원본: inn-quest-board.pxpen. PixelPen native 인덱스 픽셀 제작 후 저장본에서 PNG 출력. GUI 브러시 조작은 아님.
- 이전 입식 v1 원본 보존. 현재 제작 스크립트: tools/author_inn_quest_board_wall.gd.
- 게임용 출력: art/export/inn-quest-board/inn-quest-board.png. 128×160 캔버스 유지, 아래 받침 영역은 투명 처리. 64px/단위·최근접·무밉맵.
- 벽걸이 위치 (14,1.1,4.05), 바닥 점유·충돌·바닥 그림자 제거. 상호작용 위치 (224,108). 2×1은 기존 크기 기준이며 더 이상 바닥을 막지 않음.
- PixelPen 저장/재읽기/내보내기 및 확대 이미지 확인 완료. 게임 실행·웹 빌드 미수행.
