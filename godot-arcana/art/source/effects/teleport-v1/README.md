# 텔레포트 전용 스킬 이펙트

사용자가 승인한8단계 시안은 `approved-concept.png`입니다. 분산 파티클 대신 윤곽 점등→압축된 빛 실루엣→가느다란 빛→소멸→도착 섬광→빛 실루엣 확장→윤곽 잔상→효과 종료를 사용합니다. 8방향×8프레임, 각20ms, 전체160ms입니다.

## 캐릭터와의 분리

캐릭터의 기존 대기·달리기·시전·벤치 시트, PixelPen 원본, `heroine_run.gd`와 캐릭터 셰이더를 수정하지 않습니다. 이펙트 원본은 이 폴더의 `pixelpen/blink_*.pxpen`, 게임 자산은 `art/export/effects/teleport-v1/teleport-effect.png`, 표시기는 `scripts/teleport_effect.gd`와 전용 셰이더입니다.

원본 캐릭터의 같은 방향 알파 윤곽을 읽기 전용 기준으로 사용해 빛 실루엣의 형태와 발(48,116)을 맞췄습니다. 효과 캔버스96×136·64px/단위는 캐릭터와 같지만, 효과 자체는 별도의 청백색/청보라색 팔레트입니다. PixelPen 네이티브 API로 효과8프로젝트64프레임을 실제 수정·저장·재열기했습니다. 기록은 `plans/native-result.json`입니다.

`pixel3d_world.gd`가 캐릭터의 정상 pose를 계속 갱신한 뒤 별도 이펙트를 출발/도착점에 배치합니다. 효과가 켜진 경우20~120ms 동안 캐릭터 표시만 숨기며, 캐릭터 재질·프레임·애니메이션 상태는 효과 표시기가 변경하지 않습니다. 효과 끄기/모션 감소에서는 캐릭터를 숨기지 않고 즉시 도착점에 표시합니다.

## 게임 연결

기본2번은 `teleport`이며 기존 `dodge` 대시도 기본 기술 목록과 퀵슬롯 선택에 유지합니다. 기존 저장에서 쿨타임은0으로 보완하고, 슬롯은1회만2번을 텔레포트로 이관한 뒤 이후 수동 설정을 존중합니다. 두 스킬은 별도5초 쿨타임과 숙련도 ID를 사용합니다. 기본 이동28좌표(1.75칸)·회피0.3초·MP0이며 텔레포트의 논리 위치는 입력 즉시 도착합니다. 벽·건물 충돌은 기존 구간 검사를 사용하여 통과하지 않으며 개발 가속은 거리를 늘리지 않습니다.

## 편집과 반영

- 일반 편집: 이 폴더의 PixelPen 저장본 수정 → `python scripts/author-teleport-effect.py --sync`.
- 최초 계획 생성은 `python scripts/author-teleport-effect.py`, 네이티브 적용은 `tools/patch_teleport_effect.gd`입니다. 수동 저장 후 최초 제작 경로로 덮어쓰지 않습니다.
- `native-frames/`는 실제 네이티브 PNG 출력입니다. 비교판과 GIF는 `preview/`에 있으며 캐릭터 이미지는 비교용으로만 합성합니다. 캐릭터 애니메이션 출력으로 사용하지 않습니다.
- 썸네일은 `art/export/spells/teleport.png`입니다. 생성된 컨셉 이미지를 잘라 게임 프레임으로 사용하지 않습니다.

## 텔레포트 카메라 추적

캐릭터가 먼저 도착하도록 카메라는 기존 위치에서0.12초 머무른 뒤0.28초 동안 부드럽게 따라갑니다. 일반 보행의 추적 여백·도트 스냅은 유지하고, 모션 감소 설정과 실내 전환의 즉시 재정렬은 기존 정책을 따릅니다. 일시정지 중에는 추적 연출 시간도 멈춥니다.
