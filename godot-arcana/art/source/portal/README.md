# 2D 포탈 제작 메모

승인된 시안에서 분리한 `portal-concept-sprite.png`를 원본으로 보존합니다. `python scripts/build-portal-2d.py`가 192×192 프레임, 접지점 (96,190), 64px/월드 단위의 정지 이미지와 4×2 아틀라스를 생성합니다. 월드 64색 팔레트, 디더링 없음, 이진 알파를 사용합니다. 8프레임을 초당 8장으로 반복하며 문 안의 푸른 빛만 변화합니다. 동작 줄이기 또는 효과 끄기에서는 첫 프레임을 표시합니다. 배치 배율은 기존 포탈별 값을 유지합니다. 실제 게임 장면의 접지·표시와 애니메이션은 별도 확인이 필요합니다.
